# 경로 카드 — 안전·협력사·보안

> [경로 카드 목록](경로-카드.md) · [입구](README.md). **전부 추론**이다 — `뼈대 — 계산` 줄은 후보이고, 과제의 동사와 데이터 모양이 다르면 그 부분은 직접 짠다. 뼈대 두 줄을 먼저 읽고, 렌즈 두 줄은 화면·방어를 짤 때 연다.

- **이런 과제 문장**: 「점검 누락」「교육 미이수」「안전 의무 이행」「협력사 평가」
- **필요한 데이터**: 의무 표(조·항·호, 주기) + 이행 기록 `duty_id, site, done_at, evidence_file, reviewer` — 이행 기록이 없으면 못 쓴다 / 없을 때: 교육 이력(`emp_id, course, completed_at, due_date`)만 있으면 미이수 명단부터([사람·안전·숙련](반도체-현장/업무-유틸리티-사람/03-사람-안전-숙련.md))
- **뼈대 — 계산**: [출력을 타입으로 묶기](../methods/LLM-응용-설계/02-출력을-타입으로-묶기.md)(증빙-조항 매핑, id 서버 검사) → [다기준 의사결정](../methods/의사결정분석/03-다기준-의사결정.md)(협력사 평가일 때만) → [평가 세트와 가드레일](../methods/LLM-응용-설계/03-평가-세트와-가드레일.md)(매핑 정답·유출 0건)
- **뼈대 — 현장 관점**: [사람·안전·숙련](반도체-현장/업무-유틸리티-사람/03-사람-안전-숙련.md) — 점검은 줄이지 않고 누락만 찾는다
- **렌즈 — 판정 기준**: [중대재해 증빙 원장](법학/기업법규/02-중대재해처벌법-증빙-원장.md) — 의무별 다음 기한과 증빙 파일을 한 줄로 묶고 빈칸을 경보로 띄운다
- **렌즈 — 방어·설득**: [하도급법 기술자료](법학/기업법규/03-하도급법-기술자료.md) · [데이터 흐름도·STRIDE](컴퓨터과학/정보보안/01-데이터-흐름도와-STRIDE-위협표.md)
- **화면 한 장**: 조항 × 사업장 신호등 + 누락 증빙 목록 + 「조문 원문 보기」
- **지표 3**: 의무별 이행률 · 기한 초과 건수 · 증빙 누락 건수(0 목표)
- **반문 하나**: 「법무팀 시스템이 이미 있을 것」 → 이 도구는 현장 기록(점검일지·회의록)과 조문을 잇는 층이다
- **어디까지 맡기나**: 기한·누락 판정은 결정론, LLM 은 증빙-조항 매핑만, 법 해석은 사람(추론, [행동별 자율성 단계표](컴퓨터과학/자율성-설계/01-행동별-자율성-단계표.md))
- **같이 꺼낼 카드**: [SOP·규정 대조](경로-카드-SOP-규정-대조.md)(「서명 누락」「순서 위반」「누락률」이 같이 있으면)
