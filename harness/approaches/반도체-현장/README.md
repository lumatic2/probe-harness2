# 반도체 현장 — 학문 지도

> [입구](../README.md) › **반도체 현장**

**반도체 현장**은 학문이 아니라, 같은 과제를 현장 직무의 눈으로 읽는 법이다. 다른 분야 기법이 아니라 **같은 과제를 읽는 눈**이고, 과제 하나가 여러 눈에 걸리는 게 보통이라 「같은 데이터를 두 관점 이상으로 읽어 주는 것」이 목적이다(추론).

## 관점 아홉
관점마다 챕터 하나다. 「결정 직무」와 「핵심 지표」는 챕터에서 뽑았다. 과제 문구 신호는 [신호 지도](../신호-지도.md), 근거 등급은 각 챕터 끝에 있다. ★ 는 출처를 열어 확인하지 못한 통념이다.

## 옆 학문으로
- 과제 문구에서 챕터 찾기, 다른 학문의 눈과 같이 읽기 → [신호 지도](../신호-지도.md)
- 기법·계산·코드(기법 18개) → 경영과학 `harness/methods/`. 챕터마다 「짝 기법」로 잇는다.
- 결과를 원화로 말하기, 검사·계측의 돈 기준 → [원가관리회계](../회계학/원가관리회계/README.md)
- 알람·인계·가스 안전·PM 주기 → [공학](../공학/README.md)
- 변경 통제(Copy Exactly)·램프업 → 경영학 › [생산운영관리](../경영학/생산운영관리/README.md)

## 관점을 가로지르는 원리 다섯
(근거 + 추론)
1. **같은 이름의 지표가 직무마다 다르다.** 가용도 4종([설비 관점](흐름-설비-계획/02-설비.md)), 수율의 단계별 정의, 부서마다 다른 데이터 해석([흐름·생산 관점](흐름-설비-계획/01-흐름-생산.md)). → 과제 데이터의 지표를 받으면 **정의부터 묻는다**(추론).
2. **데이터 품질이 먼저다.** 「Data quality (veracity) has been recognized as big data “V” of most importance」, 정확성·완전성·맥락·보관 기간 문제. 「data still cannot be blindly trusted in analytical solutions」. (Moyne & Iskandar)
3. **현장 전문가 지식이 계속 필요하다.** 결론: 「incorporating SME is usually required to realize robust and maintainable solutions」. SK하이닉스 품질 채용 담당의 「판단은 결국 엔지니어의 몫」과 같은 방향.
4. **한 관점의 개선이 다른 관점의 비용이다.** 검사를 늘리면 W@R 은 줄지만 사이클타임이 는다([계측·제어 관점](품질-계측-후공정/02-계측-제어.md)). Q-time 은 수율을 위해 걸지만 흐름을 불안정하게 만든다([흐름·생산 관점](흐름-설비-계획/01-흐름-생산.md)). 장비를 바쁘게 돌리면 비싼 장비 값은 하지만 사이클타임이 폭증한다. → **트레이드오프 곡선 하나**가 대부분 관점에서 가장 설득력 있는 화면이다(추론).
5. **성숙한 것과 아직 부분 성공인 것을 구분한다.** 널리 쓰임: FD·SPC·R2R. 부분 성공: PdM·VM·예측 스케줄링. 미래 과제: 수율 예측(Moyne & Iskandar). → 「성숙한 도구 위에서 사람의 결정을 빠르게」가 「아직 안 되는 예측을 해냈다」보다 서술형 답에서 방어하기 쉽다(추론).

**전제**: 이 선반은 공개 자료 기준의 일반론이다. 해외 판매사(INFICON·Applied Materials)의 일반론이 메모리 IDM 팹에 대체로 맞는다고 본다 — 반례 가능성: 메모리 팹은 제품 수가 적고 물량이 커 FabTime 응답의 「제품 믹스」 순위가 다를 수 있다(추론).

## 표기와 약칭
> **표기**: **(추론)** 은 필자 판단이라 근거 등급이 없다. **★** 는 업계 통념이지만 원문으로 확인하지 못한 것 — 단정하지 말고 현업에게 물어볼 질문으로 쓴다. 따옴표 안 영어·한국어 문장은 원문 그대로다. `[H1]` 같은 꼬리표는 각 챕터 「근거」의 출처 id(이 모듈 안에서만 유효). 값은 이 챕터에 옮겨 둔 것만 쓰고, 필요하면 현장 데이터·원 출처로 다시 확인한다.
> 「6시간 최소 문제」는 전부 필자 설계이며 현업 검증을 거치지 않았다. SK하이닉스 뉴스룸 기사의 발언(E4)은 개인 발언이고, 직무 구조 서술은 자사 기사(E2)다.
