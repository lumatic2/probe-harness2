# 품질·수율 관점 — 「불량은 어디서 왔고, 내보내도 되나」

> [품질-계측-후공정](README.md) › 01 · 짝 기법: [기대손실 결정표](../../../methods/의사결정분석/01-기대손실-결정표.md), [공정능력](../../../methods/품질과-신뢰성-통계/03-공정능력.md), [관리도와 오경보 주기](../../../methods/품질과-신뢰성-통계/01-관리도와-오경보-주기.md) (+[관련원가·매몰원가](../../회계학/원가관리회계/01-관련원가와-증분분석.md) 관련원가)
> 원 분야 사실에는 근거 등급을 달았고, 반도체로 옮긴 부분은 별도 표시가 없으면 **추론**이다. 모듈 주의는 [모듈 README](README.md), 표기는 [입구](../../README.md) 「표기」.

## 바로 쓰는 칸
- **쓸 점**: 「출하해도 되나」「불량 원인」 과제에 판정표 + 영향 범위(같은 경로 로트 수) + 공통 장비·챔버 순위를 얹는다(추론).
- **필요한 데이터**: 웨이퍼맵·빈(`lot_id, wafer_id, die_x, die_y, bin`)과 공정 이력(`eqp_id, chamber`) — 이력이 없으면 공통 장비·영향 범위를 못 센다(추론).
- **6시간 최소 형태**: 웨이퍼맵 → 규칙 기반 특징 → 패턴 라벨 + 공통 장비/챔버 순위 / 웨이퍼맵 격자 + 판정표(판정·적용 규칙 번호·근거 값).
- **반문 하나**: 「영향 범위는요?」 → 같은 경로 로트 수를 화면에 둔다(「다른 제품으로 문제가 확대될 가능성까지 확인한다」에 기댐).
- **하지 말 것**: 수율을 단계·분모 없이 말하기, WM-811K 를 라이선스 확인 없이 재배포·상업 사용하기(원 배포처 404, 미확인).

## 핵심
- **이 눈이 던지는 질문**: 불량이 어디서 왔나? 이 로트를 내보내도 되나?
- **과제 문구 신호**(추론): 「출하해도 되나」「불량 원인」「수율 이탈」「웨이퍼맵」「영향 범위」「재검/보류」「오경보·미탐」
- **핵심 지표와 공식**(원문 표는 부록)

| 지표 | 뜻 | 근거 |
|---|---|---|
| 라인 수율과 단계 수율 | (추론) 단계 수율이 곱해지므로 단계당 0.1%p 차이도 라인 전체에선 크게 벌어진다 | Moyne & Iskandar 2017 · E2 |
| 수율의 분자·분모 | 투입 대비 양품 비율 — 분자·분모와 측정 단계부터 확인 | ★(필자 요약, 외부 출처 미확인) |
| 로트 수율 평균 ≠ 전체 수율 | 전체 양품 ÷ 전체 투입, 엔지니어링 로트 제외 건수 표시 | 필자 요약(외부 출처 미확인) |
| 수율 학습곡선 | 신제품은 낮은 수율로 시작 — Tirkel: 현장에 더 맞는 S자 | Tirkel IEEE TSM 2013 · E2(초록) |
| 관리한계 ≠ 규격한계, Cp / Cpk | UCL/LCL 은 공정이 보이는 범위, USL/LSL 은 고객·설계 한계 — 다른 색 선 | 필자 요약(외부 출처 미확인) |
| 작은 표본의 비율 | 점이 아니라 구간으로 말한다 | 외부 출처 미확인 |

- **결정 직무**: SK하이닉스 품질보증 네 세부 직무(제품인증·양산품질보증·고객품질·불량분석)와 수율·소자·PE (부록 「결정 직무」).
- **데이터**: 웨이퍼 테스트 빈·웨이퍼맵, 공정 이력, 계측값(YMS·SPC). 컬럼 예 `lot_id, wafer_id, die_x, die_y, bin, test_item, value, pass_fail`(필자 설계 — `unique()` 로 확인). 연습용 SECOM(UCI #179)·WM-811K 의 라이선스는 부록 「데이터」.
- **6시간 최소 문제**(추론): ① 웨이퍼맵 → 규칙 기반 특징 → 패턴 라벨 + 같은 패턴이 공통으로 지난 장비/챔버 순위. ② 출하 판정표: 규정 + 검사값 → 출하/재검/보류 + 영향 범위(같은 경로 로트 수). ③ 수율 램프 곡선 맞추기(S자) → 목표 수율 도달 예상 주차와 불확실성.
- **현장 사람이 할 반문**: ① 「영향 범위는요?」 ② 「이 수율은 어느 단계 값이고 분모가 뭔가요?」(추론) ③ 「AI 가 찾은 미세한 불량 가능성이 실제 어떤 위험인지는 누가 판단하나요?」(추론)

## 부록 — 상세·인용·근거
### 무엇을 보나
- **무엇을 보나**: 웨이퍼 한 장에서 나온 **좋은 칩의 비율**과 그 손실의 원인. 수율 정의가 측정 단계(팹·웨이퍼 테스트·패키지·최종)에 따라 다르다는 점은 외부 출처 미확인.
  - 단계: 웨이퍼 테스트 단계는 EDS(웨이퍼 상태에서 칩별 전기 검사·수선·불량 표시, 필자 요약). 「HBM 수율」은 단계를 붙여 말한다(웨이퍼 테스트·적층 후·최종 테스트 — [후공정·HBM 관점](03-후공정-HBM.md) 부록 지표 표). 수율 3종 구분은 ★.
  - 용어(정의는 필자 요약, ★ = 출처를 열어 확인 못 한 통념): **Bin** 전기 검사 결과에 따른 칩 분류 번호, 범주형이라 평균 금지, Bin1=양품은 ★ · **웨이퍼맵** · **불량 패턴**(★) 가장자리 링·중심·스크래치·국소 등, 클래스 목록은 ★ · **이탈 Excursion** 평소 범위를 벗어난 사건, SECOM(UCI) 「yield excursions」
    - **공통성 분석**(★) 불량 로트들이 공통으로 지난 장비·챔버·레시피 · **Hold/Release**(★) · **재검/폐기**(★) 판정 규정집의 핵심 출력.

### 핵심 지표와 공식 — 원문
- **핵심 지표와 공식**

  - **라인 수율과 단계 수율**: 「Yield across the entire line usually must be very high (e.g., >90%, which often translates to >99% at each process step)」. (추론) 단계 수율이 곱해지기 때문 — 단계가 수백 개면 단계당 0.1%p 차이가 라인 전체에선 크게 벌어진다.
    - 근거: Moyne & Iskandar 2017 · E2
  - **수율의 분자·분모**: 투입 대비 양품 비율. 분자·분모(다이·로트·라인)와 측정 단계를 확인한다. 같은 이름의 지표가 직무마다 다르다 → 정의부터 묻는다(추론)
    - 근거: ★(3종 구분, 외부 출처 미확인)
  - **로트 수율 평균 ≠ 전체 수율**: 로트 크기가 다르면 다르다. 전체 양품 ÷ 전체 투입으로 보고, 엔지니어링 로트 제외 건수를 표시한다
    - 근거: 필자 요약(외부 출처 미확인). 로트 평균의 함정
  - **수율 학습곡선**: 신제품은 낮은 수율로 시작해 끌어올린 뒤 유지해야 한다. Tirkel 은 전통적 학습곡선(누적 생산의 거듭제곱 함수) 대신 단계별 수율 학습곡선(지수 함수)을 곱한 복합 모형을 제안했고 그 모양이 「sigmoid shape curve which better coincides with practice」(현장에 더 맞는 S자)라고 썼다. Moyne & Iskandar 도 「rapid yield ramp-up is a challenge」
    - 근거: Tirkel IEEE TSM 2013 · E2(초록 기준) · Moyne & Iskandar E2
  - **관리도 오경보(ARL)**: 3σ 단독·WECO 규칙을 더했을 때의 평균 오경보 주기 수치 → [엔지니어 업무 관점](../업무-유틸리티-사람/01-엔지니어-업무.md) 부록 지표 표
    - 근거: 관리도와 오경보 주기 문서, NIST e-Handbook(아래 근거)
  - **관리한계 ≠ 규격한계, Cp / Cpk**: 관리한계(UCL/LCL)는 공정이 스스로 보이는 범위(보통 ±3σ), 규격한계(USL/LSL)는 고객·설계가 정한 한계 — 다른 색 선. Cp/Cpk 는 공정능력지수, Cpk 는 치우침을 반영해 Cpk ≤ Cp. 자세히는 공정능력
    - 근거: 필자 요약(외부 출처 미확인)
  - **작은 표본의 비율**: 표본이 작으면 비율을 점이 아니라 구간으로 말한다. 이상치는 지우기 전에 표시한다
    - 근거: 외부 출처 미확인

### 결정 직무와 데이터
- **결정 직무**: SK하이닉스 품질보증은 네 세부 직무 — 제품인증(Qualification)·양산품질보증(품질 모니터링, 공정 부적격 자재 처리, **공정 변경 관리**, 출하 품질 검사)·고객품질·불량분석. 이상 데이터가 나오면 원인만 찾고 끝내지 않고 「고객에게 미칠 영향과 출하 가능 여부, 다른 제품으로 문제가 확대될 가능성까지 확인한다」.
  - 분석 도구로 Excel·Python·JMP 를 직접 언급하고, 일하는 법을 「정상과 불량 집단을 비교하고 가설을 세운 뒤 검증하는 과정」으로 적었다. 수율·소자·PE 도 이 눈의 결정자다.
- **데이터**: 웨이퍼 테스트 빈·웨이퍼맵, 공정 이력, 계측값(YMS·SPC).
  - 컬럼 예(필자 설계·추론, 실제 열 이름은 `unique()` 로 확인): `lot_id, wafer_id, die_x, die_y, bin, test_item, value, pass_fail` · 웨이퍼맵 2D 배열(WM-811K 모양)
    - 로트 요약 `lot_id, good_die, total_die, yield_pct, lot_type(양산/엔지)` · 고객 클레임 `claim_id, customer, product, lot_id(역추적), symptom, received_at, due_at, status, root_cause, capa`(8D·RMA 회신 기한 등 세부 업무 흐름은 ★).
  - 연습용 공개 데이터(URL 은 아래 근거): **SECOM**(UCI #179) 1,567행 × 591 특징, 라벨 −1=pass / 1=fail, fail 104건, NaN 결측 다수, CC BY 4.0 · E2. **WM-811K** — Kaggle 표기 CC0 이나 업로더는 원저자가 아니고 원 배포처(MIR Lab)는 404 → 원저자 라이선스 미확인, 재배포·상업 사용은 보류 · E3(업로더 자기 표기). 로트 수·라벨 수는 검색 요약 기준.

### 흔한 고통
- **흔한 고통 — 현직자 말**: 「'한정된 인력으로 수많은 공정 변수를 어떻게 완벽하게 통제할 것인가'다. 엔지니어가 실시간으로 모든 데이터를 확인하고 미세한 이상 징후를 빠짐없이 잡아내는 데는 물리적인 한계가 있기 때문이다.」(서정원 TL) · 「원인을 알 수 없는 돌발 문제가 발생했을 때, 이를 '정해진 기한 내에 완벽하게 해결하는 것'이 가장 큰 도전 과제다.」(박우종 TL) · FDC 의 높은 설정 비용·오경보·미탐 인용은 [설비 관점](../흐름-설비-계획/02-설비.md) 부록.
  - 신호가 너무 많고 유용한 신호가 묻힘(SECOM 사례, 아래 원문).
  - SECOM 사례의 원문: 「Engineers typically have a much larger number of signals than are actually required」(SECOM(UCI), scrapling:make_request 축자). 수율 손실 원인이 먼지 → 공정 산포로 이동(외부 출처 미확인). 웨이퍼맵 패턴 분류가 사람 눈에 의존 ★. 고객 불량 분석 자동화는 「가능성」으로 언급(GaiA Biz 에이전트 글).
  - 데이터 품질: Moyne & Iskandar 의 인용 둘은 [엔지니어 업무 관점](../업무-유틸리티-사람/01-엔지니어-업무.md) 부록 「근거로 확인한 업무 장면」 표.

### AI/최적화 기회와 이미 쓰이는 것
- **AI/최적화 기회와 이미 쓰이는 것**: **웨이퍼맵 패턴 인식** — 웨이퍼맵의 실패 패턴이 원인 추적의 단서. Wu 외(2015, IEEE TSM)는 회전·크기에 불변인 특징으로 대규모 웨이퍼맵을 줄여 표현하고 811,457장 공개 데이터셋(WM-811K)을 만들었다(초록 기준). **수율 예측은 아직 미래 과제**: 「Yield prediction remains as a future effort hindered largely by data quality issues」.
  - **회사가 그리는 방향과 그 단서**: 채용 담당 TL — 「앞으로는 AI를 활용해 불량을 미리 감지하는 '예측 · 예방' 중심으로 발전」, 동시에 「하지만 AI가 미세한 불량 가능성을 찾아내더라도, 이것이 실제 어떤 위험을 의미하는지 판단하는 것은 결국 엔지니어의 몫」. → 서술형 답의 HITL(사람 확인) 근거로 그대로 쓸 수 있는 회사 자신의 문장(추론: 쓰는 법).
  - 성숙도: 널리 쓰임 FD·SPC·R2R · 부분 성공 PdM·VM·예측 스케줄링 · 미래 과제 수율 예측 — 인용과 읽는 법은 [설비 관점](../흐름-설비-계획/02-설비.md) 부록 「AI/최적화 기회」.
  - 회사 공개: Gauss Labs 가상계측을 양산 박막 증착에 적용하고 RCA(근본원인 분석) 솔루션을 예고(Gauss Labs 기사, E3, AI 번역 기사).

### 6시간 최소 문제 — 상세
- **6시간 최소 문제**(추론): ① 웨이퍼맵 → 규칙 기반 특징(가장자리 비율·중심 집중·선형) → 패턴 라벨 + 「같은 패턴 웨이퍼가 공통으로 지난 장비/챔버」 순위. ② 출하 판정표: 규정 + 검사값 → 출하/재검/보류 + **영향 범위(같은 경로 로트 수)** — 품질보증이 실제로 묻는 「다른 제품으로 확대될 가능성」을 화면에 둔다. ③ 수율 램프 곡선 맞추기(S자) → 「목표 수율 도달 예상 주차」와 그 불확실성.
  - 틀·화면(필자 설계): 판정은 결정론 규칙 엔진, 판정 사유 문장은 LLM. 사전학습 CNN 은 6시간에 무리 → 규칙 기반 특징. 웨이퍼맵 격자 렌더 + 패턴 라벨 · 판정 결과표(판정·적용 규칙 번호·근거 값) · 「이번 주 수율 이탈 원인 후보 Top 5」 카드 · 클레임 → 로트 역추적 → 영향 범위 → 회신 초안(사실/추정 구분 표시).
