## 바로 쓰는 칸
- **쓸 점**: 「쌓을수록 하나의 불량이 전체를 버린다」 — 층수·층별 수율로 최종 수율을 계산하고 사전 선별 기준(기대비용)을 고르게 한다(추론).
- **필요한 데이터**: 층수·층별 수율·선별 테스트 비용·버려지는 스택 비용 — 공개 수치가 없어 사용자 가정값으로 둔다(후공정 컬럼은 전부 ★).
- **6시간 최소 형태**: 층수·층별 수율·선별 비용·폐기 비용 → 「사전 테스트를 얼마나 엄격히 할까」 기대비용 곡선 / 최종 수율 계산기 + 선별 기준 슬라이더.
- **반문 하나**: 「그 층별 수율은 어느 단계, 어디서 나온 숫자죠?」 → 수율은 단계를 붙여 말하고 입력은 가정값으로 표시한다.
- **하지 말 것**: 실제 HBM 수율 수치(회사 비공개)·매체 추정치를 쓰기 — 0.99¹² 같은 산수는 (추론) 으로 표시한다.

## 핵심
- **이 눈이 던지는 질문**: 쌓은 칩 중 하나만 나빠도 전체가 버려진다 — 어디서 걸러낼까?
- **과제 문구 신호**(추론): 「HBM」「적층」「12단·16단」「사전 선별」「테스트 비용」「라인 전용」「패키지 테스트 데이터」
- **핵심 지표와 공식**(원문 표는 부록)

| 지표 | 뜻 | 근거 |
|---|---|---|
| 적층 수율 ≈ 층별 수율의 곱 | (추론, 산수) 층별 99% 로 12단 ≈ 88.6%, 16단 ≈ 85.1%, 층별 98% 로 12단 ≈ 78.5% | 실제 HBM 수율 수치는 비공개 |
| 수율의 단계 | 「HBM 수율」은 단계를 붙여 말한다 — 웨이퍼 테스트·적층 후·최종 테스트 | 외부 출처 미확인 |
| 사전 선별 · 테스트 비용 · 버려지는 스택 비용 | (추론) 사전 테스트가 엄격할수록 선별 비용은 오르고 스택 폐기는 준다 | 추론 |
| 번인 · KGD 선별 | 공식 수치 근거 없음 — 정의도 찾지 못했다 | 공백(근거 없음) |

- **결정 직무**: 양산기술(P&T) 패키지·테스트, HBM 융합기술. 설비 전용·입지 결정은 부록 「결정 직무」.
- **데이터**: 패키지·테스트 데이터, 적층 단계 이력. 컬럼 예 `stack_id, die_layer(1..12 또는 1..16), tsv_test_result, warpage_um, bond_temp` — 전부 ★(공개 1차 없음, 필자 설계).
- **6시간 최소 문제**(추론): ① 층수·층별 수율·선별 테스트 비용·버려지는 스택 비용 → 「사전 테스트를 얼마나 엄격히 할까」 기대비용 곡선. ② 테스트 빈 데이터 → 실패 항목 파레토 + 전공정 이력으로 겹치는 경로 찾기. ③ 라인 전용 시나리오 — 제품 A 라인 일부를 HBM 으로 돌릴 때 산출·납기 변화(용량 LP).
- **현장 사람이 할 반문**(추론): ① 「그 층별 수율은 어느 단계, 어디서 나온 숫자죠?」 ② 「증산 중엔 처음 보는 변수가 나오는데, 계산판이 그걸 어떻게 받나요?」 ③ 「가운데 다이 열은요? 선별만으로 되나요?」
- **옆 챕터로**: [품질원가](../../회계학/원가관리회계/02-품질원가와-검사-흐름.md)(예방·평가·실패 비용, HBM 적층 검사 흐름) · [결합원가·분리점](../../회계학/원가관리회계/03-결합원가와-분리점.md)(한 웨이퍼에서 여러 등급이 나올 때) · [웨이퍼 → 다이 → 비트당 원가](../../경영학/재무관리/03-웨이퍼-다이-비트-원가.md)(양품 다이당 원가)

## 부록 — 상세·인용·근거
### 무엇을 보나
- **무엇을 보나**: 전공정이 끝난 웨이퍼를 제품 형태로 **패키징**하고 설계대로 동작하는지 **테스트**한다. SK하이닉스에선 양산기술(P&T)이 맡는다 — 패키지 기술(칩 보호·열·전기 연결 구조)과 테스트 기술(동작 검증, 테스트 데이터로 오류 식별·개선 방향 도출). P&T 담당 부사장: 「P&T 공정 현장에는 엄청난 양의 데이터가 있습니다. 이를 잘 활용하면 수율을 높일 수 있고, 신제품 개발에 힌트를 얻을 수도 있습니다.」
  - 용어(정의는 필자 요약): **후공정**(★) 검사·패키징 등 칩을 제품으로 만드는 단계 · **HBM** DRAM 을 수직으로 쌓아 프로세서 옆에 붙인 고대역폭 메모리 · **TSV** 쌓은 다이를 수직으로 관통해 잇는 전극 · **MR-MUF / TC-NCF / 하이브리드 본딩** 적층·접합 방식들, 높이·휨·열이 선택을 좌우. 8대 공정 이름은 회사마다 다르다 — 하이닉스는 웨이퍼 제조 → 전공정 → 후공정으로 나눈다고 적는다(추론).
- **HBM 이 특별한 이유**: 「HBM은 다른 제품보다 공정 수가 많고 생산 과정도 복잡」(기자 서술), 12단 HBM3E 는 8단보다 공정 난도가 높고 「생산량을 급격히 늘려가는 과정에서 예상치 못한 변수가 추가로 발생할 수 있고 해결도 매우 어렵습니다」(한권환 부사장).
  - **설비 전용(轉用)** 결정(수요 급증 때 라인 전환 회고 둘)이 후공정 관점의 대표 결정이라는 근거는 [공급망·계획 관점](../흐름-설비-계획/03-공급망-계획.md) 부록 「결정 직무」에 있다. 적층 높이·휨·열이 본딩 방식 선택을 좌우한다(외부 출처 미확인).
  - 본딩 방식 차이(외부 출처 미확인): MR-MUF 는 다 쌓고 한꺼번에 접속(mass reflow) + 액체 보호재, 삼성·마이크론은 칩마다 필름을 끼우는 TC-NCF.
    - 하이브리드 본딩 도입 시점은 불확실.

### 핵심 지표와 공식 — 원문
- **핵심 지표와 공식**

| 지표 | 뜻 | 근거 |
|---|---|---|
| 적층 수율 ≈ 층별 수율의 곱 | (추론, 산수) 층별 99% 로 12단이면 0.99¹² ≈ 88.6%, 16단이면 ≈ 85.1%. 층별 98% 면 12단 ≈ 78.5%. → 쌓기 **전에** 나쁜 다이를 걸러 내는(사전 선별) 가치가 층수와 함께 커진다. 실제 HBM 수율 수치는 회사가 공개하지 않는다(매체 추정치는 쓰지 않음). | 외부 출처 미확인 |
| 수율의 단계 | 「HBM 수율」은 단계를 붙여 말한다 — 웨이퍼 테스트·적층 후·최종 테스트. 쌓으면 단계별 손실이 곱해진다(12단, 단마다 99% → 약 89%, 산술 예시 — 추론) | 외부 출처 미확인 |
| 사전 선별 · 테스트 비용 · 버려지는 스택 비용 | 6시간 최소 문제 ①의 입력 세 가지. 정의식은 따로 없다 — (추론) 사전 테스트가 엄격할수록 선별 비용은 오르고 스택 폐기는 준다 | 추론 · 관점 쌍 「쌓기 전 선별 비용 ↔ 쌓은 뒤 버리는 비용」 |
| 번인 · KGD 선별 | HBM 번인·KGD 선별 공정과 그 수율의 공식 수치는 근거 없음. KGD 의 정의도 찾지 못했다 | 공백(근거 없음) |

### 결정 직무와 데이터
- **결정 직무**: 양산기술(P&T) 패키지·테스트, HBM 융합기술.
  - 설비·입지 결정(외부 출처 미확인): 승부처 HBM 후공정은 자기 손 + 국내 조달(전공정 장비 해외 탑5 비중·TC 본더 이원화는 [공급망·계획 관점](../흐름-설비-계획/03-공급망-계획.md) 부록 「팹 바깥 조건」 조달 줄) · 미국 리쇼어링에서 하이닉스는 후공정 당사자(전공정은 한국, 미국은 패키징) · HBM 후공정을 어디에 두나 = 메모리 3사 입지 경쟁(중립성·비용 vs 고객 근접·보조금).
- **데이터**: 패키지·테스트 데이터, 적층 단계 이력.
  - 컬럼 예(★ — 공개 1차 없음, 필자 설계): `stack_id, die_layer(1..12 또는 1..16), tsv_test_result, warpage_um, bond_temp` + 전공정 이력 `lot_id, wafer_id, step_seq, eqp_id, chamber, recipe_id`. 후공정·HBM 현업 불량 데이터 컬럼은 공개 1차가 없어 전부 ★.

### 흔한 고통
- **흔한 고통**: 증산 중 「예상치 못한 변수가 추가로 발생할 수 있고 해결도 매우 어렵습니다」(한권환 부사장, 위 인용). 공정이 직렬이라 중간 확인이 중요하고, 높이·휨·열이 본딩 선택을 좌우한다(외부 출처 미확인). 후공정 공정별 구체 불량 통계는 ★.
  - 열(2026-11-09 보강): 가운데 다이의 열은 「열이 못 빠져 나가요」, 그래서 위아래로 열만 나르는 더미 TSV 를 뚫지만 「근데 이걸 뚫어 줘도이 패키징에서 가운데 열이 잘 안 빠져나간다 그래요.」 [칩쟁이 영상 https://www.youtube.com/watch?v=HKAGhIAZ_AI&t=1200s 및 &t=1230s, E5 개인 채널·영상 발언(「그래요」 투의 전해 들은 말)].
    - 더미 TSV 효과의 1차 수치는 확인하지 않았다. 「HBM 은 쌓을수록 가운데가 뜨겁다.」는 영상 발언 대신 1차 근거를 먼저 찾아 쓴다(외부 출처 미확인).

### 현장 사람이 할 반문 — 상세
- **현장 사람이 할 반문**(현직자 반문은 공개 자료에 없음 — 추론): ① 「그 층별 수율은 어느 단계, 어디서 나온 숫자죠?」(수율은 단계를 붙여 말한다) ② 「증산 중엔 처음 보는 변수가 나오는데, 계산판이 그걸 어떻게 받나요?」(한권환 부사장 인용에서) ③ 「가운데 다이 열은요? 선별만으로 되나요?」(칩쟁이 영상의 열 서술에서)

### AI/최적화 기회와 이미 쓰이는 것
- **AI/최적화 기회와 이미 쓰이는 것**: P&T 담당 부사장은 위 인용에서 후공정 데이터를 잘 쓰면 수율을 높이고 신제품 개발에 힌트를 얻을 수 있다고 했다. 이 선반이 모은 문서에는 후공정·HBM 전용 AI 적용의 공개 사례도, 선별 수율의 공식 수치도 없다(공백).
  - 인접 사례 하나 — 제품 테스트(SSD 등)의 「AI 기반 로그 분석 자동화」: 펌웨어 테스트 에러 메시지에서 원인 후보 탐색 → NVMe Spec 과 비교·검증해 위반 판단 → 요약 전달, 「스펙 관련 SSD 불량 분석 시간을 20% 이상」 단축(자사 주장, "스펙 관련" 불량으로 범위 한정, GaiA Biz 에이전트 글 · E2→성과 수치는 한 단계 낮춤).
  - HBM 이 아니라 SSD 다. 공통성 분석(불량이 공통으로 지난 장비·챔버·레시피)은 6시간 틀의 뼈대(추론).

### 6시간 최소 문제 — 상세
- **6시간 최소 문제**(추론): ① 층수·층별 수율·선별 테스트 비용·버려지는 스택 비용 → 「사전 테스트를 얼마나 엄격히 할까」 기대비용 곡선(기대손실 결정표). ② 테스트 빈 데이터 → 실패 항목 파레토 + 전공정 이력과 묶어 「어느 전공정 경로가 후공정 실패와 겹치나」. ③ 라인 전용 시나리오: 제품 A 라인 일부를 HBM 으로 돌릴 때 두 제품의 산출·납기 변화(용량 LP).
  - 틀·화면(필자 설계): 층수·층별 수율 → 최종 수율 계산기 + 사전 선별 기준(기대비용) 슬라이더. 공정 이력 + 계측값 조인 → 공통성 분석. 공정 흐름 가로 막대(스텝별 통과 장비) · 장비별 이상 비율 히트맵. 실제 HBM 수율 수치는 쓰지 않는다 — 계산판 입력은 사용자 가정값으로 둔다.

### 공백
- **공백**: HBM 번인·KGD 선별 공정과 그 수율의 공식 수치는 근거 없음(회사 비공개로 보임). 본 표면은 웹 검색 1회와 뉴스룸 임원 인터뷰 2편. 「하이닉스 HBM 수율 수치(공시 없음)」는 근거가 약하다.
