## 핵심 개념어
정의는 필자 요약이고, ★ 는 출처를 열어 확인하지 못한 통념이다.
- **Inform Note**: 장비 이상 상태·문제점·처리 결과를 다음 작업자·부서에 알리는 문서(SK하이닉스 용어).
- **명장·마스터**: SK하이닉스 숙련 기술 전문가 호칭. 제도 상세는 미확인이다.
- **GaiA**: Generative AI Assistant. SK하이닉스 반도체 업무 특화 생성형 AI 플랫폼.
- **에이전트 / 에이전틱 AI**: 도구를 써서 목표를 수행하는 AI / 스스로 계획·실행하는 고도화된 에이전트.
- **HITL**: Human-In-The-Loop. 사람 피드백이 계속 반영되는 구조(GaiA 설계 원칙).
- **클린룸**: 걸러진 공기로 가압·층류 기류를 만든 먼지 통제 공간. 청정도는 「클래스」.
- **레시피**(★): 장비가 공정을 수행하는 조건 묶음(온도·압력·시간 등).
- **Hold / Release**(★): 의심 로트를 멈춤 / 판정 후 다시 흘림.

## 관점 쌍
- **제조 효율 지표 ↔ 공조 효율**: 제조 지표가 좋아도 공조는 비효율일 수 있다([02](02-유틸리티-환경.md), 추론).
- **생산 계획 ↔ 유틸리티 비용**: 공정 장비 전력이 열이 되어 공조 부하로 돌아온다. 어느 시간에 어떤 장비를 돌리나가 유틸리티 비용을 바꿀 수 있다([02](02-유틸리티-환경.md), 추론).
- **사람 부족 ↔ 흐름 지연**: 팬데믹 때 작업자 부족 응답이 늘었다([03](03-사람-안전-숙련.md)).
- **기록·에이전트 ↔ 사람의 판단**: 공통 설계 원칙은 HITL 이다([01](01-엔지니어-업무.md)).
- **증산 압박 ↔ 안전**: 「안전보다 중요한 것은 없습니다」(한권환 부사장, 증산을 말한 같은 인터뷰)([03](03-사람-안전-숙련.md)).

## 이 분야 사람이 먼저 묻는 것 5
1. 교대 인계서·알람 처리 기준·변경 결재의 실제 양식은 무엇인가? (공개 근거 없음 ★ — 현업 질문)
2. 같은 이름의 지표를 부서마다 어떻게 정의하나?
3. 이 설비가 서면 어느 공정이 멈추나?
4. 이 장비를 다룰 사람이 교대별로 몇 명인가?
5. 가져온 수치의 조건(연도·지역·산업)이 우리 팹과 맞나?

## 흔한 함정
- LBNL 클린룸 공조 비중(36–67%)을 지금 메모리 팹 비중으로 옮긴다. 2001년·캘리포니아·다산업 보고다([02](02-유틸리티-환경.md)).
- 같은 보고서의 「up to 50%」(건물 에너지)와 「36–67%」(측정된 14곳의 시설 에너지)를 한 범위로 섞는다([02](02-유틸리티-환경.md)).
- 벤더의 「교대 직후 반복 이상 탐지」 주장을 사실로 쓴다. E4 로 취급했다([01](01-엔지니어-업무.md)).
- 교대 인계서 양식·알람 SLA·결재 단계를 아는 것처럼 말한다([01](01-엔지니어-업무.md)).
- 2020년 기술명장 인터뷰를 지금의 현장 상태로 말한다. 개인 인터뷰이고 시점이 있다([03](03-사람-안전-숙련.md)).
