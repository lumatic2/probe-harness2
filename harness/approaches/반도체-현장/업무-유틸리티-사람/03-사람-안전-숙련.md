# 사람·안전·숙련 관점 — 「누가 할 줄 알고, 누가 다치지 않나」

> [업무-유틸리티-사람](README.md) › 03 · 짝 기법: — (+[핵심 결정 기법(CDM)](../../공학/인간공학/05-핵심-결정-기법.md) CDM, [중대재해처벌법 이행 증빙 원장](../../법학/기업법규/02-중대재해처벌법-증빙-원장.md) 중대재해 증빙 원장)
> 원 분야 사실에는 근거 등급을 달았고, 반도체로 옮긴 부분은 별도 표시가 없으면 **추론**이다. 모듈 주의는 [모듈 README](README.md), 표기는 [입구](../../README.md) 「표기」.

## 바로 쓰는 칸
- **쓸 점**: 숙련·교대 공백과 점검·교육 이수 누락 과제에서 「이 장비를 다룰 사람이 0~1명」인 교대를 찾는다(추론).
- **필요한 데이터**: 숙련 매트릭스(사람 × 장비 자격)와 근무 편성·교육 이력(`emp_id, course, completed_at, due_date`) — 없으면 못 쓴다.
- **6시간 최소 형태**: 숙련 매트릭스 + 교대표 → 교대별 0~1명 공백 탐지 → 교차훈련 우선순위 / 배정표 · 구역 지도 신호등 · 미이수 명단.
- **반문 하나**: 「증산이 급한데 점검을 AI 가 줄이는 건 아니죠?」 → 「안전보다 중요한 것은 없습니다」를 근거로 점검은 줄이지 않고 누락만 찾는다(추론).
- **하지 말 것**: 숙련·교대 편성·안전 점검의 공개 적용 사례가 있는 것처럼 말하기(근거 없음), 2020 인터뷰를 지금 상태로 말하기.

## 핵심
- **이 눈이 던지는 질문**: 누가 그 일을 할 줄 아나? 사람이 다치지 않나?
- **과제 문구 신호**(추론): 「숙련」「교대 공백」「교차훈련」「명장·마스터」「점검·교육 이수 누락」「안전」「한정된 인력」「가스실·협력사 안전」
- **핵심 지표와 공식**

| 지표 | 뜻 | 근거 |
|---|---|---|
| 숙련 보유 인원·교차훈련 범위 ★ | (추론) 장비 자격별로 교대마다 다룰 수 있는 사람 수. 0~1명이면 공백 | ★(지표 이름만 있음, 정의식 없음 — 외부 출처 미확인) |
| 교육 이수율 ★ | (추론) 이수 인원 ÷ 대상 인원, 기한(`due_date`) 대비 | 같은 칸 ★ |
| 교차훈련 우선순위 | (추론) 공백 위험 × 장비 중요도 | 6시간 문제의 필자 설계 |
| Standby-WIP-waiting time | 인력 제약 신호로 쓴다 | INFICON CT 글(E3). 정의식은 이 카드에서 확인하지 않음 |

- **결정 직무**: 현장 리더(교대 편성)·명장·마스터(교육·난제 자문)·안전보건 조직(점검·교육). 직무 구분·학력 요건은 부록 「결정 직무」.
- **데이터**: 교육 이력·근무 편성·작업 허가·점검 기록 ★. 컬럼 예는 필자 설계 — `unique()` 로 확인(부록 「데이터」).
- **6시간 최소 문제**(추론): ① 숙련 매트릭스(사람 × 장비 자격) + 교대표 → 교대별 「이 장비를 다룰 사람이 0~1명」 공백 탐지 → 교차훈련 우선순위. ② 명장 조치 기록 검색 + 「이 조치를 아는 사람」 연결. ③ 점검·교육 이수 누락 탐지와 알림 초안.
- **현장 사람이 할 반문**(추론): ① 「교대마다 이 장비를 다룰 사람이 몇 명인지, 이 표는 누가 갱신하나요?」 ② 「그건 전임직 얘기입니까, 기술사무직 얘기입니까?」 ③ 「증산이 급한데 점검을 AI 가 줄이는 건 아니죠?」 ④ 「AI 가 찾아도 위험 판단은 우리 몫」
- **옆 챕터로**: [핵심 결정 기법(CDM)](../../공학/인간공학/05-핵심-결정-기법.md)(명장 암묵지 꺼내기) · [TWI 작업지도](../../경영학/조직과-지식/03-TWI-작업지도.md)(따라다니며 배우기를 끝내는 법)

## 부록 — 상세·인용·근거
### 무엇을 보나
- **무엇을 보나**: 기계와 데이터가 아닌 **사람의 역량과 안전** — 숙련 이전(명장 노하우), 인력 공백(교대·교차훈련), 작업 안전.

### 결정 직무와 데이터
- **결정 직무**: 현장 리더(교대 편성), 명장·마스터(교육·난제 자문), 안전보건 조직(점검·교육). 작업 허가·점검 양식의 실제 모양은 ★.
  - 회사 직무 언어(외부 출처 미확인): 생산직(전임직) 오퍼레이터·메인트 / 기술사무직 양산기술·양산관리·P&T·PE·소자·설계·R&D. 2026-06-17 신입 수시부터 **기술사무직**의 「4년제 학사 이상」을 삭제했고 전임직은 여전히 고졸·전문대졸이다 — 「하이닉스는 학력을 아예 안 본다」는 틀리고, 「직무 근육」은 회사 표현으로 확인 안 됨(미확인).
- **데이터**: 교육 이력, 근무 편성, 작업 허가·점검 기록 ★. 컬럼 예(필자 설계 — 실제 열 이름은 `unique()` 로 확인): 교육 `emp_id, course, hours, completed_at, due_date` · 점검 `zone, check_item, measured, limit, checked_at, inspector` · 편성 `emp_id, site(이천/청주…), shift(A~D), home_area, start_time`.

### 근거로 확인한 것
- **근거로 확인한 것**
  - **숙련 이전을 제도로**: SK하이닉스는 「현장 기술자의 경험과 역량을 활용하고 계승하기 위해 '명장'과 '마스터' 직책을 도입」했고 마스터 제도를 넓혀 「회사의 기술 노하우가 보존, 계승될 수 있는 환경」을 만든다는 방침(2023-12-20). Inform Note 에이전트도 「명장·마스터 지식」으로 보완한다(GaiA 에이전트 글, 근거 참조). 명장·마스터는 「SK하이닉스 숙련 기술 전문가 호칭」이고 제도 상세는 미확인이다(필자 요약).
  - 명장이 직접 후배 교육을 일정 잡아 진행 — 「유지보수 관리 업무 시에 장비에 사용되는 원부자재가 어떻게 만들어지는지 아는 것과 모르는 것은 천지 차이」.
  - **사람 부족이 흐름을 늦춘다**: 팬데믹 때 작업자 부족 응답 급증(FabTime 응답 글), 작업자·기술자 교차훈련 부족이 성능을 제약하는 실수로 꼽힘, 「Standby-WIP-waiting time」을 인력 제약 신호로 쓴다(INFICON CT 글).
  - **안전**: 「안전보다 중요한 것은 없습니다」(한권환 부사장, 증산 압박을 말한 같은 인터뷰). 산업보건 역사·위험의 외주화·가스실 화재는 외부 출처 미확인.

### 흔한 고통
- **흔한 고통**
  - 「한정된 인력」 문제 제기(서정원 TL, 뉴스룸 「품질보증」, E4)는 [품질·수율 관점](../품질-계측-후공정/01-품질-수율.md) 부록 · 증산 쪽 한권환 부사장 인용(같은 인터뷰, E4)은 [후공정·HBM 관점](../품질-계측-후공정/03-후공정-HBM.md) 부록.
  - 현장의 시선: 김진환 기술명장(Wire Bond)은 「앞으로는 장비 고장을 사전에 방지할 수 있어야 한다」며 FDC 시스템 구축 프로젝트와 카메라 이미지로 장비가 스스로 재가동을 판단하는 기능을 개발 중이라 했다(2020 인터뷰, E4 — 지금 상태로 말하지 않는다).
  - 숙련 인력은 지역·건설에도 걸린다: TSMC 애리조나는 숙련 인력 부족으로 1년 밀렸다. 곽노정 대표가 인정한 지방 팹의 장벽은 주거·교육(남방 한계선)이고, 청주 M15·M15X 는 수도권 밖에서도 대규모 팹이 돈다는 회사 자체 사례다(외부 출처 미확인).
  - 안전은 회사를 공격하지 않고 회사가 걸어온 길로 말한다: 2014 산업보건검증위원회 → 지원보상위 → 127개 과제 → 2017 선진화위 → 2026-11 성과공유회(협력사 보건관리 포함).

### 현장 사람이 할 반문 — 상세
- **현장 사람이 할 반문**(추론): ① 「교대마다 이 장비를 다룰 사람이 몇 명인지, 이 표는 누가 갱신하나요?」 — 모듈 README 의 질문 4. ② 「그건 전임직 얘기입니까, 기술사무직 얘기입니까?」 — 직무와 학력 요건이 갈린다(외부 출처 미확인).
  - ③ 「증산이 급한데 점검을 AI 가 줄이는 건 아니죠?」 — 근거: 「안전보다 중요한 것은 없습니다」. ④ 「AI 가 찾아도 위험 판단은 우리 몫」 — 채용 담당 TL 발언(원문은 [품질·수율 관점](../품질-계측-후공정/01-품질-수율.md) 부록, 뉴스룸 「품질보증」, E4).

### AI/최적화 기회와 이미 쓰이는 것
- **AI/최적화 기회와 이미 쓰이는 것**: 명장·마스터 지식으로 보완한 Inform Note 에이전트(GaiA 에이전트 글, 2025-10-31, E2 자사)가 이 선반이 모은 문서에서 찾은 사람의 지식을 쓰는 AI 사례이고, 「현재는 Inform Note 중심」이라는 단서가 붙는다. 숙련 매트릭스·교대 편성·안전 점검에 쓴 공개 적용 사례는 이 선반이 모은 문서에 없다(근거 없음). 편성은 제약 최적화(노선·배차·편성)로 푸는 유형이고 화면은 배정표 · 제약 위반 0건 배지(필자 설계).

### 6시간 최소 문제 — 상세
- **6시간 최소 문제**(추론): ① 숙련 매트릭스(사람 × 장비 자격) + 교대표 → 교대별 「이 장비를 다룰 사람이 0~1명」 공백 탐지 → 교차훈련 우선순위(공백 위험 × 장비 중요도). ② 명장 조치 기록 검색 + 「이 조치를 아는 사람」 연결 — 지식 검색에 사람 지도를 붙인 꼴. ③ 점검·교육 이수 누락 탐지와 알림 초안. ③의 해법 틀·화면(필자 설계): 점검 누락·초과 탐지 + 교육 미이수 대상 자동 목록 + 안내문 생성 / 구역 지도 신호등 · 미이수 명단 · 일괄 알림 초안.
