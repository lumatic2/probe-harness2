## 핵심 개념어
정의는 필자 요약이고, ★ 는 출처를 열어 확인하지 못한 통념이다.
- **WIP**(★): Work In Process. 공정 중 재공 물량.
- **사이클 타임 / TAT**(★): 투입부터 완료까지 걸린 시간.
- **대기시간**(★): 로트가 다음 공정을 기다린 시간. 평균과 p90 을 같이 본다.
- **디스패칭**(★): 다음에 어느 로트를 어느 장비에 넣을지 정하는 규칙·시스템.
- **Hold / Release**(★): 의심 로트를 멈춤 / 판정 후 다시 흘림.
- **SEMI E10 장비 상태**: 생산·대기·엔지니어링·계획정지·비계획정지·비스케줄 6상태. 표준 본문이 유료라 요약 기준이다.
- **PM**(★) / **BM**(★): 고장 전 계획 정비 / 고장 후 수리. 가동률 분모에서 따로 센다.
- **MTBF** · **MTTR**: 고장 사이 평균 정상 가동 시간 · 평균 수리 시간.
- **가동률**(★): 가동 시간 ÷ 기준 시간. 분모(달력/계획) 정의를 반드시 확인한다.
- **OEE**: 설비종합효율 = 가용성 × 성능 × 품질.
- **챔버**(★): 장비 안 실제 처리가 일어나는 방. 장비 하나에 여럿.

## 관점 쌍
- **흐름 ↔ 설비**: 사이클타임 원인 1위가 장비 고장·정지다(응답 50건, 자기 선택 표본). 디스패칭보다 어느 장비의 정지가 대기를 만드는지를 먼저 본다([01](01-흐름-생산.md), 추론).
- **총가용도 ↔ 도착 시 장비 유무**: 원문은 총가용도보다 로트가 도착했을 때 장비가 없을 확률을 줄이라고 권한다([02](02-설비.md)).
- **정비 ↔ 생산 ↔ 재무**: 같은 「가용도」도 쓰는 쪽에 따라 분모가 다르다([02](02-설비.md)).
- **수율을 위한 Q-time ↔ 흐름의 불안정**: 걸수록 재처리로 앞 장비 도착률이 오른다([01](01-흐름-생산.md)).
- **평균 최적 ↔ 강건**: 수요 시나리오가 갈릴 때 두 투입 계획을 나란히 놓는다([03](03-공급망-계획.md), 강건·시나리오 계획).

## 흔한 함정
- 1위 원인이 설비 정지인데 디스패칭 규칙부터 손댄다([01](01-흐름-생산.md)).
- 자기 선택 표본의 건수를 비율로 말한다([01](01-흐름-생산.md)).
- 예시 수치(병목 가동률 80.1%·84%·87%, 완충 15%)를 하이닉스 목표로 쓴다. 필자도 과장 가능성을 단서로 달았고 완충은 대수가 있는 장비군 기준이다([01](01-흐름-생산.md)).
- 가용도를 한 숫자로 말하고 정의를 밝히지 않는다([02](02-설비.md)).
- 램프 5일 전 85% 예측 같은 판매사 단일 사례를 PdM 효과로 말한다([02](02-설비.md)).
- 판매사의 가상 수치를 절감액으로 옮긴다([03](03-공급망-계획.md)).
