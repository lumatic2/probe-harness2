# 구조화 교대 인계 — I-PASS / SBAR

> [인간공학](README.md) › 03 · 짝 기법: [출력을 타입으로 묶기](../../../methods/LLM-응용-설계/02-출력을-타입으로-묶기.md) · [근거를 붙여 답하기](../../../methods/LLM-응용-설계/01-근거를-붙여-답하기.md) · [평가 세트와 가드레일](../../../methods/LLM-응용-설계/03-평가-세트와-가드레일.md)
> 원 분야 사실에는 근거 등급을 달았고, 반도체로 옮긴 부분은 별도 표시가 없으면 **추론**이다. 모듈 주의는 [모듈 README](README.md), 표기는 [입구](../../README.md) 「표기」.

## 바로 쓰는 칸
- **쓸 점**: 교대 인계서를 I-PASS 5칸 틀로 자동 초안하고 필수 항목이 빠진 인계서를 표시한다.
- **필요한 데이터**: state_change.csv(ts, eqp_id, from, to), alarm.csv, action_note.csv(ts, eqp_id, text), shift.csv(start, end, crew). 교대 경계가 없으면 못 쓴다.
- **6시간 최소 형태**: 교대 경계 직전 12시간 사건 요약 → 장비별 I-PASS 5칸 → 빈 칸 경고. 화면: 장비 목록(중증도 색) + 5칸 카드 + 받는 사람 확인 버튼.
- **반문 하나**: 「인계에 시간이 더 든다」 → 다기관 연구에서 구두 인계 시간은 2.4분 대 2.5분으로 차이 없었다(단, 의료 사례).
- **하지 말 것**: 의료 효과 크기(23%)는 의료 수치이므로 팹 효과로 말하지 않는다. I-PASS 다섯 글자 풀이는 미확인이다.

## 상세

**한 줄**: 「의료에서는 교대할 때 환자 정보가 새어 의료 오류가 나는 문제를 풀 때 I-PASS 같은 구조화 인계를 쓴다. 핵심 논리는 인계를 정해진 순서로 말과 글 모두 표준화하고, 훈련·관찰·유지 활동을 묶는다는 것이다. 「환자」를 장비·LOT 으로, 「레지던트 교대」를 4조 교대 장비 엔지니어·오퍼레이터 인계로 바꿔 대입하면 교대 인계 누락 문제에 적용된다. 지금 방식(자유 형식 인계 메모)과 비교해 「인계 직후 n시간 안에 생긴, 인계에 있었어야 할 사건 수」와 「필수 항목 포함률」로 개선을 보일 수 있다.」
- **과제 문구 신호**(추론): 「교대」「인계」「4조 교대」「인계서」「다음 조에 넘기기」「지식 이전」
- **가정 변환**

| 원 분야 | 반도체 |
|---|---|
| 환자 중증도(Illness severity) | 장비 상태(DOWN/ENG/주의 관찰), 홀드 LOT |
| 환자 요약 | 장비 최근 이력·진행 중 조치 |
| 할 일 목록(Action list) | 대기 중 부품, 재측정 대기 LOT, 다음 PM |
| 상황 인식·대비(만약 ~면 ~한다) | "압력이 다시 튀면 홀드하고 ○○에게 연락" |
| 받는 사람 되읽기(Synthesis) | 다음 조가 요약을 다시 말해 확인 |

- **원 분야 사실과 효과**(초록 기준, 소아 레지던트 교대 인계 9개 병원):
  - 개입 = 말·글 인계를 표준화하는 기억 장치(mnemonic), 인계·소통 훈련, 지도교수 관찰 프로그램, 유지 캠페인. 결과(10,740 입원): 의료 오류 24.5 → 18.8 /100 입원(23% 감소, P<0.001), 예방 가능한 위해 4.7 → 3.3(30% 감소).
  - **반론에 쓸 사실**: 구두 인계 시간은 환자당 2.4분 → 2.5분으로 유의한 변화 없음(P=0.55), 환자·가족 접촉 시간과 컴퓨터 시간 등 업무 흐름도 변화 없음.
  - **단서**: 9곳 중 6곳에서만 유의한 감소, 예방 불가능한 위해는 변화 없음. I-PASS 다섯 글자의 풀이(중증도·환자 요약·할 일·상황 인식과 대비·받는 사람의 종합)는 초록에 없어 원문으로 확인하지 않았다(**미확인** — 위 변환표의 칸 이름은 이 통설 풀이를 따른 것).
  - SBAR(상황·배경·평가·권고)도 같은 계열의 더 짧은 틀로 알려져 있으나 원문 확인 안 함(**미확인**).
- **하이닉스 적용 예**(추론): (a) 교대 인계서 자동 초안: 지난 12시간 MES 상태 변화·알람·조치 기록에서 I-PASS 틀로 초안을 만들고 사람이 '만약 ~면' 칸을 채운다. (b) 인계 품질 점검: 필수 항목 빠진 인계서 표시.
- **기준선과 지표**: 필수 항목 포함률, 인계 후 4시간 안 "인계에 없던 기존 문제" 재발견 건수, 인계 작성 시간(늘지 않았는지 — 의료 연구 근거가 이 칸을 받쳐 준다).
- **6시간 최소 형태**: 데이터 `state_change.csv(ts, eqp_id, from, to)`, `alarm.csv`, `action_note.csv(ts, eqp_id, text, author)`, `shift.csv(shift_id, start, end, crew)`. 계산: 교대 경계 기준 직전 12시간 사건 요약 → 장비별 I-PASS 5칸 채우기 → 빈 칸 경고. 화면: 장비 목록(중증도 색) + 장비별 5칸 카드 + "받는 사람 확인" 버튼 + 근거 기록 링크.
- **반론과 답**: "인계에 시간이 더 든다" → 다기관 연구에서 구두 인계 시간은 2.4분 대 2.5분으로 차이 없었다(단, 의료 사례다). "의료와 팹은 다르다" → 옮기는 건 '틀과 되읽기'이지 의료 내용이 아니다. **효과 크기(23%)는 의료 수치이므로 팹 효과로 말하지 않는다.**
