# 경제학 — 학문 지도

> [입구](../README.md) › **경제학**
> 희소한 자원을 두고 사람과 조직이 자기 이익대로 어떻게 고르는지 보는 학문이다. 경영과학(W)이 「최적해는 무엇인가」를 푼다면, 경제학은 「각 부서가 그 해를 정직하게 신고하고 따르게 하려면 규칙을 어떻게 짜나」와 「바꾼 뒤 정말 좋아졌다고 어떻게 증명하나」를 푼다(추론).

## 하위 분야 지도
15갈래 전체다. 챕터가 없는 행(—)은 지도용이며 정의는 교과 일반이라 출처를 달지 않았다(추론). 반도체 연결 칸은 모두 추론이다. 갈래 이름 옆 → 는 다른 학문의 챕터로 이어진다.

## 옆 학문으로
- 경영과학 기법(최적화·대기행렬·시뮬레이션) → `harness/methods/` 기법 18개. 경제학 카드는 판정 기준과 규칙 설계를 얹는다.
- 원가·투자·재고 가격 → 경영학 › 재무관리, 회계학 › 원가관리회계
- 공급 위험·집중도(HHI) → 경영학 › 생산운영관리
- 사람이 AI 를 안 쓰는 이유 → 경영학 › 조직행동
- 알람·교대 인계·화면 설계 → 공학 › 인간공학
