# 인과추론과 실험 — 학문 지도

> [입구](../../README.md) › [경제학](../README.md) › **인과추론과 실험** · 챕터 3
> 한 줄: **계량경제학·인과추론**은 관찰 데이터에서 원인과 결과를 가려내고, **실험경제학**은 통제된 실험으로 효과를 잰다. 둘 다 「그게 없었다면 어땠을까」를 어떻게 보이느냐의 문제다.
> **주의**: 반도체 팹에서 DID·합성통제·스위치백으로 운영 변경이나 AI 도입 효과를 잰 공개 현장 연구는 **근거 없음**이다. 이번에 한 표면(검색)만 봤으므로 「없다」가 아니라 「못 찾음」이다. 챕터의 원 분야 수치(예: 상담원 14%·34%)는 그 연구의 값이며 하이닉스 효과의 예측이 아니다. 초록 기준 항목은 본문의 조건·한계 절을 보지 않았다. 리허설·데모 수치를 효과 근거로 쓰지 않는다. 데모는 방법을 보여 주는 것이고 효과 크기는 현장 데이터로 다시 잰다.

## 핵심 질문
**「AI 를 쓴 뒤 좋아졌다」가 아니라 「AI 가 없었다면 어땠을지와 비교해 좋아졌다」를 어떻게 보이나?**

## 이럴 때 꺼낸다 / 옆 모듈로
- **꺼낸다**: 「AI 효과를 어떻게 증명하나」 질문이 나올 때 · 일부 라인·장비에 먼저 적용했을 때 · 누구에게 먼저 줄지 정할 때.
- **옆 모듈로**
  - 규칙을 설계해 부서가 정직하게 움직이게 하기(우선순위 가격·경매·매칭) → [메커니즘 디자인](../메커니즘-디자인/README.md)
  - 알고리즘 회피·숙련 격차 압축을 제출물의 서사로 → 경제학 › 사람과 기술 (다른 모듈)
  - 효과를 원화로 바꾸기 → 회계학 › [원가관리회계](../../회계학/원가관리회계/README.md)
  - 민감도·부트스트랩·몬테카를로 → 경영과학 민감도 분석 · 몬테카를로, 디스패칭 시뮬레이션·대기열 → 디스패칭 규칙 시뮬레이션 · 대기행렬과 운영 곡선

## 핵심 개념어
- **반사실**: 처리를 안 받았다면 어땠을지. 직접 못 보니 비교군으로 대신한다.
- **비교군**: 처리를 받지 않았지만 처리군과 비슷한 대상.
- **평행 추세**: 처리 전에 두 그룹 지표가 비슷하게 움직였는지. 이벤트 스터디 그래프의 도입 전 구간으로 본다.
- **간섭**: 한 쪽 처리가 다른 쪽 결과에 새는 것. 같은 대기열을 쓰면 생긴다.
- **잔류 효과**: 처리가 끝난 뒤에도 결과에 영향을 미치는 시간.
- **위약 검정**: 처리받지 않은 단위에 가짜 처리를 줘 보고 진짜 효과가 그 분포 안에서 어디인지 본다.
- **이질적 효과**: 평균이 아니라 누구에게 얼마나였는지.

## 관점 쌍
- **실험 ↔ 준실험**: 무작위로 나눠 돌려야 믿을 수 있다 ↔ 팹은 무작위 배정이 어려우니 시차 도입·한 라인 시범 같은 자연 실험을 쓴다(노벨 2021 해설).
- **평균 효과 ↔ 이질적 효과**: 평균 몇 % 좋아졌나 ↔ 누구에게·어디에서 효과가 있었나. 상담원 연구는 신입·저숙련 34%, 숙련자는 미미하다고 적는다([03](03-숙련도별-효과-차이.md)).
- **한 번의 회귀 ↔ 그룹·시점별 추정**: 시차 도입을 이원 고정효과 한 번으로 돌리면 효과가 변할 때 치우친다 ↔ 그룹·시점별로 나눠 모은다([01](01-시차-도입-이중차분.md)).

## 이 분야 사람이 먼저 묻는 것 5
1. 그게 없었다면 어땠을까(반사실)? 비교군은 공정한가?
2. 무작위로 나눴나? 못 나눴다면 도입 전 추세가 평행했나?
3. 한쪽 처리가 다른 쪽으로 새지 않나(간섭)?
4. 권고를 받은 사람이 다 따랐나? 숫자가 누구에게 적용되나?
5. 평균이 아니라 누구에게 효과가 있었나? 신뢰구간은 얼마나 넓나?

## 흔한 함정
- 시차 도입을 한 번의 회귀(이원 고정효과)로 돌린다. 효과가 시간에 따라 변하면 치우친다(Goodman-Bacon)([01](01-시차-도입-이중차분.md)).
- 상담원 14%·34% 같은 원 분야 수치를 하이닉스 효과처럼 말한다([03](03-숙련도별-효과-차이.md)).
- 리허설·데모 수치를 효과 근거로 쓴다.
