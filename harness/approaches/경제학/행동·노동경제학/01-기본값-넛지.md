# 기본값 넛지

> [행동·노동경제학](README.md) › 01 · 짝 기법: (없음)
> 원 분야 사실에는 근거 등급을 달았고, 반도체로 옮긴 부분은 별도 표시가 없으면 **추론**이다. 모듈 주의는 [모듈 README](README.md), 표기는 [입구](../../README.md) 「표기」.

## 바로 쓰는 칸
- **쓸 점**: 경보 후 기본 동작·승인 양식의 기본 선택(자동 홀드, 인계 확인 안 하면 잠김)을 화면 설계 원칙으로만 쓴다. (추론)
- **필요한 데이터**: 별도 데이터 없이 원칙으로만 쓴다. 「위험 쪽 선택 비율」을 말하려면 기본값 전후의 선택 기록이 있어야 한다.
- **6시간 최소 형태**: 독립 앱이 아니다 — 화면 기본값 결정을 서술형 답에서 한 줄로 설명한다. 보이려면 「기본값이 바뀐 뒤 위험 쪽 선택 비율」 한 숫자.
- **반문 하나**: "자동 홀드가 늘면 가동률이 떨어진다" → 그래서 기본값을 일괄이 아니라 위험도별로 다르게 둔다.
- **하지 말 것**: 정량 효과 말하기 — 재현성 반론이 있고 나라별 구체 수치는 원문을 열지 않아 쓰지 않는다(미확인).

## 상세

**한 줄**: 「행동경제학·공공정책에서는 사람이 선택을 미루거나 바꾸지 않는 문제를 풀 때 기본값(default)을 설계한다. 핵심 논리는 미리 정해진 선택지를 사람은 잘 바꾸지 않으므로, 안전하고 바람직한 쪽을 기본값으로 둔다는 것이다. 「장기 기증 동의 기본값」을 경보 후 장비 상태 기본값(자동 홀드 vs 계속 진행)·레시피 변경 승인 양식의 기본 선택으로 바꿔 대입하면 현장 시스템 화면의 기본 선택 설계 문제에 적용된다. 지금 방식(기본값 = 계속 진행)과 비교해 「기본값이 바뀐 뒤 위험 쪽 선택 비율」로 개선을 보일 수 있다.」
- **과제 문구 신호**(추론): 「화면의 기본 선택」「승인 양식」「자동 홀드」「인계 확인 안 하면 잠김」
- **가정 변환**

| 원 분야 | 반도체 |
|---|---|
| 동의 기본값 | 경보 후 기본 동작, 승인 양식 기본 선택 |
| 선택을 바꾸는 수고 | 클릭 수·사유 입력 |

- **원 분야 사실**(초록 기준): 기본값이 선호에 큰 차이를 만들며, 자연 자료와 실험 자료로 기본값이 기증 동의율을 크게 올림을 보였다. 나라별 구체 수치는 원문을 열지 않아 쓰지 않는다(**미확인**). **반대 근거 신호**: 검색 결과에 "기본값 효과 연구 상당수가 충분한 표본으로 재현되지 않았고, 장기 기증 시나리오 재현에서 효과를 못 찾았다"는 재현 연구가 보였다(Meta-Psychology — **원문 미확인, 검색 요약 기준**).
- **하이닉스 적용 예**(추론): [알람 관리](../../공학/인간공학/01-알람-관리.md)·[구조화 교대 인계](../../공학/인간공학/03-구조화-교대-인계.md) 화면 설계의 원칙으로만: "근거 없음일 때 기본은 홀드", "인계 확인 안 하면 다음 단계 잠김".
- **6시간 최소 형태**: 독립 앱 아님. 화면 기본값 결정을 서술형 답에서 한 줄로 설명.
- **반론과 답**: "자동 홀드가 늘면 가동률이 떨어진다" → 그래서 기본값을 일괄이 아니라 위험도별로 다르게 둔다([SLO와 오류 예산](../../공학/신뢰성공학/01-SLO와-오류-예산.md) 오류 예산과 연결). 재현성 반론이 있으므로 정량 효과는 말하지 않는다.
