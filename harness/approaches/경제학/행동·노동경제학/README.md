# 행동·노동경제학 — 학문 지도

> [입구](../../README.md) › [경제학](../README.md) › **행동·노동경제학** · 챕터 3
> 한 줄: **행동경제학**은 사람이 합리 모델에서 벗어나는 체계적 방식을, **노동경제학**은 일자리·숙련·임금이 기술에 따라 어떻게 바뀌는지를 본다.
> **주의**: 「사실」은 출처에 있는 말, 「추론」은 반도체에 옮겨 붙인 말이다(추론에는 등급 없음). **타 분야 효과 크기(1% 등)는 원 분야 수치이며 팹 효과의 예측이 아니다 — 제출물·서술형 답에서 이 숫자를 "하이닉스에서도 이만큼"으로 말하면 틀리다.** [01](01-기본값-넛지.md)·[02](02-손실-프레임-인센티브.md)는 6시간 안에 실험이 불가능해 우선순위가 낮다.

## 핵심 질문
**AI 가 엔지니어의 일을 대체하나 보완하나? 그리고 사람은 왜 더 나은 권고를 안 따르나?** (뒤의 절반은 경영학 › [조직행동](../../경영학/조직행동/README.md)에서 다룬다.)

## 이럴 때 꺼낸다 / 옆 모듈로
- **꺼낸다**: 신입에게 효과가 큰지 말해야 할 때 · 화면의 기본 선택을 설계할 때 · 포상 규칙의 프레임을 비교할 때.
- **옆 모듈로**
  - 사람이 AI 권고를 안 따르는 이유(알고리즘 회피) → 경영학 › [조직행동](../../경영학/조직행동/README.md)
  - 경력 구간별 효과를 재는 방법 → 경제학 › [인과추론과 실험](../인과추론과-실험/README.md) (경력별 효과는 [03](../인과추론과-실험/03-숙련도별-효과-차이.md))
  - KPI 가 행동을 왜곡하는 구조 → 경제학 › [인센티브와 정보 설계](../인센티브와-정보-설계/README.md)
  - 엔지니어 시간의 원화 단가 → 회계학 › [시간동인 활동기준원가](../../회계학/원가관리회계/04-시간동인-활동기준원가.md)

## 핵심 개념어
- **기본값(default)**: 선택하지 않으면 적용되는 값. 선호에 큰 차이를 만든다.
- **손실 회피**: 얻는 것보다 잃는 것을 더 크게 느낀다.
- **알고리즘 회피**: 알고리즘이 더 정확해도 한 번 틀린 뒤에는 사람보다 먼저 버리는 현상.
- **이질적 효과**: 같은 기술이 사람·장비마다 다른 크기로 나타나는 효과.

## 관점 쌍
- **알고리즘이 더 정확하다 ↔ 사람이 더 믿음직하다**: 정확도 비교와, 같은 실수에 대한 신뢰 하락 속도(조직행동 모듈).
- **평균 효과 ↔ 이질적 효과**: 평균 몇 % 좋아졌나와, 누구에게 효과가 컸나([03](03-숙련-격차-압축.md)).

## 이 분야 사람이 먼저 묻는 것 5
1. 사람은 실제로 어떻게 고르나? 기본값·프레임이 결과를 바꾸나?
2. 기술이 사람을 대체하나, 보완하나? 누가 득을 보나?
3. 이 직무를 과업으로 쪼개면 어느 칸이 AI 몫인가? (추론)
4. 효과는 평균인가, 숙련도별로 나눠 봤나? (추론)
5. 원 연구의 효과 크기가 우리 현장에 그대로 옮겨지나? (추론)

## 흔한 함정
- 권고 정확도만 보여 주고 틀렸을 때 어떻게 보이는지를 설계하지 않는다(조직행동 모듈).
- 상담원 14%·34% 같은 원 분야 수치를 하이닉스 효과처럼 말한다. 학술지판 수치도 미확인이다([03](03-숙련-격차-압축.md)).
- 손실 프레임의 약 1% 를 크게 말하거나 재현성 반론을 빼고 기본값 효과를 말한다([01](01-기본값-넛지.md), [02](02-손실-프레임-인센티브.md)).
