> 한 줄: **계약이론**은 무엇을 재서 보상하느냐가 행동을 바꾼다고 보고, **정보경제학**은 누가 무엇을 알고 어떻게 드러내느냐를 본다. 사람과 부서가 자기 이익대로 움직인다는 것을 모델 안에 넣는 분야다.

## 핵심 질문
**무엇을 재고 무엇을 보여 주느냐가 사람의 행동을 바꾼다. 그렇다면 KPI·알람·대시보드를 어떻게 설계해야 부서들이 같은 방향으로 움직이나?**

## 핵심 개념어
- **다중과업**: 일이 여러 가지인데 일부만 재기 쉬운 상태. 재기 쉬운 쪽으로 힘이 쏠린다.
- **정보성 원리**: 보상을 노력에 대해 정보를 주는 모든 지표에 건다.
- **상대평가**: 같은 충격을 받는 비교 대상 대비 성과로 운을 걷어 낸다.
- **정보 설계**: 상대에게 무엇을 어떤 규칙으로 드러낼지 미리 정하는 일. 원본을 숨기는 것이 아니다.

## 관점 쌍
- **강한 성과급 ↔ 균형 잡힌 약한 유인**: 재는 것에 보상하면 좋아진다는 말과, 재기 쉬운 일에만 힘이 쏠리니 약하게 걸어야 한다는 말([01](01-다중과업-인센티브.md)).
- **많이 보여 주기 ↔ 골라서 보여 주기**: 데이터는 다 보여 줄수록 좋다는 말과, 행동을 바꾸는 것은 신호의 설계라는 말([03](03-정보-설계-알람과-대시보드.md)).

## 이 분야 사람이 먼저 묻는 것 5
1. 무엇을 재서 보상하나? 재지 못하는 일은 어떻게 되나?
2. 새 KPI 가 무엇을 소홀하게 만드나? (추론)
3. 누가 무엇을 알고 있고, 그걸 드러낼 유인이 있나?
4. 비교 대상이 같은 충격을 받는 같은 조건인가? (추론)
5. 이건 안에서 할 일인가, 밖에 맡길 일인가?

## 흔한 함정
- KPI 대시보드를 만들면서 새 KPI 가 무엇을 소홀하게 만들지 묻지 않는다([01](01-다중과업-인센티브.md)). 안전·보고 지표에는 보상을 걸지 않는다. 숨기게 만든다.
- 정보 설계를 「불리한 정보 숨기기」로 오해받는다. 원본은 늘 열람 가능하고 기본 화면의 순서·요약만 설계한다고 말한다([03](03-정보-설계-알람과-대시보드.md)).
- 원 분야 수치(예측시장 25%)를 하이닉스 효과처럼 말한다.
