# 8D 와 A3 — 여러 부서에 걸친 문제를 한 장에 모으는 양식

> [생산운영관리](README.md) › 03 · 짝 기법: [몬테카를로](../../../methods/확률과-시뮬레이션/03-몬테카를로.md) · [기대손실 결정표](../../../methods/의사결정분석/01-기대손실-결정표.md) · [공정능력](../../../methods/품질과-신뢰성-통계/03-공정능력.md) / [파레토 프런티어](../../../methods/최적화/04-파레토-프런티어.md) · [민감도 분석](../../../methods/의사결정분석/02-민감도와-가정-바꿔-보기.md) · [질문을 파라미터로](../../../methods/최적화/05-질문을-파라미터로.md)
> 원 분야 사실에는 근거 등급을 달았고, 반도체로 옮긴 부분은 별도 표시가 없으면 **추론**이다. 모듈 주의는 [모듈 README](README.md), 표기는 [입구](../../README.md) 「표기」.

## 바로 쓰는 칸
- **쓸 점**: 여러 부서에 걸친 품질 문제(8D)와 부서 간 이견(A3)을 한 장 양식에 모은 초안을, 근거 없는 칸은 비워 둔 채 만든다(추론).
- **필요한 데이터**: 불량 로트·조치 기록(영향 로트 포함). A3 는 장비 시간 조정안·레시피 변경안 같은 대책 후보와 계산 결과. 없으면 칸을 못 채운다.
- **6시간 최소 형태**: 계산: 불량 로트·조치 기록 → D2·D3(영향 로트, 몬테카를로)·D4(원인 후보+검증 상태). 화면: 8D 초안 + 「미검증 원인」 경고(추론).
- **반문 하나**: 「양식 채우기 아닌가」 → LEI 도 「an “A3” is not a template」라고 경고한다. 빈칸은 빈칸으로 두고 「미검증」을 화면에 쓴다(추론).
- **하지 말 것**: 메모리 업계의 8D 사용(미확인)과 팹 적용 사례(근거 없음)를 있는 것처럼 말하기.

## 상세

### 8D — 고객 불만의 영구 시정

**한 줄**: 「품질경영에서는 고객 불만·품질 이탈의 재발을 원인이 바로 안 보이고 여러 부서에 걸친 상황에서 풀 때 8D(D0~D8)를 쓴다. 핵심 논리는 「임시 봉쇄(D3)와 영구 시정(D5~D6)을 나누고, 왜 그때 못 잡았는지까지 찾는다」다. 「자동차 부품 고객 불만」을 메모리 고객의 품질 클레임·출하 후 불량으로, 「팀」을 품질보증·공정·설비·양산관리로 바꾸면 QA 의 고객 대응 보고서 초안 도우미에 적용된다.」
- **과제 문구 신호**(추론): 「고객 불만」「재발 방지」「시정 조치」「품질 이슈 보고서」「CAPA」
- **가정 변환**: 자동차 부품 고객 불만 → 메모리 고객의 품질 클레임·출하 후 불량 / 팀 → 품질보증·공정·설비·양산관리.
- **원 분야 사실(E3)**:
  - ASQ 는 8D 가 「particularly suitable for situations in which a problem’s root cause is not apparent immediately, or when the problem affects multiple departments or functions」라고 하고, D4 에 「Also identify why the problem went unnoticed when it occurred.」를 넣는다.
  - 같은 페이지는 8D 가 원인 분석에, A3 는 지속 개선에 더 맞는다는 Quality Progress 글을 소개한다(2차 소개).
- **하이닉스 적용 예**(추론): QA 의 고객 대응 보고서 초안 도우미.
- **6시간 최소 형태**(추론): 불량 로트·조치 기록을 넣으면 D2(5W2H)·D3(봉쇄 범위 = 영향 로트)·D4(원인 후보 + 검증 상태) 칸을 채운 8D 초안과 「미검증 원인」 경고. 영향 범위 추정은 몬테카를로.
- **짝 기법**: [몬테카를로](../../../methods/확률과-시뮬레이션/03-몬테카를로.md)(영향 로트 수 분포) · [기대손실 결정표](../../../methods/의사결정분석/01-기대손실-결정표.md)(출하/재검/폐기) · [공정능력](../../../methods/품질과-신뢰성-통계/03-공정능력.md)
- **근거**: ASQ, Eight Disciplines 8D — https://asq.org/quality-resources/eight-disciplines-8d · 접근 2026-11-10 · **E3**(일반 HTTP 요청은 403 — 브라우저로 열어야 한다). 메모리 업계의 8D 양식 사용 여부: **미확인**. 반도체 팹 적용 공개 사례: **근거 없음**.

### A3 — 권한 다툼을 「무엇이 옳은가」 대화로

**한 줄**: 「린 경영에서는 부서 간 이해가 엇갈리는 개선안을 결정권이 한 사람에게 없는 상황에서 풀 때 A3 보고서(현상-원인-대책-실행-효과 확인을 한 장에)를 쓴다. 핵심 논리는 「사실을 한 장에 모아 권한 논쟁을 책임 대화로 바꾼다」다. 「토요타 개선 과제」를 생산-기술 장비 시간 조정안, 레시피 변경안으로 바꾸면 부서 회의 준비물 자동 작성에 적용된다.」
- **과제 문구 신호**(추론): 「보고서 자동 작성」「회의 자료」「부서 간 협의」「의사결정 근거 정리」
- **가정 변환**: 토요타 개선 과제 → 생산-기술 장비 시간 조정안, 레시피 변경안.
- **원 분야 사실(E3)**: LEI 는 A3 가 「debate about who owns what (an authority-focused debate)」에서 「dialogue around what is the right thing to do」로 옮겨 가게 돕는다고 쓴다. 또 A3 를 템플릿으로만 보는 것을 경계한다 — 「an “A3” is not a template」(원문 줄바꿈만 공백으로 합침).
- **하이닉스 적용 예**(추론): 부서 회의 준비물 자동 작성.
- **6시간 최소 형태**(추론): 질의 → LLM 이 A3 좌측(현상·목표·원인)을 데이터 근거와 함께 채우고, 우측(대책 후보)은 기법 계산 결과를 붙여 비교한다. 근거 없는 칸은 빈칸으로 남긴다. 생산-기술 장비 시간 조정안이면 [램프업 중 실험과 생산의 상충](01-램프업-실험과-생산의-상충.md)과 이어진다.
- **짝 기법**: [파레토 프런티어](../../../methods/최적화/04-파레토-프런티어.md)(두 부서 KPI 상충을 파레토로) · [민감도 분석](../../../methods/의사결정분석/02-민감도와-가정-바꿔-보기.md) · [질문을 파라미터로](../../../methods/최적화/05-질문을-파라미터로.md)
- **근거**: Lean Enterprise Institute, Lexicon: A3 Report — https://www.lean.org/lexicon-terms/a3-report/ · 접근 2026-11-10 · **E3**. 반도체 팹 적용 공개 사례: **근거 없음**.

### 두 양식 공통 주의
(추론) 양식 채우기로 줄이지 않는다. LEI 의 「an “A3” is not a template」가 그 경고다. 빈칸은 빈칸으로 남기고 「미검증」을 화면에 쓴다.
