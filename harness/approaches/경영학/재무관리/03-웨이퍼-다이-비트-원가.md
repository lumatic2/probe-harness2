# 웨이퍼 → 다이 → 비트당 원가와 수율 모델

> [재무관리](README.md) › 03 · 짝 기법: [민감도 분석](../../../methods/의사결정분석/02-민감도와-가정-바꿔-보기.md)
> 원 분야 사실에는 근거 등급을 달았고, 반도체로 옮긴 부분은 별도 표시가 없으면 **추론**이다. 모듈 주의는 [모듈 README](README.md), 표기는 [입구](../../README.md) 「표기」.

## 바로 쓰는 칸
- **쓸 점**: 수율 개선·적층 단수 변화를 「양품 다이당 원가 −○%」로 환산해, 어느 변수가 원가를 크게 움직이는지 보인다(추론).
- **필요한 데이터**: 웨이퍼 원가, 다이 면적, 결함 밀도 d0, 군집 계수 α, 적층 수 n. 다이 면적은 공개 안 됨 → 가정. 현장 d0·α 가 있으면 맞춰 넣는다.
- **6시간 최소 형태**: 계산: 음이항 수율식과 양품 다이당 원가 식(10줄). 화면: d0 슬라이더 → 수율·다이당 원가 곡선, 적층 n 별 스택 수율.
- **반문 하나**: 「실제 수율 모델은 훨씬 복잡하다」 → 맞다. 거친 모형이고, 현장 데이터가 있으면 α·d0 를 맞춰 넣는다.
- **하지 말 것**: 논문 예 조건의 수치(81.65% 등)와 웨이퍼 원가 추정치를 하이닉스 값처럼 말하기.

## 상세

**한 줄**: 「단위경제에서는 한 단위를 더 팔면 돈을 버는가를 단위의 정의가 여러 층인 상황에서 「단위당 원가·단위당 기여」로 쪼개 본다. 반도체에서는 「양품 다이당 원가 = 웨이퍼 원가 ÷ (웨이퍼당 다이 수 × 다이 수율)」이고, 수율은 결함 밀도와 다이 면적의 함수다. 결함 밀도 개선·다이 축소·적층 단수 변화를 이 식에 넣으면 어떤 개선이 비트당 원가를 얼마나 내리나로 보인다.」
- **과제 문구 신호**(추론): 「수율 개선의 효과」「비트당 원가」「적층 단수를 올리면」「결함 밀도」
- **가정 변환**: 웨이퍼 원가 = DART 공시와 생산능력 보도에 필자 가정을 얹은 값 (원가 기준 약 490만~580만원 추정, 근거 참조) · 다이 면적 = 세대별 다이 크기(공개 안 됨 → 가정) · 비트 = 다이 용량(Gb).
- **원 분야 사실(E2)**:
  - 「With the negative binomial formula for yield, a die yield of YD = (1 + A·d0/α)^−α = 81.65%」 — 300mm 웨이퍼, 가장자리 3mm, 결함 밀도 d0 = 0.5/cm², 군집 계수 α = 0.5, 다이 면적 50mm², 웨이퍼당 다이 1,278개 조건.
  - 적층하면 수율이 곱해진다(각 층 수율의 곱 — [품질원가(COQ)](../../회계학/원가관리회계/02-품질원가와-검사-흐름.md)).
  - 단위경제(고객 1명·주문 1건당 손익)의 일반 틀은 반도체에서 이미 공학 표준이다.
- **하이닉스 적용 예**(추론): (a) 수율 개선 과제의 효과를 「양품 다이당 원가 −○%」로(유형 ③). (b) HBM 적층 단수를 올릴 때 스택 수율과 원가(유형 ⑦).
- **기준선과 지표**: 양품 다이당 원가, 비트당 원가, 결함 밀도 0.1 개선당 원가 변화.
- **6시간 최소 형태**: 데이터 = 웨이퍼 원가, 다이 면적, d0, α, 적층 n. 계산 = 위 식(10줄). 화면 = d0 슬라이더 → 수율·다이당 원가 곡선, n 별 스택 수율.
- **반론과 답**: 「실제 수율 모델은 훨씬 복잡하다」 → 맞다. 이 식은 어느 변수가 원가를 크게 움직이나를 보여 주는 거친 모형이고, 현장 데이터가 있으면 α·d0 를 맞춰 넣는다. 수율 모델의 평가 논문(Cunningham 1990, *IEEE TSM*)이 있다(메타만 확인).
