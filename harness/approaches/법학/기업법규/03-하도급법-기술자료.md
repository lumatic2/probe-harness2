# 하도급법 기술자료 요구 절차 — 협력사 장비 데이터를 받을 때

> [기업법규](README.md) › 03 · 짝 기법: — (요청 양식 체크리스트라 계산이 없다)
> 원 분야 사실에는 근거 등급을 달았고, 반도체로 옮긴 부분은 별도 표시가 없으면 **추론**이다. 모듈 주의는 [모듈 README](README.md), 표기는 [입구](../../README.md) 「표기」.

## 바로 쓰는 칸
- **쓸 점**: 협력사 장비 데이터를 받을 때 기술자료 요구 절차(서면·권리귀속·대가·비밀유지계약)를 요청 워크플로로 만든다.
- **필요한 데이터**: 요청 양식의 필수 항목(목적·권리귀속·대가·보유 임직원 명단); 데이터가 협력사에 있을 때만 쓴다.
- **6시간 최소 형태**: 요청 양식 → 필수 항목 체크리스트(조문 번호) → 누락 시 제출 차단. 화면 = 요청 상태판.
- **반문 하나**: 「해커톤 주제와 거리가 멀다」 → 데이터가 협력사에 있을 때만 꺼내는 확장안의 법적 경로다.
- **하지 말 것**: 모든 장비사 거래를 하도급법 대상이라고 말하지 않는다 — 원사업자–수급사업자 해당 여부는 거래마다 다르다(추론).

## 상세

**한 줄**: 「공정거래법 분야에서는 원사업자가 협력사 기술을 빼앗는 문제를 막으려고 기술자료 요구 자체를 원칙적으로 금지하고, 예외일 때 서면·비밀유지계약을 요구한다. AI 예지보전을 위해 장비·부품 협력사의 장비 로그·설계 정보를 받아야 할 때 이 절차를 요청 워크플로로 만들면 법을 지키는 데이터 수집 흐름에 적용된다.」
- **과제 문구 신호**(추론): 「협력사 데이터」「장비사 로그」「예지보전에 협력사 설계 정보」「데이터 요청서」
- **법 원문(E1, 하도급법 제12조의3, 2026-10-02 시행본)**: ① 「원사업자는 수급사업자의 기술자료를 본인 또는 제3자에게 제공하도록 요구하여서는 아니 된다. 다만, 원사업자가 정당한 사유를 입증한 경우에는 요구할 수 있다.」 ② 요구목적·권리귀속·대가 등을 미리 협의해 서면으로 줄 것. ③ 「… 기술자료를 제공받는 날까지 … 비밀유지계약을 수급사업자와 체결하여야 한다.」 ④ 부당 사용·제3자 제공 금지.
- **조건(추론)**: 하이닉스와 장비사의 거래가 하도급법의 「원사업자–수급사업자」 관계인지는 거래마다 다르다(제조위탁 여부·규모 요건). 장비 구매는 일반 매매일 수 있다. 그래서 도구는 「해당 여부 판단 체크 → 해당이면 서면·NDA 체크」 두 단계로 둔다.
- **하이닉스 적용 예**(추론): PdM 모델 학습용 협력사 데이터 요청서 자동 작성 + 필수 항목(목적·권리귀속·대가·보유 임직원 명단) 누락 검사(유형 ⑤⑧).
- **6시간 최소 형태**: 요청 양식 → 필수 항목 체크리스트(조문 번호 붙임) → 누락 시 제출 차단. 화면 = 요청 상태판.
- **반론과 답**: 「해커톤 주제와 거리가 멀다」 → 데이터가 협력사에 있을 때만 꺼낸다. 장비 보전 과제에서 「협력사 데이터까지 쓰면 더 좋아진다」는 확장안을 낼 때 법적 경로까지 그려 둔 팀이 된다.
