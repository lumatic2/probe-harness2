# 자본적·수익적 지출 분류 — PM·부품 교체 기록을 세무 분류로

> [세법](README.md) › 02 · 짝 기법: [신뢰성과 보전 주기](../../../methods/품질과-신뢰성-통계/02-신뢰성과-보전-주기.md) · [다기준 의사결정](../../../methods/의사결정분석/03-다기준-의사결정.md)
> 원 분야 사실에는 근거 등급을 달았고, 반도체로 옮긴 부분은 별도 표시가 없으면 **추론**이다. 모듈 주의는 [모듈 README](README.md), 표기는 [입구](../../README.md) 「표기」.

## 바로 쓰는 칸
- **쓸 점**: PM 작업 지시를 자본적/수익적 다섯 칸으로 자동 분류하고 애매한 건만 사람 판단 큐로 올린다.
- **필요한 데이터**: PM 기록 CSV(작업 코드·교체 부품·금액·주기)와 장비별 미상각 잔액; 금액·주기가 없으면 못 쓴다.
- **6시간 최소 형태**: 계산 = 규칙 엔진 + LLM 보조 분류(조문 호수 근거 표시). 화면 = 장비별 분류 비율 + 「사람 판단」 큐.
- **반문 하나**: 「세무팀 일이지 현장 일이 아니다」 → 분류에 필요한 사실(주기·개조 여부)은 현장 기록에만 있다(추론).
- **하지 말 것**: 법령 금액 기준을 회사의 자본화 정책으로 말하지 않는다 — 실제 회계 정책은 미확인이다.

## 상세

**한 줄**: 「법인세법에서는 수선비를 자산으로 올릴지 비용으로 떨어낼지를 같은 설비에 크고 작은 수리가 반복되는 상황에서 풀 때 자본적 지출 판정(내용연수 연장·가치 증가)과 소액·주기 수선 예외를 쓴다. 「건물·기계 수선」을 PM·부품 교체·챔버 개조·업그레이드 키트 기록으로, 「개별자산」을 장비(툴) 단위 자산번호로 바꾸면 PM 작업 지시서에서 세무 분류를 자동으로 붙이고 판정이 애매한 건만 사람에게 올리는 문제에 적용된다.」
- **과제 문구 신호**(추론): 「PM 이력」「부품 교체 기록」「정비 비용」「작업 지시서 분류」「업그레이드 키트」
- **가정 변환**

| 원 분야 | 반도체 현장 |
|---|---|
| 수선비 지출 건 | PM 작업 지시(작업 코드·교체 부품·금액) |
| 3년 미만 주기 수선 | PM 주기표(일·주·월·분기 PM) |
| 가치 증가 | 업그레이드 키트, 레시피 성능 향상 개조 |
| 장부가액 5% | 장비별 미상각 잔액 |

- **원 분야 사실(E1)**:
  - 자본적 지출은 「법인이 소유하는 감가상각자산의 내용연수를 연장시키거나 해당 자산의 가치를 현실적으로 증가시키기 위하여 지출한 수선비」다.
  - 예시로 「본래의 용도를 변경하기 위한 개조」「그 밖에 개량ㆍ확장ㆍ증설 등」을 든다.
  - 손비로 계상했을 때 자본적 지출로 보지 않는 세 경우: 「1. 개별자산별로 수선비로 지출한 금액이 600만원 미만인 경우」 「2. … 직전 사업연도종료일 현재 재무상태표상의 자산가액 … 의 100분의 5에 미달하는 경우」 「3. 3년 미만의 기간마다 주기적인 수선을 위하여 지출하는 경우」(법인세법 시행령 제31조 ②③, 시행 2026-10-01판).
- **하이닉스 적용 예**(추론): PM 기록 CSV 의 각 행에 세무 분류를 붙인다. 「3년 미만 주기 수선」이라는 법 문구가 PM 주기표와 겹친다.
- **기준선과 지표**: 정해 둔 기준선이 없다(미확인). 지표(추론): 장비별 분류 비율, 「사람 판단」 큐의 크기.
- **6시간 최소 형태**: PM 기록 CSV → 행마다 `수익적(주기 PM)`·`수익적(600만원 미만)`·`수익적(5% 미만)`·`자본적 의심(개조·업그레이드)`·`사람 판단` 다섯 칸으로 나누는 규칙 엔진 + LLM 보조 분류(작업 문구 → 개조 여부). 판정마다 해당 조문 호수를 근거로 표시한다. 화면 한 장: 장비별 분류 비율과 「사람 판단」 큐.
- **반론과 답**: 「세무팀 일이지 현장 일이 아니다」 → 분류에 필요한 사실(주기·개조 여부)은 현장 기록에만 있다. 세무팀은 결산 때 그 사실을 다시 물으러 온다(추론). 경계: 금액 기준은 법령 값이고, 회사의 실제 자본화 정책(회계 기준)은 따로 있을 수 있다(**미확인**).
