# 경로 카드 — 숙련자 지식 보존·신입 교육

> [경로 카드 목록](경로-카드.md) · [입구](README.md). **전부 추론**이다 — `뼈대 — 계산` 줄은 후보이고, 과제의 동사와 데이터 모양이 다르면 그 부분은 직접 짠다. 뼈대 두 줄을 먼저 읽고, 렌즈 두 줄은 화면·방어를 짤 때 연다.

- **이런 과제 문장**: 「숙련자 노하우」「명장·마스터」「퇴직·은퇴 전에」「신입 교육」「암묵지」
- **필요한 데이터**: 기존 조치 기록(사건 후보를 미리 고를 원천) + 숙련자 인터뷰 답 — 조치 기록이 없으면 대조를 못 한다 / 없을 때: 숙련자 인터뷰는 팀원이 숙련자 역할로 시연한다
- **뼈대 — 계산**: 계산 뼈대 없음 — 렌즈가 본체다(렌즈 두 줄부터 읽는다). 사건 후보를 고를 때만 [근거를 붙여 답하기](../methods/LLM-응용-설계/01-근거를-붙여-답하기.md)(조치 기록 검색·근거 연결)
- **뼈대 — 현장 관점**: [사람·안전·숙련](반도체-현장/업무-유틸리티-사람/03-사람-안전-숙련.md) — 숙련 매트릭스 × 교대표로 「이 장비를 다룰 사람이 0~1명」인 교대를 찾는다
- **렌즈 — 판정 기준**: [핵심 결정 기법(CDM)](공학/인간공학/05-핵심-결정-기법.md) — 어려웠던 사건 하나를 탐침 질문으로 되짚어 판단 단서를 결정 요구표로 남긴다
- **렌즈 — 방어·설득**: [암묵지와 지식 전환](경영학/조직과-지식/02-암묵지와-지식-전환.md) · [TWI 작업지도](경영학/조직과-지식/03-TWI-작업지도.md) · [자동화의 역설](컴퓨터과학/자율성-설계/06-자동화의-역설과-신뢰-보정.md)
- **화면 한 장**: 왼쪽 대화, 오른쪽 자라나는 결정 요구표
- **지표 3**: 결정 요구표 수 · 신입 대상 사례 퀴즈 정답률(전후) · 같은 증상 MTTR
- **반문 하나**: 「엔지니어는 인터뷰할 시간이 없다」 → 사건 하나에 30분짜리 질문 흐름으로 줄이고, 조치 기록에서 사건 후보를 미리 골라 준다
- **어디까지 맡기나**: 판정 카드에 틀린 사례를 붙이고, 인계·온보딩 시간엔 연습 모드(자동화의 역설)
- **같이 꺼낼 카드**: [교대 인계·조마다 다른 대응](경로-카드-교대-인계-조마다-다른-대응.md)(「인계 누락」이 같이 있으면) · [AI 도입 효과](경로-카드-AI-도입-효과-확대와-현장-신뢰.md)(「신입에게 효과가 컸나」)
