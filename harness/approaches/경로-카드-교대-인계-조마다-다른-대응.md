# 경로 카드 — 교대 인계·조마다 다른 대응

> [경로 카드 목록](경로-카드.md) · [입구](README.md). **전부 추론**이다 — `뼈대 — 계산` 줄은 후보이고, 과제의 동사와 데이터 모양이 다르면 그 부분은 직접 짠다. 뼈대 두 줄을 먼저 읽고, 렌즈 두 줄은 화면·방어를 짤 때 연다.

- **이런 과제 문장**: 「교대 인계」「인계 때 빠지는 내용」「4조 교대」「다음 조에 넘기기」「같은 이상에도 조마다 대응이 다르다」
- **필요한 데이터**: 인계 일지(자유 텍스트)·조치 기록 `ts, eqp_id, text, author`·교대표 `shift_id, start, end, crew` — 교대 경계가 없으면 못 쓴다 / 없을 때: 상태 변화·알람 로그가 없으면 인계 일지와 조치 기록만으로 5칸을 채우고 빈 칸 경고까지만 한다(추론)
- **뼈대 — 계산**: [출력을 타입으로 묶기](../methods/LLM-응용-설계/02-출력을-타입으로-묶기.md)(인계 일지→I-PASS 5칸·빈 칸) → [근거를 붙여 답하기](../methods/LLM-응용-설계/01-근거를-붙여-답하기.md)(칸마다 근거 기록 인용) → [평가 세트와 가드레일](../methods/LLM-응용-설계/03-평가-세트와-가드레일.md)(5칸 추출 통과율)
- **뼈대 — 현장 관점**: [엔지니어 업무](반도체-현장/업무-유틸리티-사람/01-엔지니어-업무.md) — 알람→조치→기록·인계 흐름. 인계서 실제 양식은 공개 근거 없음(★)이라 현업에 묻는다
- **렌즈 — 판정 기준**: [구조화 교대 인계](공학/인간공학/03-구조화-교대-인계.md) — 필수 항목 포함률과 「인계 뒤 인계에 없던 기존 문제 재발견 건수」로 인계 품질을 잰다
- **렌즈 — 방어·설득**: [TWI 작업지도](경영학/조직과-지식/03-TWI-작업지도.md)(조마다 숙련 차이가 있는 SOP 한 건)
- **화면 한 장**: 장비 목록(중증도 색) + 장비별 5칸 카드 + 「받는 사람 확인」 버튼 + 근거 기록 링크
- **지표 3**: 필수 항목 포함률(조별) · 인계 후 4시간 안 「인계에 없던 기존 문제」 재발견 건수 · 인계 작성 시간
- **반문 하나**: 「인계에 시간이 더 든다」 → 다기관 연구에서 구두 인계 시간은 2.4분 대 2.5분으로 차이 없었다(단, 의료 사례)
- **어디까지 맡기나**: 5칸 초안은 AI, 「만약 ~면」 칸 채우기와 받는 사람 되읽기는 사람(추론)
- **같이 꺼낼 카드**: [정비 후 재고장·복귀 절차](경로-카드-정비-후-재고장-복귀-절차.md)(「정비 후 재고장」이 같이 있으면) · [숙련자 지식 보존·신입 교육](경로-카드-숙련자-지식-보존-신입-교육.md)(「퇴직」「노하우」)
