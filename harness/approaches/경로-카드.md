# 경로 카드 — 과제 유형 → 뼈대(계산·현장) + 렌즈(판정·방어)

> [입구](README.md) · 선반의 첫 길. 카드 하나가 「무엇을 계산하나(뼈대 — 계산)」「현장의 누구 눈으로 보나(뼈대 — 현장 관점)」「무엇을 기준으로 정하고 어떻게 방어하나(렌즈)」를 정한다.
> **전부 추론**이다. 유형 묶음과 뼈대·렌즈 선택은 필자 판단이고, 화면·지표·반문·데이터는 뼈대 기법 문서와 현장·렌즈 챕터의 「바로 쓰는 칸」·본문에서 옮겼다(새 사실·수치 없음). 원 분야 수치는 하이닉스 효과의 예측이 아니다.
> 목차의 ①~⑧ 은 기법·코드 선반 [`harness/methods/`](../methods/README.md) §1 과 입구 「표기」의 유형 번호다.
> `뼈대 — 계산` 줄은 **후보**다. 모의 과제로 시험했을 때 카드의 뼈대는 과제마다 절반쯤 맞았다 — 과제의 동사(찾아라·추천하라·보여 줘라)와 데이터 모양이 카드의 가정과 다르면 그 부분은 직접 짠다.

**목적이 여럿인 과제는 이렇게 읽는다**
1. 과제 문장에서 「줄여라·정해라·추천하라·알려 줘라」가 붙은 목적을 하나씩 뽑는다.
2. 목적마다 아래 표에서 카드 하나를 고른다.
3. 각 카드의 **뼈대 두 줄**(`뼈대 — 계산`·`뼈대 — 현장 관점`)만 먼저 읽는다. 렌즈 두 줄은 화면·방어를 짤 때 연다. `뼈대 — 계산` 줄은 **후보**다. 모의 과제로 시험했을 때 카드의 뼈대는 과제마다 절반쯤 맞았다 — 과제의 동사(찾아라·추천하라·보여 줘라)와 데이터 모양이 카드의 가정과 다르면 그 부분은 직접 짠다.
4. 목적이 둘이면 뼈대 계산을 잇는다 — 한 카드의 출력이 다른 카드의 입력이 되게 순서를 정한다.

| [투자·재고·가격](#투자재고가격) ⑦ | 「재고 목표」「재공품 수준」「재고 평가손실」 | 몬테카를로 → 민감도 |

목적이 하나인데 두 카드에 걸리면 과제의 **결정**(무엇을 정해 달라는가)에 맞는 카드의 뼈대를 쓰고, 다른 카드는 `같이 꺼낼 카드` 줄로 연다.

## 장비 이상·보전 조치
- **이런 과제 문장**: 「조치 기록 정리」「고장 모드」「재발 방지」「장비 보전 지식 도우미」「과거 조치 검색」「조치 이력」
- **필요한 데이터**: 조치 기록 `note_id, eqp_id, chamber, occurred_at, symptom_text, cause_text, action_text, downtime_min` — 조치 텍스트가 없으면 못 쓴다 / 없을 때: 알람 로그만 있으면 [엔지니어 업무](반도체-현장/업무-유틸리티-사람/01-엔지니어-업무.md)의 최소 문제 ②(같은 장비·시간창 묶기 → 사건 큐)로 간다
- **뼈대 — 계산**: [출력을 타입으로 묶기](../methods/LLM-응용-설계/02-출력을-타입으로-묶기.md)(조치 텍스트→고장 모드·S·O·D) → [근거를 붙여 답하기](../methods/LLM-응용-설계/01-근거를-붙여-답하기.md)(유사 조치·note_id 인용) → [평가 세트와 가드레일](../methods/LLM-응용-설계/03-평가-세트와-가드레일.md)(추출·인용 통과율)
- **뼈대 — 현장 관점**: [엔지니어 업무](반도체-현장/업무-유틸리티-사람/01-엔지니어-업무.md) — 증상 유사 검색 → 근거 note 인용 조치 카드 3장. 과제가 「과거 조치를 바로 찾게」뿐이면 이것이 본체다
- **렌즈 — 판정 기준**: [FMEA와 HAZOP](공학/안전공학/02-FMEA와-HAZOP.md) — 고장 모드별 S·O·D 로 RPN 을 매겨 「먼저 고칠 것」을 정한다
- **렌즈 — 방어·설득**: [행동별 자율성 단계표](컴퓨터과학/자율성-설계/01-행동별-자율성-단계표.md) · [장비 소유원가(COO)](회계학/원가관리회계/05-수명주기원가와-장비-소유원가.md)
- **화면 한 장**: RPN 정렬 표 + 각 칸 근거 note_id 링크 + 「점수 수정」 버튼
- **지표 3**: RPN 상위 10개 고장 모드의 재발 건수 · 평균 다운타임 · 검출도 나쁨(D 높음) 모드 수
- **반문 하나**: 「RPN 은 곱셈이라 심각도 10·발생 1 과 심각도 1·발생 10 이 같다」 → 심각도 상위는 RPN 과 따로 먼저 보여 준다
- **어디까지 맡기나**: 기록 추출·점수 초안은 AI, 점수 확정은 사람 — 「분석은 높게, 실행은 낮게」(행동별 자율성 단계표)
- **같이 꺼낼 카드**: [알람 판정·우선순위](#알람-판정우선순위)(「알람이 너무 많다」가 같이 있으면) · [정비 후 재고장·복귀 절차](#정비-후-재고장복귀-절차)(「PM 후 재발」「복귀 절차」가 같이 있으면)

## 정비 후 재고장·복귀 절차
- **이런 과제 문장**: 「정비 후 재고장」「PM 후 재발」「복귀 절차」「체크 누락」「체결 누락」「SOP 가 너무 길어 현장에서 안 본다」
- **필요한 데이터**: 정비 기록(정비 id·장비·종료 시각·체크 항목·체크 여부·소요 시간·작업자) + 고장 이력 `eqp_id, ts, cause_text` — 고장 시각이 없으면 라벨을 못 만든다 / 없을 때: 원인 텍스트가 없으면 항목별 근거는 못 대고 누락과 재고장의 겹침만 센다. 체크 시각이 없으면 순서는 못 보고 생략만 센다(추론)
- **뼈대 — 계산**: [사건 이력에서 라벨 만들기](../methods/판정-모델/01-사건-이력에서-라벨-만들기.md)(정비 종료→N시간 안 재고장 0/1) → [표준 경로 이탈](../methods/이벤트-로그-분석/02-표준-경로-이탈.md)(체크 항목 생략·순서) → [불균형일 때 맞았는지 재기](../methods/판정-모델/03-불균형일-때-맞았는지-재기.md)(위험 점수를 낼 때만)
- **뼈대 — 현장 관점**: [설비](반도체-현장/흐름-설비-계획/02-설비.md) — 재고장을 어느 상태 코드(DOWN)·정의로 세나, 복귀(RUN 전환)를 누가 정하나(장비 엔지니어)
- **렌즈 — 판정 기준**: [체크리스트](공학/인간공학/04-체크리스트.md) — 긴 SOP 대신 과거 재고장과 겹친 항목 5~9개만 복귀 전 멈춤 지점으로 남긴다
- **렌즈 — 방어·설득**: [통제 테스트](회계학/회계감사/04-통제-테스트.md)(허용 일탈률을 받았을 때만 판정)
- **화면 한 장**: PM 종류를 고르면 체크리스트 5~9항목 + 항목마다 「이 항목을 빠뜨려 생긴 과거 고장 n건」 근거
- **지표 3**: PM 후 24/72시간 재고장률 · 첫 LOT 스크랩 · 체크리스트 완료율
- **반문 하나**: 「이미 SOP 가 있다」 → SOP 는 길고, 체크리스트는 결정적 순간에 팀이 멈추게 하는 짧은 장치다
- **어디까지 맡기나**: 누락·재고장 연결과 항목 후보는 AI, 체크리스트 확정과 장비 복귀 승인은 사람(추론, [승인 게이트](컴퓨터과학/자율성-설계/02-가역성과-영향-크기로-나누는-승인-게이트.md))
- **같이 꺼낼 카드**: [SOP·규정 대조](#sop규정-대조)(「SOP 준수율」「누락률 판정」이 같이 있으면) · [교대 인계·조마다 다른 대응](#교대-인계조마다-다른-대응)(「인계 누락」이 같이 있으면) · [장비 이상·보전 조치](#장비-이상보전-조치)(「PM 주기」)

## 스케줄·Q-Time·디스패칭
- **이런 과제 문장**: 「일정을 짜라」「배정」「Q-Time 을 넘기지 않게」「위반 0건」「긴급 로트」「끼어든 로트」
- **필요한 데이터**: `lot, step, 장비 후보, 공정시간, PM 창, Q-Time 규칙` — 「무엇을 바꿀 수 있나」가 안 보이면 모형 이전의 범위 문제다 / 없을 때: 비는 칸은 현업 질문 목록으로 올린다. 현행 일정표가 없으면 최소 변경이 아니라 처음 짜는 일정이다
- **뼈대 — 계산**: [로트 이력 구간 대기](../methods/이벤트-로그-분석/01-로트-이력-구간-대기.md)(현행 위반 기준선) → [제약 프로그래밍 일정](../methods/최적화/01-제약-프로그래밍-일정.md)(위반 0 일정·검사기) → [최소 변경 재스케줄](../methods/최적화/03-최소-변경-재스케줄.md)(현행 일정이 있을 때만)
- **뼈대 — 현장 관점**: [흐름](반도체-현장/흐름-설비-계획/01-흐름-생산.md) — 대기·Q-Time·사이클타임, 평균과 p90 을 같이 본다
- **렌즈 — 판정 기준**: [결정변수·목적·제약](경영과학/모형으로-다시-쓰기/01-결정변수-목적-제약으로-다시-쓰기.md) — 과제 문장을 세 칸 표로 먼저 써야 솔버를 고를 수 있다
- **렌즈 — 방어·설득**: [하드 제약 대 벌점](경영과학/모형으로-다시-쓰기/03-깰-수-없는-규칙과-값을-매길-규칙.md) · [교란 뒤 최소 변경](경영과학/흐름과-변동으로-보기/04-교란-뒤-최소-변경.md) · [가정이 틀리면](경영과학/모형을-믿어도-되나/01-가정이-틀리면-민감도와-뒤집히는-경계.md)
- **화면 한 장**: 세 칸 표 + 장비별 간트 + 「검사기 위반 0건」 배지
- **지표 3**: 독립 검사기가 센 Q-Time 위반 건수 · 완료 시각 · 가중 지연
- **반문 하나**: 「모형이 현실을 너무 단순화한다」 → 단순화한 항목을 화면에 적고, 결론이 뒤집히는지는 민감도로 본다
- **어디까지 맡기나**: 「Q-Time 초과 배정 금지」를 실드 규칙으로 두고 AI 제안을 거른다(추론, [단순 감시기·안전 실드](컴퓨터과학/자율성-설계/05-단순-감시기-구조와-안전-실드.md))

## 수율·불량 판정과 영향 범위

- **뼈대 — 현장 관점**: [품질·수율](반도체-현장/품질-계측-후공정/01-품질-수율.md) — 영향 범위(같은 경로 로트 수), 수율은 단계·분모를 붙여 말한다
- **렌즈 — 판정 기준**: [관련원가와 증분분석](회계학/원가관리회계/01-관련원가와-증분분석.md) — 이미 들인 원가를 빼고 앞으로 달라지는 돈만으로 진행·재작업·폐기를 가른다
- **렌즈 — 방어·설득**: [품질원가와 검사 흐름](회계학/원가관리회계/02-품질원가와-검사-흐름.md) · [결합원가와 분리점](회계학/원가관리회계/03-결합원가와-분리점.md)
- **화면 한 장**: 로트별 「진행/재작업/폐기」 기대 손익 막대 + 매몰원가를 회색으로 따로 보여 주고 판정에서 뺐다고 표시
- **지표 3**: 판정별 기대 증분 손익 · 잘못 판정했을 때 손실(EVPI) · 판정이 뒤집히는 손익분기 확률
- **반문 하나**: 「진행 시 양품 확률을 어떻게 아나」 → 과거 위반 로트의 결과로 추정하고, 없으면 범위로 두고 손익분기 확률을 보인다
- **어디까지 맡기나**: 판정 비교는 AI, 되돌릴 수 없는 폐기는 사람 승인(추론, [승인 게이트](컴퓨터과학/자율성-설계/02-가역성과-영향-크기로-나누는-승인-게이트.md))
- **같이 꺼낼 카드**: [스케줄·Q-Time](#스케줄q-time디스패칭)(「다시 위반이 안 나게 일정을」이 같이 있으면)

## SOP·규정 대조
- **이런 과제 문장**: 「SOP 준수」「점검 누락」「PM 체크리스트 누락률」「서명 누락·순서 위반·기한 초과」
- **필요한 데이터**: `record_id, sop_step, signed, signed_at, due_at` + 품질·안전 부서가 정한 허용 일탈률 / 없을 때: 체크 항목 기록이면 체크 여부를 `signed` 로 읽고, 시각이 없으면 순서·기한은 빼고 누락만 센다(추론). 허용 일탈률이 없으면 판정은 못 하고 누락률과 95% 이항 상한만 보인다(추론)
- **뼈대 — 계산**: [표준 경로 이탈](../methods/이벤트-로그-분석/02-표준-경로-이탈.md)(단계 생략·순서 위반 전수) → [기대손실 결정표](../methods/의사결정분석/01-기대손실-결정표.md)(일탈을 위반 위험 비용으로 정렬)
- **뼈대 — 현장 관점**: [엔지니어 업무](반도체-현장/업무-유틸리티-사람/01-엔지니어-업무.md) — 점검·변경 기록이 실제로 어떤 칸으로 남나(열 이름은 `unique()` 로 확인)
- **렌즈 — 판정 기준**: [통제 테스트](회계학/회계감사/04-통제-테스트.md) — 「이 비율 넘게 어기면 통제를 믿지 않는다」를 품질·안전 부서에서 받아 기록으로 판정한다
- **렌즈 — 방어·설득**: [프로세스 마이닝](회계학/회계감사/02-프로세스-마이닝.md) · [체크리스트](공학/인간공학/04-체크리스트.md)
- **화면 한 장**: 통제별 일탈률 막대 + 허용선 + 일탈 기록 드릴다운
- **지표 3**: 표본 일탈률 · 신뢰수준 95% 이항 상한 · 「통제 신뢰/불신」 판정
- **반문 하나**: 「AI 로 전수 검사하면 표본이 왜 필요한가」 → 디지털 기록은 전수(프로세스 마이닝)로, 표본은 사람이 현장 확인할 실물 점검에만 남긴다
- **어디까지 맡기나**: 일탈 판정은 AI, 「통제 불신」 판정과 후속 조치는 사람(추론, [행동별 자율성 단계표](컴퓨터과학/자율성-설계/01-행동별-자율성-단계표.md))
- **같이 꺼낼 카드**: [정비 후 재고장·복귀 절차](#정비-후-재고장복귀-절차)(「PM 후 재고장」이 같이 있으면) · [안전·협력사·보안](#안전협력사보안)(「안전 의무」「교육 미이수」)

## 유틸리티·에너지 운전
- **이런 과제 문장**: 「냉동기·공조 운전 설정 추천」「온습도 허용 범위를 지키며」「전력비·요금표」「설정값 최적화」「에너지 절감」

- **렌즈 — 방어·설득**: [단순 감시기·안전 실드](컴퓨터과학/자율성-설계/05-단순-감시기-구조와-안전-실드.md) · [가정이 틀리면](경영과학/모형을-믿어도-되나/01-가정이-틀리면-민감도와-뒤집히는-경계.md)

- **반문 하나**: 「냉동기를 줄이면 청정도·온습도는 누가 보장하나요?」 → 허용 범위는 하드 제약과 실드로 막고, 절감과 여유의 맞바꿈은 프런티어로 보인다(추론)
- **어디까지 맡기나**: AI 는 제어·권고 계통에, 인터록·비상 정지는 건드리지 않는다. 프런티어의 어느 점을 쓸지는 현업이 고른다
- **같이 꺼낼 카드**: [AI 도입 효과](#ai-도입-효과확대와-현장-신뢰)(「절감 효과를 증명」「시범 적용」이 같이 있으면 — 시범 1대면 [합성통제 계산](../methods/효과-측정/02-합성통제-계산.md))
