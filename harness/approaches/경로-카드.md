# 경로 카드 — 과제 유형 → 뼈대(계산·현장) + 렌즈(판정·방어)

> [입구](README.md) · 선반의 첫 길. 카드 하나가 「무엇을 계산하나(뼈대 — 계산)」「현장의 누구 눈으로 보나(뼈대 — 현장 관점)」「무엇을 기준으로 정하고 어떻게 방어하나(렌즈)」를 정한다.
> **전부 추론**이다. 유형 묶음과 뼈대·렌즈 선택은 필자 판단이고, 화면·지표·반문·데이터는 뼈대 기법 문서와 현장·렌즈 챕터의 「바로 쓰는 칸」·본문에서 옮겼다(새 사실·수치 없음). 원 분야 수치는 하이닉스 효과의 예측이 아니다.
> 목차의 ①~⑧ 은 기법·코드 선반 [`harness/methods/`](../methods/README.md) §1 과 입구 「표기」의 유형 번호다.
> `뼈대 — 계산` 줄은 **후보**다. 모의 과제로 시험했을 때 카드의 뼈대는 과제마다 절반쯤 맞았다 — 과제의 동사(찾아라·추천하라·보여 줘라)와 데이터 모양이 카드의 가정과 다르면 그 부분은 직접 짠다.

**목적이 여럿인 과제는 이렇게 읽는다**
1. 과제 문장에서 「줄여라·정해라·추천하라·알려 줘라」가 붙은 목적을 하나씩 뽑는다.
2. 목적마다 아래 표에서 카드 하나를 고른다.
3. 각 카드의 **뼈대 두 줄**(`뼈대 — 계산`·`뼈대 — 현장 관점`)만 먼저 읽는다. 렌즈 두 줄은 화면·방어를 짤 때 연다. `뼈대 — 계산` 줄은 **후보**다. 모의 과제로 시험했을 때 카드의 뼈대는 과제마다 절반쯤 맞았다 — 과제의 동사(찾아라·추천하라·보여 줘라)와 데이터 모양이 카드의 가정과 다르면 그 부분은 직접 짠다.
4. 목적이 둘이면 뼈대 계산을 잇는다 — 한 카드의 출력이 다른 카드의 입력이 되게 순서를 정한다.


목적이 하나인데 두 카드에 걸리면 과제의 **결정**(무엇을 정해 달라는가)에 맞는 카드의 뼈대를 쓰고, 다른 카드는 `같이 꺼낼 카드` 줄로 연다.
