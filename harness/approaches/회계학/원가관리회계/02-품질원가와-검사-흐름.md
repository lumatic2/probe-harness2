# 품질원가(COQ) — 예방·평가·내부실패·외부실패, HBM 적층 검사 흐름

> [원가관리회계](README.md) › 02 · 짝 기법: [기대손실 결정표](../../../methods/의사결정분석/01-기대손실-결정표.md) · [계측 샘플 배분](../../../methods/품질과-신뢰성-통계/04-계측-샘플-배분.md) (+[몬테카를로](../../../methods/확률과-시뮬레이션/03-몬테카를로.md) · [민감도 분석](../../../methods/의사결정분석/02-민감도와-가정-바꿔-보기.md))
> 원 분야 사실에는 근거 등급을 달았고, 반도체로 옮긴 부분(가정 변환·적용 예·지표·6시간 형태)은 별도 표시가 없으면 전부 **추론**이다. 원화로 말할 때는 하한=원가 기준, 상한=기회비용 기준, 기준 시점 명시. 표기는 [입구 README](../../README.md) 「표기」.

## 바로 쓰는 칸
- **쓸 점**: 검사를 늘릴지 줄일지를 예방·평가·내부실패·외부실패 4칸 합계, 곧 양품 스택당 총원가로 비교한다.
- **필요한 데이터**: 층 수 n, 다이 수율 Y_D, 접합 수율 Y_S, 검사 단계별 비용·검출률, 다이 원가; 실제 수율을 모르면 슬라이더로 둔다.
- **6시간 최소 형태**: 계산 = 검사 흐름별 몬테카를로 또는 기대값 식으로 양품 스택당 원가. 화면 = 검사 흐름 × 층 수 히트맵 + COQ 4칸 쌓은 막대.
- **반문 하나**: 「검사 늘리면 사이클타임이 늘어난다」 → 맞다. 검사 시간을 병목 장비시간 비용으로 평가 칸에 넣는다.
- **하지 말 것**: 논문의 총원가 57.34% 감소를 하이닉스 효과로 말하지 않는다 — 일반 3D-SIC 모형 수치이고 HBM 적용은 미확인이다.

## 상세

**한 줄**: 「품질경영·원가회계에서는 품질에 돈을 얼마나 써야 하나를 검사·예방을 늘리면 실패 비용이 줄어드는 상황에서 풀 때 품질원가(PAF) 분류를 쓴다. 핵심 논리는 「예방·평가에 1원을 더 쓰면 내부·외부 실패 비용이 몇 원 줄어드나」다. 평가를 계측·웨이퍼 테스트·적층 중간 검사로, 내부실패를 스크랩·재작업으로, 외부실패를 고객 반품·클레임으로 바꾸면 HBM 적층 공정에서 어느 단계에서 검사할지에 적용된다. 지금 방식과 비교해 양품 스택당 총원가로 보인다.」
- **과제 문구 신호**(추론): 「검사를 늘릴까 줄일까」「계측 샘플 비율」「적층 수율」「재작업·폐기 비용」「HBM 단수」
- **가정 변환**

| COQ 칸 | 반도체(HBM) 대응물 |
|---|---|
| 예방 | 공정 조건 관리, 레시피 승인, 설비 PM |
| 평가 | 웨이퍼 테스트(KGD), 적층 중간 검사, 계측 샘플 |
| 내부실패 | 불량 다이 위에 쌓은 양품 다이까지 버리는 손실(적층은 곱셈 수율) |
| 외부실패 | 고객 인증 실패·필드 반품·RMA |

- **원 분야 사실**: ASQ 정의 —
  - 「Cost of quality (COQ) is defined as a methodology that allows an organization to determine the extent to which its resources are used for activities that prevent poor quality, that appraise the quality of the organization’s products or services, and that result from internal and external failures.」
  - 내부실패 = 고객에게 가기 전 발견(스크랩·재작업·불량 분석), 외부실패 = 고객이 발견(보증·반품·클레임).
  - COQ = 예방 + 평가 + 내부실패 + 외부실패, 판단은 총합 최소화.
- **반도체 실제 적용(E2)**:
  - Taouil 외(J Electron Test 2012)가 3D 적층(D2W)에서 검사 흐름 8가지의 총원가를 비교했다.
  - 기준 공정(5층 적층, 다이 수율 81.65%, 결함 검출률 100% 가정, 제조원가 고정)에서 접합 전·중간 검사를 모두 하는 흐름(TF8)이 접합 후 검사만 하는 흐름(TF1)보다 총원가 57.34% 낮다(원문: 「Test flow TF8 is able to reduce the cost by 57.34% compared to TF1」).
  - 검사 비용 비중은 13~19% 로 오히려 높아졌다 — 「A higher test cost share does not necessarily result in higher overall cost.」
  - 또 「The lower the die yield, the larger the reduction」.
  - **조건**: 다이 수율·적층 수율·검출률 100% 가 가정값이고 논문은 일반 3D-SIC 모형이다.
  - HBM 의 MR-MUF·TC 본딩 공정에 그대로 맞는지는 **미확인**(추론으로만 연결).
  - **57% 는 이 논문 모형의 수치이지 하이닉스 효과가 아니다.**
- **하이닉스 적용 예**(추론): (a) HBM 적층 단수(8·12·16단)별로 중간 검사를 몇 번째 층에 넣을지(유형 ③). (b) 계측 샘플 비율을 줄였을 때 「평가 비용 절감 vs 놓친 불량의 내부·외부 실패 비용」(유형 ③④, 계측 샘플 배분 과 짝).
- **기준선과 지표**: 지금 = 지금의 검사 배치(가정). 지표 = 양품 스택당 총원가, COQ 4칸 구성.
- **6시간 최소 형태**: 데이터 = 층 수 n, 다이 수율 Y_D, 접합 수율 Y_S, 검사 단계별 비용·검출률, 다이 원가. 계산 = 검사 흐름별 몬테카를로(몬테카를로) 또는 기대값 식 → 양품 스택당 원가. 화면 = 검사 흐름 × 층 수 히트맵 + COQ 4칸 쌓은 막대 + 「수율이 낮을수록 중간 검사 가치↑」 슬라이더.
- **반론과 답**: 「검사 늘리면 사이클타임이 늘어난다」 → 맞다. 검사 시간을 병목 장비시간 비용(약 8.9억~14.3억원/시간 추정 — EUV 220 wph·웨이퍼 1장이 지나는 횟수 5~8회 가정, 근거 참조)으로 COQ 평가 칸에 넣는다. 「실제 수율을 모르지 않나」 → 수율은 슬라이더로 두고 결론이 바뀌는 손익분기 수율을 보여 준다(민감도 분석).
