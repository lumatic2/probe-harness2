# 결합원가·분리점 — 한 웨이퍼에서 여러 등급이 나올 때

> [원가관리회계](README.md) › 03 · 짝 기법: [선형·정수계획](../../../methods/최적화/02-선형-정수계획.md)
> 원 분야 사실에는 근거 등급을 달았고, 반도체로 옮긴 부분(가정 변환·적용 예·지표·6시간 형태)은 별도 표시가 없으면 전부 **추론**이다. 원화로 말할 때는 하한=원가 기준, 상한=기회비용 기준, 기준 시점 명시. 표기는 [입구 README](../../README.md) 「표기」.

## 바로 쓰는 칸
- **쓸 점**: 등급(빈) 판정에서 결합원가 배부액은 빼고, 재테스트·하위 등급 대체 판매의 증분 이익만으로 결정한다.
- **필요한 데이터**: `die_id, bin, test_margin, grade_price{A,B,C}, retest_cost, p_upgrade`; 등급별 가격이 없으면 증분 이익을 못 낸다.
- **6시간 최소 형태**: 계산 = 다이별 재테스트 기대 증분 이익 + 등급 재고 → 주문 배정 LP. 화면 = 경계 다이 산점도 + 「재테스트할 다이 n개, 기대 +○원」.
- **반문 하나**: 「제품 원가를 등급별로 배부하는 게 회사 규정이다」 → 재무보고용 배부는 그대로 두고 결정만 증분으로 한다(추론).
- **하지 말 것**: 반도체 빈닝을 결합원가로 다룬 자료는 근거 없음 — 교과서 논리를 반도체에서 입증된 사례처럼 말하지 않는다.

## 상세

**한 줄**: 「원가회계에서는 한 공정에서 여러 제품이 동시에 나오는 문제(결합제품)를 풀 때 분리점 이후의 증분만 보는 「팔까, 더 가공할까」 분석을 쓴다. 핵심 논리는 「분리점 전 결합원가는 어떻게 배부하든 의사결정과 무관」이다. 결합 공정을 웨이퍼 팹 공정으로, 결합제품을 속도·전력·용량 등급(빈)으로, 추가 가공을 추가 테스트·번인·재분류로 바꾸면 등급 판정과 하위 등급 대체 판매에 적용된다.」
- **과제 문구 신호**(추론): 「빈닝」「등급 판정」「경계값 근처 다이 재테스트」「상위 등급 재고가 남는다」
- **가정 변환**: 결합원가 = 웨이퍼 원가 · 분리점 = 테스트·빈 분류 · 분리점 판매가 = 등급별 시장가 · 추가 가공 = 재테스트·번인·모듈화 · 하위 대체 = 상위 등급 다이를 하위 등급 주문에 투입.
- **원 분야 사실**: 분리점 이전 원가는 추가 가공 결정에 무관하다(OpenStax 10장 해설 — 10.1 절은 축자로 읽었고 분리점 문장은 WebSearch 요약). 결합원가 배부(판매가치법·순실현가치법)는 재고 평가용 공식이다(accountingtools 요지 — WebSearch 요약만, 원문 미열람). 추가 가공 판단 = (추가 가공 후 판매가 − 분리점 판매가) − 추가 가공 원가 > 0 ? 결합원가는 계산에 넣지 않는다.
- **반도체 관련 OR 문헌**: Bitran & Dasu(1992, *Operations Research*)가 「확률적 수율과 대체 가능한 수요」 아래 발주 정책을 다뤘다 — 한 투입에서 여러 등급이 나오고 상위 등급이 하위 수요를 대신할 수 있는 상황(**메타데이터만**, 원문은 요청 제한으로 못 받음). 반도체 빈닝을 회계의 결합원가로 다룬 자료는 **근거 없음**(WebSearch 1회 — 일반 결합원가 자료만 나옴).
- **하이닉스 적용 예**(추론): (a) 경계값 근처 다이를 재테스트해 상위 등급으로 올릴지(유형 ③). (b) 상위 등급 재고가 남을 때 하위 주문에 돌릴지 vs 기다릴지(유형 ⑦, 선형·정수계획 LP 배정).
- **기준선과 지표**: 지금 = 등급별 원가 배부 기준 판단(가정). 지표 = 경계 다이 재테스트 기대 증분 이익(원), 등급 재고 → 주문 배정 이익.
- **6시간 최소 형태**: 데이터 `die_id, bin, test_margin, grade_price{A,B,C}, retest_cost, p_upgrade`. 계산 = 다이별 재테스트 기대 증분 이익 + 등급 재고 → 주문 배정 LP(선형·정수계획). 화면 = 경계 다이 산점도(마진 vs 기대 이익) + 「재테스트할 다이 n개, 기대 +○원」.
- **반론과 답**: 「제품 원가를 등급별로 배부하는 게 회사 규정이다」 → 재무보고용 배부는 그대로 둔다. 결정은 증분으로만 한다는 게 회계 교과서의 결론이다(배부액으로 판단하면 하위 등급이 「적자」처럼 보여 잘못 버린다 — 추론).
