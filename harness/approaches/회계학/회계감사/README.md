# 회계감사 — 학문 지도

> [입구](../../README.md) › [회계학](../README.md) › **회계감사** · 챕터 4
> 한 줄: **회계감사**는 숫자·기록·통제를 믿어도 되는지 독립된 눈으로 확인한다. 전부 볼 수 없으니 어디를 얼마나 볼지 정하고, 놓칠 위험을 받아들일 수준 아래로 묶는다.
> **주의**: 원 분야 사실에는 등급을 달았고 반도체로 옮긴 부분은 별도 표시가 없으면 **추론**이다. 이 모듈에서 반도체에 실제 쓰인 선례는 [프로세스 마이닝](02-프로세스-마이닝.md)뿐이고 나머지는 선례를 못 찾았다(「없다」가 아니라 「이번 표면에서 못 찾았다」).

## 핵심 질문
**이 숫자·기록·통제를 믿어도 되나? 다 못 볼 때 어디를 얼마나 봐야 하고, 놓친 오류가 어느 수준 아래라고 말할 수 있나?**

## 이럴 때 꺼낸다 / 옆 모듈로
- **꺼낸다**: 계측·검사 슬롯이 모자랄 때 · SOP 준수·점검 누락을 따질 때 · 로그 전체로 규정 이탈을 찾을 때 · 수기 기록의 신뢰를 따질 때 · 「AI 가 틀리면 누가 책임지나」에 답해야 할 때.
- **옆 모듈로**
  - 판정에 원화 기준이 필요하다(재작업·폐기·검사 늘리기) → 회계학 › [원가관리회계](../원가관리회계/README.md)
  - 법이 요구하는 증빙·보존 기간 → 법학 › 기업법규
  - 어디가 나쁜지 배우면서 뽑기(탐색·학습) → 계측 샘플 배분 · 패턴 이상 탐지 → 관리도와 오경보 주기
  - 접근 통제·암호·보안 구현 → 컴퓨터과학 › 정보보안

## 핵심 개념어
- **전수와 층화**: 혼자서도 허용 오류를 넘을 큰 항목은 전수로 보고, 나머지는 비슷한 것끼리 층을 나눠 표본을 줄인다([01](01-감사-표본추출.md)).
- **허용 왜곡표시액**: 받아들일 수 있는 놓친 오류의 크기. 반도체에서는 받아들일 수 있는 미검출 손실(원)로 옮긴다.
- **적합도**: 로그에서 그린 실제 흐름이 표준 흐름과 얼마나 맞는지의 값([02](02-프로세스-마이닝.md)).
- **3선 모델**: 1선 실행, 2선 위험 관리 지원, 3선 독립 보증([03](03-3선-모델과-내부회계관리제도.md)).
- **허용 일탈률**: 이 비율을 넘게 어기면 통제를 믿지 않는다는 선([04](04-통제-테스트.md)).

## 관점 쌍
- **학습 ↔ 보증**: 계측 샘플 배분 은 어디가 나쁜지 배우는 것이고, 감사 표본은 놓친 손실이 한도 아래라고 말하는 것이다([01](01-감사-표본추출.md)).
- **표본 ↔ 전수**: 기록이 디지털이면 전수([02](02-프로세스-마이닝.md))로 가고, 표본은 사람이 현장을 확인하는 통제에만 남는다([04](04-통제-테스트.md)).

## 이 분야 사람이 먼저 묻는 것 5
1. 모집단이 무엇이고, 빠진 것은 없나?
2. 전수로 볼 큰 항목을 먼저 떼어 냈나?
3. 받아들일 수 있는 오류의 크기를 누가 정했나?
4. 이 통제는 실제로 지켜졌다는 증거가 남아 있나?
5. 기록이 사후에 바뀌지 않았다는 것을 어떻게 아나?

## 흔한 함정
- 재진입 공정 전체를 한 그래프로 그려 스파게티를 만든다. 제품 1개·구간 1개로 좁힌다([02](02-프로세스-마이닝.md)).
- 표본 학습(계측 샘플 배분)과 감사 표본(보증)을 같은 것으로 말한다([01](01-감사-표본추출.md)).
- 계수·확률의 가정값을 현장 수치처럼 보인다. 화면에 「가정값」을 붙인다.
