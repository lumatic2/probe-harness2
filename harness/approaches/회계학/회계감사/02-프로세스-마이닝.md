# 프로세스 마이닝 — 표본 대신 모집단 전체 이벤트 로그

> [회계감사](README.md) › 02 · 짝 기법: [디스패칭 규칙 시뮬레이션](../../../methods/확률과-시뮬레이션/01-디스패칭-규칙-시뮬레이션.md)
> 원 분야 사실에는 근거 등급을 달았고, 반도체로 옮긴 부분은 별도 표시가 없으면 **추론**이다. 모듈 주의는 [모듈 README](README.md), 표기는 [입구](../../README.md) 「표기」.

## 바로 쓰는 칸
- **쓸 점**: MES 로트 이력을 전수로 돌려 표준 라우트 이탈·재작업 루프·스텝 사이 대기 구간을 찾는다.
- **필요한 데이터**: `case_id(lot), activity(step), resource(eqp), timestamp`; 로트별 공정 스텝 이력이 없으면 못 쓴다.
- **6시간 최소 형태**: 계산 = pm4py 귀납 마이너 적합도 또는 pandas 표준 다음 스텝 비교. 화면 = 전이 그래프(굵기=로트 수, 빨강=비표준) + 이탈 로트 목록.
- **반문 하나**: 「재진입 공정이라 그래프가 스파게티가 된다」 → 제품 1개·구간 1개(예: 포토→식각 루프)로 좁혀 보인다.
- **하지 말 것**: OST 데모를 성과 사례로 말하지 않는다 — 학생 프로젝트 초록이고 성과 수치는 없다. pm4py 는 킷 목록에 없어 당일 설치가 필요하다.

## 상세

**한 줄**: 「감사·정보시스템 분야에서는 업무가 규정된 순서대로 돌았는지를 ERP 이벤트 로그가 모두 남는 상황에서 풀 때 프로세스 마이닝을 쓴다. 핵심 논리는 「로그에서 실제 흐름을 그려 내고(발견), 표준 흐름과 얼마나 맞는지 잰다(적합도)」 — 표본이 아니라 전수다. 이벤트 로그를 MES 로트 이력(로트 id·공정 스텝·장비·시각)으로 바꾸면 표준 라우트 이탈·재작업 루프·대기 구간 발견에 적용된다.」
- **과제 문구 신호**(추론): 「표준 라우트 이탈」「재작업 루프」「공정 순서 위반」「스텝 사이 대기가 긴 구간」「규정 대조」
- **가정 변환**: 사건(case) = 로트 · 활동 = 공정 스텝(재진입 포함) · 자원 = 장비·챔버 · 표준 모형 = 제품별 표준 라우트.
- **원 분야**: Jans·Alles·Vasarhelyi(2012, *Int. J. Accounting Information Systems*) — 감사에 프로세스 마이닝을 쓸 때의 부가가치 원천으로 표본이 아닌 모집단 전체 분석 등을 든다(**메타데이터와 검색 요약만**, 본문 미열람).
- **반도체 실제 사례(E4)**:
  - 스위스 OST 대학·Intellion 의 Fab Analytic Miner 데모 — pm4py 로 「filtering, process discovery and conformance checking」 기능을 반도체 고객 로그(LotTrack)에 붙였다.
  - 문제 서술: 「the lots are processed in loops in about 400 production steps. It can take up to three months for a lot to be produced.」
  - **조건**: 학생 프로젝트 초록이고 성과 수치는 없다. 삼성 반도체 MES 로그에 프로세스 마이닝을 적용한 UNIST 사례 문서가 있다는 검색 결과가 있으나 원문은 연결 실패로 못 받음.
- **하이닉스 적용 예**(추론): (a) 표준 라우트를 벗어난 로트 비율과 그 로트의 수율 차이(유형 ③). (b) 스텝 사이 대기가 긴 구간 = Q-Time 위험 구간 지도(유형 ②). (c) 규정 대조 과제에서 「절차 순서 위반」 전수 탐지(유형 ⑤).
- **기준선과 지표**: 적합도(fitness), 이탈 로트 비율, 이탈 경로별 수율·사이클타임 차이.
- **6시간 최소 형태**: 데이터 `case_id(lot), activity(step), resource(eqp), timestamp`. 계산 = pm4py 의 귀납 마이너로 모형 발견 + 토큰 재생 적합도(설치만 되면 수십 줄 — **킷 의존성 목록에 pm4py 는 없음**, 당일 설치 필요 확인). 대안: pandas 로 「표준 다음 스텝 표」와 실제 전이를 비교하는 규칙 기반 적합도. 화면 = 전이 그래프(굵기=로트 수, 빨강=비표준) + 이탈 로트 목록.
- **반론과 답**: 「재진입 공정이라 그래프가 스파게티가 된다」 → 원문도 루프 400 스텝을 문제로 든다. 그래서 제품 1개·구간 1개(예: 포토→식각 루프)로 좁혀 보인다.
