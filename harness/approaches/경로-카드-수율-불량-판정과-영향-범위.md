# 경로 카드 — 수율·불량 판정과 영향 범위

> [경로 카드 목록](경로-카드.md) · [입구](README.md). **전부 추론**이다 — `뼈대 — 계산` 줄은 후보이고, 과제의 동사와 데이터 모양이 다르면 그 부분은 직접 짠다. 뼈대 두 줄을 먼저 읽고, 렌즈 두 줄은 화면·방어를 짤 때 연다.

- **이런 과제 문장**: 「Q-Time 초과 로트」「재작업할지 폐기할지」「끝까지 흘려 테스트할지」「출하 판정」「웨이퍼맵 불량 패턴」「같은 장비를 거친 로트」
- **필요한 데이터**: Q-Time 초과 로트 처분이면 → `lot_id, step_seq, total_steps, wafer_count, qtime_excess_min, rework_route, p_good_if_continue, p_good_if_rework` · 웨이퍼맵·공정 이력이면 → 웨이퍼맵·빈(`lot_id, wafer_id, die_x, die_y, bin`)과 공정 이력(`eqp_id, chamber`) — 이력이 없으면 공통 장비·영향 범위를 못 센다(추론) / 없을 때: 양품 확률은 과거 위반 로트 결과로 추정하고, 그것도 없으면 범위로 두고 손익분기 확률을 보인다
- **뼈대 — 계산**: Q-Time 초과 로트 처분이면 → [로트 이력 구간 대기](../methods/이벤트-로그-분석/01-로트-이력-구간-대기.md)(초과 로트·초과 시간) → [기대손실 결정표](../methods/의사결정분석/01-기대손실-결정표.md)(진행/재작업/폐기·EVPI) → [민감도 분석](../methods/의사결정분석/02-민감도와-가정-바꿔-보기.md)(양품 확률 범위) · 웨이퍼맵·공정 이력이면 → (공통 장비·챔버 찾기와 영향 로트 조인은 선반에 없다 — 직접 짠다. 방법의 뼈대는 현장 챕터 [품질·수율](반도체-현장/품질-계측-후공정/01-품질-수율.md)의 6시간 최소 문제) → [기대손실 결정표](../methods/의사결정분석/01-기대손실-결정표.md) → [민감도 분석](../methods/의사결정분석/02-민감도와-가정-바꿔-보기.md), 방어는 [생산 데이터로 실험을 대신할 수 있나](../methods/판정-모델/06-생산-데이터로-실험을-대신할-수-있나.md)
- **뼈대 — 현장 관점**: [품질·수율](반도체-현장/품질-계측-후공정/01-품질-수율.md) — 영향 범위(같은 경로 로트 수), 수율은 단계·분모를 붙여 말한다
- **렌즈 — 판정 기준**: [관련원가와 증분분석](회계학/원가관리회계/01-관련원가와-증분분석.md) — 이미 들인 원가를 빼고 앞으로 달라지는 돈만으로 진행·재작업·폐기를 가른다
- **렌즈 — 방어·설득**: [품질원가와 검사 흐름](회계학/원가관리회계/02-품질원가와-검사-흐름.md) · [결합원가와 분리점](회계학/원가관리회계/03-결합원가와-분리점.md)
- **화면 한 장**: 로트별 「진행/재작업/폐기」 기대 손익 막대 + 매몰원가를 회색으로 따로 보여 주고 판정에서 뺐다고 표시
- **지표 3**: 판정별 기대 증분 손익 · 잘못 판정했을 때 손실(EVPI) · 판정이 뒤집히는 손익분기 확률
- **반문 하나**: 「진행 시 양품 확률을 어떻게 아나」 → 과거 위반 로트의 결과로 추정하고, 없으면 범위로 두고 손익분기 확률을 보인다
- **어디까지 맡기나**: 판정 비교는 AI, 되돌릴 수 없는 폐기는 사람 승인(추론, [승인 게이트](컴퓨터과학/자율성-설계/02-가역성과-영향-크기로-나누는-승인-게이트.md))
- **같이 꺼낼 카드**: [스케줄·Q-Time](경로-카드-스케줄-Q-Time-디스패칭.md)(「다시 위반이 안 나게 일정을」이 같이 있으면)
