# 과제 받고 10분 체크리스트

> 역할: [경로 카드](경로-카드.md)로 뼈대(계산·현장 관점)와 렌즈를 고른 뒤, 다른 현장 관점을 훑고 방어를 준비하는 용도.
> [입구](README.md)
(현장 관점 문서의 끝 체크리스트를 옮긴 것. 시계를 켜고 위에서 아래로. 각 줄은 「예/아니오 + 한 줄 메모」면 된다.)

**0~2분 — 과제 문장 분해**
- [ ] 과제 문장에서 **명사**(로트·장비·웨이퍼·알람·사람·전력…)와 **동사**(줄이다·예측하다·판정하다·배정하다)를 뽑았다.
- [ ] 결정을 내리는 **사람(직무)** 이 누구인지 한 단어로 적었다 — 양산관리 / 장비 엔지니어 / 공정 엔지니어 / 품질보증 / P&T / 유틸리티 / 현장 리더. 모르면 「누가 이 화면을 매일 아침 열까?」로 정한다.

**2~6분 — 열 개의 눈으로 같은 과제 보기** (괄호 안은 해당 반도체 현장 챕터)
- [ ] ① 흐름([흐름 챕터](반도체-현장/흐름-설비-계획/01-흐름-생산.md)): 이 문제가 **대기·WIP·사이클타임·Q-time** 을 바꾸나? 리틀의 법칙으로 검산할 세 숫자가 데이터에 있나?
- [ ] ② 설비([설비 챕터](반도체-현장/흐름-설비-계획/02-설비.md)): **장비 정지**가 원인이나 결과에 끼어 있나? 가용도를 누구의 정의로 재고 있나?
- [ ] ③ 품질·수율([품질·수율 챕터](반도체-현장/품질-계측-후공정/01-품질-수율.md)): **불량·출하 판정**이 걸려 있나? 수율이 어느 단계에서 잰 값인가?
- [ ] ④ 계측·제어([계측·제어 챕터](반도체-현장/품질-계측-후공정/02-계측-제어.md)): **재지 않은 것의 위험**(W@R)이나 **다음 런 보정**이 문제인가?
- [ ] ⑤ 엔지니어 업무([엔지니어 업무 챕터](반도체-현장/업무-유틸리티-사람/01-엔지니어-업무.md)): **이상 대응·인계·변경·보고**의 시간을 줄이는 문제인가? 텍스트 기록이 있나?
- [ ] ⑥ 유틸리티([유틸리티 챕터](반도체-현장/업무-유틸리티-사람/02-유틸리티-환경.md)): 전력·물·공조·가스가 비용이나 정지 원인으로 끼어 있나?
- [ ] ⑦ 후공정·HBM([후공정·HBM 챕터](반도체-현장/품질-계측-후공정/03-후공정-HBM.md)): **적층·테스트** 단계가 있나? 단계 수율이 곱해지나?
- [ ] ⑧ 공급망·계획([공급망·계획 챕터](반도체-현장/흐름-설비-계획/03-공급망-계획.md)): 결과를 **돈·납기·재고**로 바꿔 말할 수 있나?
- [ ] ⑨ 사람·안전([사람·안전 챕터](반도체-현장/업무-유틸리티-사람/03-사람-안전-숙련.md)): **숙련·인력 공백·안전**이 제약인가?
- [ ] ⑩ AI 도입·신뢰: 이 과제가 이미 넣은 AI 의 효과·확대·현장 수용 문제인가? → [경로 카드](경로-카드.md) 해당 유형(「AI 도입 효과·확대와 현장 신뢰」)

**6~8분 — 고르기**
- [ ] 걸린 관점 중 **주 관점 1개 + 보조 관점 1개**를 골랐다(주: 화면의 본체, 보조: 효과를 다른 언어로 번역하는 칸).
- [ ] 주 관점의 **지표 하나**를 정했다(반도체 현장 챕터 「핵심 지표」 칸에서). 그 지표의 정의를 데이터로 계산할 수 있는지 컬럼명으로 확인했다(`unique()`·결측).
- [ ] 이 과제의 **트레이드오프 한 쌍**을 적었다(예: 검사량 ↔ 사이클타임, 가동률 ↔ 대기, 사전 선별 비용 ↔ 적층 손실).

**8~10분 — 방어 준비**
- [ ] 「원본 생산 데이터에 손대지 않는다·사람이 최종 판단한다」를 어디에 보일지 정했다(품질보증 채용 담당의 회사 문장은 [품질·수율 챕터](반도체-현장/품질-계측-후공정/01-품질-수율.md)에 있다).
- [ ] 이 관점의 현장 사람이 할 법한 반문 하나를 적었다(예: 양산관리 「그 숫자, 우리 정의로는 다르게 나오는데요?」 / 품질 「영향 범위는요?」 / 설비 「정비팀 탓인가요, 생산 사정인가요?」).
- [ ] 6시간 안에 안 될 것(RL 디스패칭·대형 예측 모델·풀 디지털 트윈)을 명시적으로 뺐다.
- [ ] AI 에 어디까지 맡기는지 단계로 답할 준비를 했다(행동마다 감지·분석·선택·실행 중 어느 칸까지 — [자율성 단계표](컴퓨터과학/자율성-설계/01-행동별-자율성-단계표.md)).
- [ ] 효과를 무엇과 비교해 증명할지 정했다(단순 전후 비교 말고 비교군 — [인과추론과 실험](경제학/인과추론과-실험/README.md)).
