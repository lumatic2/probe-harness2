# 경로 카드 — 유틸리티·에너지 운전

> [경로 카드 목록](경로-카드.md) · [입구](README.md). **전부 추론**이다 — `뼈대 — 계산` 줄은 후보이고, 과제의 동사와 데이터 모양이 다르면 그 부분은 직접 짠다. 뼈대 두 줄을 먼저 읽고, 렌즈 두 줄은 화면·방어를 짤 때 연다.

- **이런 과제 문장**: 「냉동기·공조 운전 설정 추천」「온습도 허용 범위를 지키며」「전력비·요금표」「설정값 최적화」「에너지 절감」
- **필요한 데이터**: 냉동기·공조 운전 로그(부하·전력·냉수 온도)·구역 온습도와 허용 범위·시간대별 요금 — 없으면 못 쓴다 / 없을 때: 설정값 → 구역 온습도 반응 모델과 효율 곡선은 선반에 없다 — 직접 만든다
- **뼈대 — 계산**: [선형·정수계획](../methods/최적화/02-선형-정수계획.md)(운전 대수·부하 배분) → [파레토 프런티어](../methods/최적화/04-파레토-프런티어.md)(절감 대 여유)
- **뼈대 — 현장 관점**: [유틸리티·환경](반도체-현장/업무-유틸리티-사람/02-유틸리티-환경.md) — 냉동기 효율 곡선 + 시간대별 부하 → 운전 대수·부하 배분 LP → 절감 추정(신뢰구간)
- **렌즈 — 판정 기준**: [목적이 둘이면 트레이드오프 곡선](경영과학/모형으로-다시-쓰기/02-목적이-둘이면-트레이드오프-곡선.md) — 절감과 온습도 여유를 한 값으로 합치지 않고 프런티어 위 현행 점으로 현업이 고르게
- **렌즈 — 방어·설득**: [단순 감시기·안전 실드](컴퓨터과학/자율성-설계/05-단순-감시기-구조와-안전-실드.md) · [가정이 틀리면](경영과학/모형을-믿어도-되나/01-가정이-틀리면-민감도와-뒤집히는-경계.md)
- **화면 한 장**: 절감률 대 온습도 여유 프런티어 + 현행 운전 점 + 「제약 위반 0건」 배지 + 실드 차단 시점·사유
- **지표 3**: 전력 절감 추정(신뢰구간) · 온습도 허용 범위 위반 0건 · 실드 차단률
- **반문 하나**: 「냉동기를 줄이면 청정도·온습도는 누가 보장하나요?」 → 허용 범위는 하드 제약과 실드로 막고, 절감과 여유의 맞바꿈은 프런티어로 보인다(추론)
- **어디까지 맡기나**: AI 는 제어·권고 계통에, 인터록·비상 정지는 건드리지 않는다. 프런티어의 어느 점을 쓸지는 현업이 고른다
- **같이 꺼낼 카드**: [AI 도입 효과](경로-카드-AI-도입-효과-확대와-현장-신뢰.md)(「절감 효과를 증명」「시범 적용」이 같이 있으면 — 시범 1대면 [합성통제 계산](../methods/효과-측정/02-합성통제-계산.md))
