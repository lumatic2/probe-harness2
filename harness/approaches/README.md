# 접근법 선반 — 과제를 다른 학문의 눈으로 읽는다

> 이 선반은 과제를 받았을 때 「이렇게 한번 접근해 볼까」를 떠올리게 하는 재료다. 다른 분야의 관점 두세 개와 판정 기준·화면·반문을 준다. **과제 고유의 계산은 당일 직접 짠다** — 선반의 기법·코드는 출발점이지 완성품이 아니고, 데이터 모양이 다르면 고쳐 쓴다.
>
> 층: **입구(이 파일) → 학문 → 모듈 → 챕터(파일 하나)**. 학문 README 에는 그 학문의 하위 분야 지도가 있고, 모듈 README 에는 그 모듈의 학문 지도(핵심 질문·갈래·함정)와 챕터 목록이 있다.
> 이 선반은 「어떻게 보나」를 다룬다. 「어떻게 계산하나」는 경영과학 기법·코드 선반 `harness/methods/`에 있고, 챕터마다 「짝 기법」로 잇는다.

## 쓰는 법 (5줄)
1. **문제 정의 단계** — [경로 카드](경로-카드.md)의 뼈대(기법 + 현장 챕터)에 렌즈 챕터(판정·방어)를 얹는다. 없으면 [신호 지도](신호-지도.md)의 굵은 챕터부터 **2~3개** 꺼내 렌즈를 넓힌다. 반도체 현장 챕터는 「이 문제를 그 직무의 눈으로 보면 이미 해결됐나/아닌가」를 묻는 반증 재료다.
2. **해법 후보 단계** — 챕터의 「가정 변환」 표와 「6시간 최소 형태」를 후보 한 줄의 재료로 쓴다. 주 무기는 카드의 `뼈대 — 계산` 기법이고, 접근법 챕터는 **렌즈(판정 기준·방어 문장)**로 얹는다(기법 하나로 끝내지 않는다 — `harness/methods/README.md` §5).
3. **옮기는 법** — 챕터의 문장 꼴: 「<분야>에서는 <문제>를 <상황>에서 풀 때 <기법>을 쓴다 … <가정>을 <반도체 현장의 무엇>으로 바꾸면 <하이닉스 문제>에 적용된다. 기준 대비 <지표>로 개선을 보인다.」 가정 변환 표에서 안 맞는 행은 그대로 쓰지 말고, 제출물·서술형 답에서 「맞지 않는 점」으로 말한다.
4. **지킬 것** — 원 분야의 효과 크기(57%·23%·1% 등)는 원 분야의 수치다. 팹 효과의 예측이 아니므로, 제출물·서술형 답에서 「하이닉스에서도 이만큼」으로 말하면 틀린다. `추론`·`근거 없음`·`미확인` 표시는 지우지 않는다.
5. **근거 옮기기** — 제출물·서술형 답에 근거를 쓸 때는 챕터 「근거」 칸의 외부 출처 URL·접근일·등급을 그대로 옮겨 적는다. 챕터 파일 경로 자체를 근거로 적지 않는다.

## 표기
- **정본**: 기법은 경로 카드의 `뼈대 — 계산` 줄이 정본이다. `harness/methods/README.md` 의 표는 카드에 없는 기법을 이름·신호로 찾을 때만 쓴다.
- **반문의 정본**: 반문·방어 문장의 정본은 챕터다. 카드·체크리스트의 반문은 그 요약이다.
- **바로 쓰는 칸**: 챕터 맨 위 `## 바로 쓰는 칸` 다섯 줄만 읽고 열지 말지 정한다.
- **기법 문서의 「바로 쓰는 칸」**: 끝 줄 「대신 쓸 수 있었던 것 / 안 쓴 이유」는 서술형 「선택 이유·대안」 답의 재료다.
- **(외부 출처 미확인)** = 준비 과정의 메모에서 온 사실로 외부 URL 을 붙이지 못했다. 쓰기 전에 확인하거나 쓰지 않는다.
- **원화 값**은 가정이다. 과제 데이터·공시로 다시 센다(하한=원가 기준, 상한=기회비용 기준, 기준 시점 명시).
- **챕터 순서**: **한 줄**(문장 꼴) → 과제 문구 신호 → 가정 변환 → 원 분야 사실 → 하이닉스 적용 예 → 기준선과 지표 → 6시간 최소 형태 → 반론과 답 → 짝 기법 → 근거. 반도체 현장 챕터는 「무엇을 보나 · 핵심 지표 · 결정 직무 · 데이터 · 흔한 고통 · AI/최적화 기회 · 6시간 최소 문제」 순서다.
- **파일 이름**: `01-이름.md` — 번호는 그 모듈 안에서 쓰일 가능성 순서이고, 다른 뜻은 없다.
- **근거 등급** `E1~E5`: 법령·표준·공시·감사 기준은 E1, 피어리뷰 논문은 E2, 교과서·교육자료·전문 기관·판매사 글은 E3, 개인 발언·벤더 글·2차 인용은 E4, 비공식 커뮤니티는 E5. 출처 조사가 붙인 그대로 옮겼다.
- **기타 표시**: **추론** = 필자 해석(등급 없음) · **추정** = 공개값에 가정을 얹은 계산 · **★** = 원문을 확인하지 못한 통념(현업에게 물어볼 질문으로만 쓴다) · **미확인/근거 없음** = 이번 조사에서 못 찾았다는 뜻이다. 「없다」는 뜻이 아니다.
- **접근일**: 기존 챕터는 2026-11-09, 신규 학문·모듈(경영학 신규·경제학·세법·컴퓨터과학)은 2026-11-10.
- **「과제 문구 신호」 칸은 필자 추론**이다. 챕터의 적용 예에서 뽑은 말이지 과제에 그 말이 나온다는 예측이 아니다.
- **유형 번호**: ①~⑥ 은 `harness/methods/README.md` §1 과 같다. 이 선반이 두 칸을 더했다 — ⑦ 투자·재고·가격(경영 판단형), ⑧ 안전·협력사·보안(규제형). 경로 카드에서는 번호를 목차 표에만 달고, 카드는 이름(제목)으로 가리킨다.
- **외부 URL 없는 반도체 사실**: 위 「(외부 출처 미확인)」 표시가 붙은 사실이다. 쓰기 전에 확인한다.
