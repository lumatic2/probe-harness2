# 가정이 틀리면 — 민감도와 결론이 뒤집히는 경계

> [모형을 믿어도 되나](README.md) › 01 · 짝 기법: [민감도 분석](../../../methods/의사결정분석/02-민감도와-가정-바꿔-보기.md) 민감도·what-if (+[기대손실 결정표](../../../methods/의사결정분석/01-기대손실-결정표.md) · [몬테카를로](../../../methods/확률과-시뮬레이션/03-몬테카를로.md))
> 원 분야 사실에는 근거 등급을 달았고, 반도체로 옮긴 부분은 별도 표시가 없으면 **추론**이다. 모듈 주의는 [모듈 README](README.md), 표기는 [입구](../../README.md) 「표기」.

## 바로 쓰는 칸
- **쓸 점**: 결론이 입력 가정에 얼마나 기대는지 토네이도와 「이만큼 틀리면 뒤집힌다」 임계 한 줄을 효과 추정 옆에 붙인다.
- **필요한 데이터**: 결과를 내는 함수(솔버 호출 가능) + 가정값 표(수율·손실 단가·인정률·발생 확률). 각 가정의 현실적 범위는 현업에게 묻는다(±20% 는 근거 없음).
- **6시간 최소 형태**: 가정을 하나씩 흔들어 재실행(OAT) + 임계 탐색. 화면: 토네이도 가로 막대 + 우측 임계 목록 + 슬라이더.
- **반문 하나**: 「OAT 는 상호작용을 못 본다」 → 맞다. 중요한 두 가정은 2변수 격자로 본다.
- **하지 말 것**: 입력이 수십 개이거나 풀이가 몇 분 걸리면 OAT 가 맞지 않는다. 임계가 비현실 범위면 「안 뒤집힌다」와 근거 숫자를 적는다.

## 상세

**한 줄**: 「경영과학에서는 모형의 결론이 입력 가정에 얼마나 기대는지를 가정을 하나씩 흔들어 보는 민감도 분석으로 확인한다. 핵심 논리는 「어느 가정이 결과를 가장 크게 움직이나(토네이도)」와 「결론이 뒤집히려면 이 가정이 몇 % 틀려야 하나(손익분기 가정)」다. 가정을 수율·손실 단가·인정률·발생 확률로, 결론을 도입/보류 판정으로 바꾸면 모든 유형의 효과 추정에 붙는다. 흔들기 전후의 결론 일치 여부로 보인다.」
- **과제 문구 신호**(추론): 「가정이 틀리면?」「얼마나 안정적인가」「ROI」「도입 타당성」「어떤 변수가 가장 중요한가」「시나리오 비교」
- **가정 변환**

| 원 분야 | 반도체 |
|---|---|
| 기준값 x₀ | 현장 확인 전의 가정값(수율, 랏당 손실, 발생 확률) |
| ±δ 흔들기 | 가정마다 현실적인 범위(예: 수율 ±2%p) — ±20% 는 임의 폭 |
| 임계 x* | 판정이 도입에서 보류로 바뀌는 값, 기준 대비 % 로 표시 |
| 상호작용 | 두 가정이 함께 움직이는 경우 — 2변수 격자로 부호 영역 |

- **원 분야 사실**: what-if 재계산은 Microsoft IFS 가 2026 Edelman 을 받은 구조의 핵심 기능이다(OptiGuide, E2→E3 · INFORMS, 자기 신고). Intel 램프업 연구는 용량 여유 ±5% 안의 편차에는 둔감하고 그 밖에서는 빠르게 나빠진다는 경계를 핵심 결론으로 냈다(WSC 2018, E2, 수치 예제 기반). 토네이도·손익분기의 정의는 교과 일반이며 출처를 달지 않았다(추론).
- **하이닉스 적용 예**(추론): (a) 솔버 결과나 원화 효과 추정 옆에 「이 가정이 이만큼 틀리면 결론이 뒤집힌다」 한 줄. (b) 가정 간 곱으로 묶인 항목(발생 건수 × 랏당 손실 × 인정률)은 swing 이 같게 나오므로 한 덩어리로 보고한다. (c) 임계가 비현실적 범위에 있으면 「안 뒤집힌다」고 말하고 그 근거 숫자를 적는다.
- **기준선과 지표**: 기준선 = 기준 가정에서의 결론. 지표 = swing 순 토네이도, 가정별 임계(기준 대비 %), 2변수 격자의 부호 경계.
- **6시간 최소 형태**: 결과를 내는 함수(솔버 호출이어도 됨) + 가정값 표 → 재실행 루프(OAT) + 임계 탐색. 화면 = 토네이도 가로 막대 + 우측 임계 목록 + 슬라이더. 입력이 수십 개이거나 풀이가 몇 분 걸리면 OAT 가 맞지 않는다(민감도 분석 문서).
- **반론과 답**: 「OAT 는 상호작용을 못 본다」 → 맞다. 중요한 두 가정은 2변수 격자로 본다. 전역 민감도(Sobol·Morris)는 본격 분석용이다. 「±20% 근거가 있나」 → 없다. 현업에게 각 가정의 현실적 범위를 묻는 것이 첫 질문이다.
