# 깰 수 없는 규칙과 값을 매길 규칙 — 하드 제약 대 벌점, Q-Time

> [모형으로 다시 쓰기](README.md) › 03 · 짝 기법: [제약 프로그래밍 일정](../../../methods/최적화/01-제약-프로그래밍-일정.md) CP-SAT 잡숍 · [기대손실 결정표](../../../methods/의사결정분석/01-기대손실-결정표.md) 결정분석 (+[디스패칭 규칙 시뮬레이션](../../../methods/확률과-시뮬레이션/01-디스패칭-규칙-시뮬레이션.md))
> 원 분야 사실에는 근거 등급을 달았고, 반도체로 옮긴 부분은 별도 표시가 없으면 **추론**이다. 모듈 주의는 [모듈 README](README.md), 표기는 [입구](../../README.md) 「표기」.

## 바로 쓰는 칸
- **쓸 점**: Q-Time 같은 규칙을 하드 제약과 벌점 두 모형으로 돌려, 하드가 풀리지 않을 때 어느 LOT·장비가 충돌하는지 보인다.
- **필요한 데이터**: 일정 입력(LOT, 공정시간, 장비, Q-Time 상한). 벌점 계수를 정하지 못하면 기대 손실 환산은 보류하고 위반 건수만 말한다.
- **6시간 최소 형태**: 같은 입력으로 모형 A(하드)·B(벌점) 스위치 하나. 화면: 두 모형의 간트 + 「A 가 풀리지 않을 때 B 가 어긴 곳」 빨간 표시 + 벌점 슬라이더.
- **반문 하나**: 「Q-Time 은 규정이라 벌점으로 두면 안 된다」 → 운영 모형은 하드로 두고, B 는 불가능할 때 충돌을 설명하는 진단용이다.
- **하지 말 것**: Meituan 의 폐기 20% 감소는 신선식품 사례 수치다 — Q-Time 효과로 말하지 않는다(반도체 효과 수치는 근거 없음).

## 상세

**한 줄**: 「경영과학에서는 규칙 하나를 모형에 넣을 때 절대 어길 수 없는 하드 제약으로 둘지, 어기면 값을 치르는 벌점으로 둘지 가른다. 하드로 두면 위반 0건이 증명되지만 풀리지 않을 수도 있고, 벌점으로 두면 늘 풀리지만 얼마를 어긴 해가 나온다. 기한이 다가오는 재고를 이송·가격으로 처리해 폐기를 줄인 Meituan 사례처럼, Q-Time 상한이 다가오는 WIP 를 기한이 있는 재고로 바꾸면 Q-Time 임박 LOT 처리에 적용된다. 같은 데이터로 두 모형을 돌려 위반 수와 기대 손실로 비교한다.」
- **과제 문구 신호**(추론): 「Q-Time 을 넘기지 않게」「위반 0건」「폐기 손실」「긴급 LOT 이 끼면」 / 규정과 현실이 어긋난다는 말
- **가정 변환**

| 모형 | 반도체 |
|---|---|
| 하드 제약 | Q-Time 상한을 깰 수 없는 규칙으로 — 해가 없으면 INFEASIBLE |
| 벌점 | 상한 초과 확률 × (폐기·재작업·고객 위험 손실) — [관련원가](../../회계학/원가관리회계/01-관련원가와-증분분석.md)의 판정 논리와 같은 꼴 |
| 이송 | 임박 LOT 을 다른 동등 장비로 재배정 |
| 가격 조정 | 임박 LOT 의 디스패칭 우선순위 가산 |

- **원 분야 사실**:
  - 제약 프로그래밍 일정 문서 — Q-Time 을 하드로 걸면 INFEASIBLE 이 나올 수 있으니 「어느 제약이 충돌하나」를 보이려고 벌점 변형을 함께 돌린다.
  - Meituan(+GWU) 2025 Wagner 수상 발표: 「coordinate nighttime transshipment and dynamic pricing across thousands of micro fulfillment centers, reducing spoilage by 20% and improving profitability.」(EurekAlert 미러, E2, 자기 신고, 학회지 본문 미판독). 이 수치는 신선식품 사례의 것이다.
- **하이닉스 적용 예**(추론): Meituan 은 「반도체 문제와 구조가 가장 닮은 비반도체 사례」로 볼 수 있다 — Q-Time 임박 WIP 는 유통기한 임박 재고다. (a) 규정상 못 어기는 상한은 하드로, 현업이 회색 지대로 두는 상한은 벌점으로 둔다(유형 ②). (b) 하드 모형이 INFEASIBLE 일 때 벌점 모형으로 어느 LOT·어느 장비가 충돌하는지 보인다. 이 구조의 반도체 효과 수치는 **근거 없음**.
- **기준선과 지표**: 기준선 = 현행 우선순위 규칙(가정). 지표 = Q-Time 위반 건수(하드 모형은 0 또는 INFEASIBLE), 벌점 모형의 기대 손실, 임박 LOT 의 평균 남은 시간.
- **6시간 최소 형태**: 같은 입력으로 모형 A(하드)와 B(벌점)를 돌리는 스위치 하나. 화면 = 두 모형의 간트 + 「A 가 풀리지 않을 때 B 가 어긴 곳」 빨간 표시. 벌점 계수는 숨기지 말고 슬라이더로 둔다.
- **반론과 답**: 「Q-Time 은 규정이라 벌점으로 두면 안 된다」 → 운영 모형은 하드로 둔다. B 는 불가능할 때 무엇이 충돌했는지 설명하는 진단용이다. 「벌점 계수를 누가 정하나」 → 정하지 못하면 기대 손실 환산은 보류하고 위반 건수만 말한다(근거 없는 숫자를 지어내지 않는다).
