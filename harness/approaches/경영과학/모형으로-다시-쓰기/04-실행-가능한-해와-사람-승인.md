# 최적해보다 실행 가능한 해와 사람 승인 — 예측 → 처방 → 승인

> [모형으로 다시 쓰기](README.md) › 04 · 짝 기법: [제약 프로그래밍 일정](../../../methods/최적화/01-제약-프로그래밍-일정.md) CP-SAT 잡숍 · [최소 변경 재스케줄](../../../methods/최적화/03-최소-변경-재스케줄.md) 최소 변경 재스케줄 (+[질문을 파라미터로](../../../methods/최적화/05-질문을-파라미터로.md))
> 원 분야 사실에는 근거 등급을 달았고, 반도체로 옮긴 부분은 별도 표시가 없으면 **추론**이다. 모듈 주의는 [모듈 README](README.md), 표기는 [입구](../../README.md) 「표기」.

## 바로 쓰는 칸
- **쓸 점**: 솔버 안을 별도 검사기로 다시 세고, 안 2~3개 카드와 승인/반려 사유 로그를 붙여 실행 가능한 제안으로 낸다.
- **필요한 데이터**: 솔버 안의 스케줄 표(검사기는 솔버 변수 없이 이 표만으로 재계산) + 현행 일정. 현행 일정이 없으면 변경 수를 못 센다.
- **6시간 최소 형태**: 솔버 안 → 별도 검사기 → 안 3개 카드 → 승인/반려 + 사유 로그(승인 이력 CSV 한 개). 화면: 검사기 통과 배지 + 승인 버튼.
- **반문 하나**: 「사람 승인은 병목이다」 → 승인 대상을 안 2~3개로 줄이고, 각 안의 대가를 곡선 한 장으로 보인다.
- **하지 말 것**: 검사기를 데이터 교체 뒤에도 통과시키지 못하면 「위반 0건」을 쓰지 않는다.

## 상세

**한 줄**: 「경영과학에서는 모형의 최적해를 현장에 내려보낼 때 이 해가 현장 규칙을 실제로 지키는지, 현장이 받아들일 크기인지를 따로 확인하고 마지막 선택을 사람에게 둔다. 수상·결선작의 공통 골격이 「예측(ML) → 최적화 → 사람이 고르는 what-if」다. 솔버 결과를 별도 검사기로 다시 세고, 현행 일정에서 바뀐 정도를 목적에 넣고, 승인 버튼을 화면에 두면 일정 제안 서비스에 적용된다. 검사기 위반 건수와 현행 대비 변경 수로 보인다.」
- **과제 문구 신호**(추론): 「현장이 받아들이게」「사람이 최종 결정」「설명 가능」「기존 일정을 최대한 유지」「다시 짜면 다 바뀐다」
- **가정 변환**

| 모형의 말 | 현장의 말 |
|---|---|
| 최적해 | 솔버가 낸 안 — 아직 실행안이 아니다 |
| 실행 가능 | 독립 검사기가 겹침·정지창·선후·Q-Time 위반을 0건으로 센 안 |
| 변경 벌점 | 현행 일정에서 바뀐 LOT 수 — 현장 혼란의 대리 지표 |
| 승인 | 안 2~3개 중 사람이 고르고 사유를 남긴다 |

- **원 분야 사실**:
  - 2019~2026 수상·결선작 정리 — JD.com(2024 Wagner), Amazon(2025 결선), Google(2026 결선), OCP(2024 EURO EEPA)가 모두 예측 → 최적화 → 사람이 고르는 what-if 골격이다(INFORMS·EURO 발표, E2, 자기 신고).
  - 교란 뒤 복구는 [교란 뒤 최소 변경](../흐름과-변동으로-보기/04-교란-뒤-최소-변경.md)에서 다룬다. 솔버 결과를 솔버와 다른 코드로 다시 검사하는 것이 「위반 0건」 주장의 증거라는 점은 이 선반의 추론이다.
- **하이닉스 적용 예**(추론): (a) 일정 제안마다 검사기 통과 배지를 달고 승인·반려 버튼과 사유 기록을 둔다(유형 ①②). (b) 원본 무접촉·읽기 전용·감사 로그·사람 승인을 내부통제 언어로 설명한다([방법론 지도 §6](../../../methods/README.md)). (c) 설명문과 검사기 출력이 같은 숫자를 가리키게 한다 — 읽는 쪽이 설명문을 코드와 대조할 수 있다.
- **기준선과 지표**: 기준선 = 현행 일정(가정). 지표 = 검사기 위반 0건 여부, 현행 대비 변경 LOT 수, 안 3개의 KPI 차이.
- **6시간 최소 형태**: 솔버 안 → 별도 검사기(솔버 변수 없이 스케줄 표만으로 재계산) → 안 3개 카드 → 승인/반려 + 사유 로그. 승인 이력 CSV 한 개면 충분하다. 검사기를 데이터 교체 뒤에도 통과시키지 못하면 「위반 0건」을 쓰지 않는다.
- **반론과 답**: 「사람 승인은 병목이다」 → 승인 대상을 안 2~3개로 줄이고 각 안의 대가를 [곡선](02-목적이-둘이면-트레이드오프-곡선.md) 한 장으로 보인다. 「AI 가 알아서 하면 더 빠르다」 → 이 서비스는 결정을 대체하지 않고 근거를 준다. 어느 점을 고를지는 현업이 정한다.
