# 경영과학 — 학문 지도

> [입구](../README.md) › **경영과학**

**경영과학(OR)**은 자원이 모자란 결정을 모형으로 쓰고 계산해 선택지와 그 대가를 보여 주는 학문이다. 이 폴더는 「문제를 어떻게 다시 읽나」를 다루고, 기법과 코드는 별도 선반에 있다.

## 하위 분야 지도
갈래 목록은 교과 일반의 OR 분류와 경영과학·OR 트렌드 조사의 무기 표를 따랐다. 정의와 반도체 연결 칸은 추론이다. 우리 모듈 칸이 → 로 시작하면 챕터는 없고 기법·코드 선반의 모듈로 넘긴다.
