# 어디를 잴까 — 희소한 점검 자원과 불확실성

> [흐름과 변동으로 보기](README.md) › 05 · 짝 기법: [계측 샘플 배분](../../../methods/품질과-신뢰성-통계/04-계측-샘플-배분.md) 밴딧 계측 배분 (+[관리도와 오경보 주기](../../../methods/품질과-신뢰성-통계/01-관리도와-오경보-주기.md) SPC)
> 원 분야 사실에는 근거 등급을 달았고, 반도체로 옮긴 부분은 별도 표시가 없으면 **추론**이다. 모듈 주의는 [모듈 README](README.md), 표기는 [입구](../../README.md) 「표기」.

## 바로 쓰는 칸
- **쓸 점**: 계측 슬롯이 모자랄 때 추정 불량률과 불확실성을 합친 지수 순으로 어느 챔버·LOT 을 잴지 배분한다.
- **필요한 데이터**: 챔버·레시피·LOT 군별 과거 검사 결과(검사 수, 불량 수)와 이번 교대 슬롯 수. 과거 검사 결과가 없으면 못 쓴다.
- **6시간 최소 형태**: 베타-이항 경험적 베이즈 + UCB 지수(numpy 수십 줄), 라운드별 갱신. 화면: 챔버별 추정 불량률·신뢰구간 + 이번 교대 슬롯 배분.
- **반문 하나**: 「반사실을 어떻게 아나」 → 로그에 선택 확률이 있어야 IPW 가 되는데 합성이면 약하다. 비교는 시뮬레이션 안에서만 한다.
- **하지 말 것**: Eva 의 1.85배는 그리스 코로나 검사 수치이지 하이닉스 효과가 아니다. 슬롯이 넉넉하면 이득이 작아진다.

## 상세

**한 줄**: 「경영과학에서는 검사 능력이 모자라 모두 볼 수 없을 때 한정된 검사를 어디에 쓸지를 순차 의사결정(제약 있는 배치형 밴딧)으로 푼다. 핵심 논리는 「추정 위험(활용)과 불확실성(탐색)을 합친 지수 순으로 배분하고 결과가 들어오면 갱신」이고, 표본이 적은 그룹의 비율은 전체 평균 쪽으로 수축한다(경험적 베이즈). 입국자 유형을 챔버·레시피·LOT 군으로, 검사를 계측 슬롯으로 바꾸면 계측 샘플링과 알람 조사 배분에 적용된다. 같은 슬롯으로 찾아낸 불량 수로 보인다.」
- **과제 문구 신호**(추론): 「계측 능력이 모자라다」「어느 LOT 을 먼저 잴까」「샘플링 비율」「어느 챔버를 먼저 점검」
- **가정 변환**

| 원 분야(Eva) | 반도체 |
|---|---|
| 국경 40곳의 PCR 검사 한도 | 교대당 계측 슬롯 |
| 입국자 유형 | 챔버·레시피·LOT 군 |
| 무증상 감염자 | 계측으로 잡히는 불량 |
| 검사 결과가 며칠 뒤 도착(지연 피드백) | 계측 결과가 다음 라운드에 반영 — 지연 정도는 미확인 |
| 표본 적은 유형 | 신호가 적은 챔버 — 불량률을 전체 평균 쪽으로 수축 |

- **원 분야 사실**:
  - Eva(그리스 정부, Bastani·Drakopoulos·Gupta)는 *Nature* 599:108–113(2021)에서 무작위 검사 대비 무증상 감염자를 1.85배(성수기 2~4배), 역학 지표만 쓰는 정책 대비 1.25~1.45배 찾았다(E2, 피어리뷰).
  - 반사실 성능은 역확률 가중(IPW)으로 추정했다. 조건문: 「Eva’s targeting is most effective when tests are scarce.」 비수기에는 무작위 검사가 Eva 의 54.1% → 73.4% 까지 따라왔다.
  - Gittins 지수를 쓴 이유는 「a simple, deterministic risk metric for each type that incorporates both estimated prevalence and corresponding uncertainty」 — 해석 가능성 때문이다.
  - **1.85배는 그리스 코로나 검사의 수치이지 하이닉스 효과가 아니다.**
- **하이닉스 적용 예**(추론): (a) 계측 슬롯이 모자랄 때 어느 챔버·LOT 을 잴지(유형 ③④). (b) 이상 알람 조사 배분. 「이상인가」를 판정하는 SPC(관리도와 오경보 주기)와 달리 「어디를 잴까」에 답한다. 계측 샘플링이 감사 표본추출과 같은 구조라는 점은 [감사 표본추출](../../회계학/회계감사/01-감사-표본추출.md)과 이어진다.
- **기준선과 지표**: 기준선 = 무작위 샘플링과 현행 규칙(가정). 지표 = 같은 슬롯 수로 검출한 불량 수, 슬롯이 줄수록 벌어지는 격차, 챔버별 추정 불량률과 신뢰구간.
- **6시간 최소 형태**: 베타-이항 경험적 베이즈 + UCB 지수(numpy 수십 줄, 계측 샘플 배분), 라운드별 갱신. 화면 = 챔버별 추정 불량률·신뢰구간 + 이번 교대 슬롯 배분. 합성 데이터로 시연하면 무작위 대비 이득은 가정 안에서만 성립함을 적는다.
- **반론과 답**: 「반사실을 어떻게 아나」 → 로그에 선택 확률이 있어야 IPW 가 되는데 합성 데이터면 의미가 약하다(설명·질의응답용으로만 쓴다). 비교는 시뮬레이션 안에서만 하고 실데이터 효과로 말하지 않는다. 「탐색에 쓴 슬롯은 낭비 아닌가」 → 불확실성이 큰 곳을 먼저 확인하는 것이므로 낭비가 아니고, 슬롯이 넉넉하면 이득이 작아진다는 점이 원문의 조건문이다.
