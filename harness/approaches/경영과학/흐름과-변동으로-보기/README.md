# 흐름과 변동으로 보기 — 학문 지도

> [입구](../../README.md) › [경영과학](../README.md) › **흐름과 변동으로 보기** · 챕터 5
> 한 줄: **경영과학**은 공장을 평균이 아니라 흐름과 변동으로 본다. 줄은 가동률이 오르면 비선형으로 길어지고, 처리량은 병목 하나가 정하고, 교란이 오면 계획이 흔들린다.
> **주의**: 이 모듈은 흐름과 변동을 「어떻게 읽나」만 다룬다. 계산과 코드는 [기법·코드 선반](../../../methods/README.md)(디스패칭 규칙 시뮬레이션~몬테카를로·병목 분석·강건·시나리오 계획·최소 변경 재스케줄·계측 샘플 배분)에 있다. 효과 수치는 모두 기업·팀의 자기 신고이며, 반도체 특화 강건·확률 계획 운영 사례는 조사에서 찾지 못했다(근거 없음).

## 핵심 질문
**평균이 아니라 분포와 꼬리는 어떤가? 어디가 병목이고, 가동률을 어디까지 올려도 되나? 교란이 오면 얼마나 바뀌나?**

## 이럴 때 꺼낸다 / 옆 모듈로
- **꺼낸다**: 사이클타임·대기·WIP 를 줄이라는 과제 · 장비를 늘릴지 믹스를 바꿀지 · 고장·긴급 LOT 에도 버티는 일정 · 계측 슬롯이 모자랄 때.
- **옆 모듈로**
  - 변수·목적·제약으로 쓰기, 트레이드오프 곡선 → [모형으로 다시 쓰기](../모형으로-다시-쓰기/README.md)
  - 가정이 틀릴 때의 민감도 → [모형을 믿어도 되나](../모형을-믿어도-되나/README.md)
  - 시간동인 ABC·병목 시간의 원가 → 회계학 › [원가관리회계](../../회계학/원가관리회계/README.md)
  - 현장 직무의 눈으로 본 흐름 → 반도체 현장 › [흐름·설비·계획](../../반도체-현장/흐름-설비-계획/README.md)
  - 고장·보전 정책(Weibull, 연령교체) → 신뢰성과 보전 주기 신뢰성·보전

## 핵심 개념어
- **리틀의 법칙**: WIP = 처리율 × 사이클타임.
- **X-factor**: 사이클타임을 순수 공정시간으로 나눈 값.
- **변동계수**: 표준편차/평균. 클수록 같은 가동률에서 대기가 길다.
- **병목 / 그림자 가격**: 처리량을 묶는 자원 / 그 자원 1시간의 처리량 가치.
- **p90**: 열 번 중 아홉 번은 이 안에 드는 값.
- **동결 / 변경 벌점**: 이미 시작한 공정은 그대로 두고, 현행에서 바뀐 정도를 목적에 넣는다.
- **경험적 베이즈 수축**: 표본이 적은 그룹의 비율을 전체 평균 쪽으로 당긴다.

## 관점 쌍
- **평균 ↔ 분포**: 같은 평균 일정도 꼬리가 다르다([03](03-평균-말고-분포로-말한다.md)).
- **가동률 ↔ 사이클타임**: 처리량을 얻는 값이 대기다([01](01-가동률을-높이면-대기가-폭증한다.md)).
- **병목 ↔ 비병목**: 병목 1시간은 공장 1시간, 비병목 시간은 처리량에 보태지 않는다([02](02-병목만-처리량을-정한다.md)).
- **사전 대비 ↔ 사후 복구**: 강건 계획은 미리, 최소 변경은 일이 난 뒤([03](03-평균-말고-분포로-말한다.md), [04](04-교란-뒤-최소-변경.md)).
- **활용 ↔ 탐색**: 이미 위험해 보이는 곳과 아직 모르는 곳을 함께 잰다([05](05-어디를-잴까-희소한-점검과-불확실성.md)).

## 이 분야 사람이 먼저 묻는 것 5
1. 병목이 어느 장비군이고, 그 가동률은 곡선의 어느 지점인가?
2. 평균만 보고 있지 않나? p90 과 최악은?
3. 변동계수는 실측했나, 지수분포를 가정했나?
4. 교란이 오면 현행 대비 몇 LOT 이 바뀌나?
5. 비교한 시나리오는 계획에 쓰지 않은 새 시나리오인가?

## 흔한 함정
- 공시 가동률을 장비 가동률 곡선의 u 에 그대로 넣는다. 인원·수율 기준이라 OEE 가 아니다([01](01-가동률을-높이면-대기가-폭증한다.md)).
- 병목을 한 번 찾고 고정한다. 믹스에 따라 이동한다([02](02-병목만-처리량을-정한다.md)).
- 분포를 지어내서 시나리오를 만들고 평균 최적 과적합을 본다([03](03-평균-말고-분포로-말한다.md)).
- 항공 사례의 효과(€12M 등)를 변경 최소화 항의 효과로 읽는다([04](04-교란-뒤-최소-변경.md)).
- 그리스 검사 사례의 1.85배를 하이닉스 계측 효과처럼 말한다([05](05-어디를-잴까-희소한-점검과-불확실성.md)).
