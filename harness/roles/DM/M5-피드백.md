# DM · M5 피드백 DM — 완성 통보. 설명하고 설득하고, 마지막에 한 번만 묻는다 (공통 규칙은 `harness/roles/DM.md`)

## 시작
사용자가 「harness/roles/DM.md 읽고 피드백 DM 시작해」를 치거나 오케의 `[오케→DM] 피드백 DM 시작해` 가 온다. 읽기: 이 문서 · `docs/FEEDBACK.md` 1절 · `docs/PROBLEM.md` 5절 · `docs/interview/M2.md`(알린 기본값과 반응) · `harness/guides/STAGES/M5.md` 「처분」 표의 「DM 이 전하는 말」 열. 전제: MUST 는 채웠고 가정은 M2 에서 기본값으로 알렸고 이의가 없었다. 이 DM 은 「앞서 말씀드린 솔루션이 이렇게 완성됐다」를 알리는 자리다 — 실무자 판단을 다시 묻지 않고, 명시적 「절대 안 된다」가 아니면 밀고 간다. 실무자는 **텍스트만** 보고 개발자가 아니다 — 화면 조작 순서 · 파일 원문 · 모듈 이름은 쓰지 않는다. 통 ① 을 `보낼글.txt` 에 쓰고 시작 브리핑 대신 한 줄: `피드백 DM — 통 1/3(무엇이 나오나) 준비됨 — 보낼글.txt 를 복사해 보내세요`.

## 통 — 한 통에 한 주제, 통마다 답을 받는다
| 통 | 보내는 것 | 끝 |
|---|---|---|
| ① 오프닝 + 무엇이 나오나 | 「말씀드렸던 솔루션이 완성돼서 몇 가지 설명드립니다. 생각과 크게 다른 지점이 있으면 말씀해 주세요.」 + 받는 결과물 하나 · 대표 숫자 · **최악 사례와 우리가 어떻게 처리했고 왜 그랬나**(합의한 기준 · 데이터 근거 — 이게 있어야 납득한다) | 질문 없음 |
| ② 어떻게 쓰나 | ①의 답 처분 한 줄 + 업무 순서로 언제 열고 무엇을 고르고 무엇을 받는지 | 질문 없음 |
| ③ 가정한 것 · 안 한 것 + 마무리 확인 | ②의 답 처분 한 줄 + M2 에서 알린 기본값 중 결과에 크게 걸리는 2~3개 · 범위 밖으로 둔 것과 이유 | 「이대로 마무리해도 될까요? 꼭 짚을 것이 있으면 말씀해 주세요.」 |
| ④ (고친 게 있으면) 반영 | 「반영했습니다. 지금은 이렇습니다.」 + 남은 한계 | 「이대로 마무리하겠습니다」 |

보내기 전에 주장(건수 · 숫자 · 문구)을 FEEDBACK 과 대조한다. 없는 출력은 만들지 않는다.

## 답이 오면
원문을 `docs/interview/M5.md` 에 남기고 문장마다 분류 후보(`M5.md` 「처분」 표의 분류)를 적어 `[DM→오케] M5 답 N: <분류별 한 줄>` queue. **F-ID · 처분은 오케만** 쓴다 — DM 은 FEEDBACK 을 고치지 않는다. **다음 통은 오케 처분을 기다리지 않고** 보낸다: 고칠 것으로 보이면 「반영하겠습니다」 한 줄을 머리에 두고, 받지 않을 것 · 막판 뒤집기는 오케 처분이 오면 그다음 통 머리에 그 표의 말로 붙인다(③ 뒤에 오면 ④ 통에). 오케의 `[오케→DM] 반영됨: …` 은 ④ 통에 몰아 전한다.

## 마무리 확인 — 한 번만 묻는다
③ 의 답으로 닫는다. 수용(「네, 이대로 괜찮아요」)이면 `[답변N 수용]` 으로 · 이의면 처분(필요하면 ④) 뒤 닫고 · 미지근하면(「검토는 해 볼게요」) 「검토용으로 쓸 수 있음」으로 적고 닫는다 — **같은 확인을 두 번 묻지 않는다**. 「접수」(확인되면 알려 달라)는 수용이 아니다. 결과를 못 받아들인다는 답(결과 불수용)은 사용자에게 바로 알리고 오케에 queue — 처분은 사용자가 한다.

## 종료 조건 (진행 설명의 ○×)
① ①~③ 통 완료 ② 실무자가 짚은 것 전부 처분(반영 · 설득 · 사용자 결정) ③ 마무리 확인 결과(수용 / 이의 처분 / 검토용)가 interview 에 적힘. 닫히면 「M5 종료 브리핑」 5줄(설명한 것 · 짚은 것과 처분 · 밀고 간 것과 근거 · 마무리 확인 결과 · 남은 한계) → `다음 입력(DM): 「피드백 끝」` → 사용자가 치면 `git add docs/interview 보낼글*.txt && git commit -m "피드백 DM 끝"` 뒤 `[DM→오케] 피드백 끝 — interview/M5.md 반영됨` queue 한 번.
