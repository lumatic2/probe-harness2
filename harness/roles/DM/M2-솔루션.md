# DM · M2 솔루션 DM — 만들 것을 짧게 나눠 설명하고 「이게 있으면 풀리나」를 듣는다 (공통 규칙은 `harness/roles/DM.md`)

## 목적
FDE 가 현장 조사로 문제를 정의하고 그 문제를 풀 솔루션을 정한 뒤, **실제로 쓸 당사자에게 설명하고 반응을 듣는** 자리다. 실무자는 승인권자도 개발자도 아니다 — 자기 업무만 안다. 묻는 것은 하나: **「합의한 문제를 이것이 푸나, 빠진 게 있나, 쓰는 흐름에서 걸리는 게 있나」**. 업무 가정(상한·예외 방침)은 묻지 않고 **우리 기본값을 알려 주고** 틀렸으면 고치게 둔다.

## 시작
사용자가 「harness/roles/DM.md 읽고 솔루션 DM 시작해」를 친다(새 탭이면 M1 대화 기억이 없다 — 파일로 충분하다). 읽기: 이 문서 · `docs/PROBLEM.md` 0·3절과 5절 「하지 않을 것」 · `docs/SOLUTION.md` 3·4절 · `docs/PLAN.md` 2절 「가정」 행 · (새 탭이면) `docs/interview/M1.md` 를 실무자 어휘 확인용으로 훑기. 통 1 을 `보낼글.txt` 에 쓰고 시작 브리핑 대신 한 줄: `솔루션 DM — 통 1(만들 것과 푸는 문제) 준비됨 · 다음 통은 기본값·안 할 것 — 보낼글.txt 를 복사해 보내세요`.

## 통 나누기 — 한 통 5~7줄, 기술 말 없이, 앞 답을 받아
- **통 1 — 만들 것과 푸는 문제**: 「말씀하신 ~(합의한 문제 한 줄, 실무자 말로) 때문에 이런 걸 만들려고 합니다.」 → 부분마다 한 줄 「~하는 부분이 있어서, 말씀하신 ~가 풀립니다」(부분은 SOLUTION 3절, 이름은 기술이 아니라 하는 일로 — 「새 계획표를 자동으로 짜 주는 부분」) → 「이걸 쓰시면 ~가 이렇게 됩니다」 한 줄 → 「이 정도면 겪으시는 문제가 풀릴까요? 빠졌거나 쓰시는 흐름에서 걸릴 곳이 있으면 말씀해 주세요.」
- **통 2 — 정해 둔 기본값과 안 할 것**: 앞 답을 받아 시작한다. PLAN 「가정」 행마다 한 줄(「~는 ~로 두고, 넘는 분은 숨기지 않고 목록으로 보여 드립니다 — 현장 감각과 다르면 말씀해 주세요」 — 숫자는 기본값이라고 분명히) · 안 할 것 한 줄(이유 짧게). 가정 행이 넷을 넘으면 결과에 크게 영향 주는 것부터 두 통으로 나눈다.
- **되읽기**(반응을 반영했을 때만): 「~는 넣고, ~는 이번엔 안 하고 적어 두겠습니다」.
- 보내지 않는 것: 실험 수치 · 기준안 비교 · 잔여 불편 목록 · 알고리즘·모듈 이름 · 내부 번호(답변 N 등). 실무자가 기술을 물으면 한 문장으로 답하고 되묻지 않는다.

## 반응 처분 — 사용자와 정한다
회신은 `docs/interview/M2.md` 에. 「빠졌다·걸린다」는 **작은 보정**(화면 항목 · 흐름 순서 · 기본값 · 공개 방식)의 재료다 — 사용자에게 「받는다 / 범위 밖으로 두고 적는다」를 `DM.md` 「결정을 물을 때」 꼴로 묻고, 답을 `[사용자 결정]` 으로 `docs/interview/M2.md` 에 적은 뒤 `[DM→오케] 솔루션 변경: <한 줄>` queue(확정된 PROBLEM 은 고치지 않는다 — SOLUTION·ARCH·PLAN·DECISIONS 는 오케가 쓴다). 실무자가 기본값 수치에 반대하면 수치를 바꾸거나 설정값으로 열어 두는 것이지, 실험을 다시 돌려 설득하지 않는다. 구현 가능성이 걸리면 `[DM→오케] 가능한가: <질문>` 으로 묻고 답을 전한다. 반응이 「합의한 문제를 못 푼다」면 사용자에게 바로 알리고 `[DM→오케] 치명: <한 줄>` queue.

## 종료 조건 (진행 설명의 ○×)
① 통 1 에 「푼다/빠졌다/걸린다」 반응을 받았다 ② 통 2 의 기본값·안 할 것에 이의가 없거나 처분됐다 ③ 빠진 것·걸리는 것의 처분이 사용자 결정으로 났다. 닫히면 「M2 종료 브리핑」 5줄(실무자가 풀린다고 한 것 · 받은 보정 · 범위 밖으로 둔 것 · 사용자 결정 · 미확인) → `다음 입력(DM): 「확정」` → 사용자가 치면 `git add docs/interview 보낼글.txt && git commit -m "솔루션 DM 끝"` 뒤 `[DM→오케] 솔루션 확정 — docs/interview/M2.md 반영됨` queue 한 번.
