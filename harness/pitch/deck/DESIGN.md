# 덱 디자인 규칙

> `index.html` 에 실제로 들어 있는 값을 적은 문서다(2026-11-10 기준). 장을 더하거나 다른 발표로 넓힐 때 이 표에서 고른다. 값이 바뀌면 `index.html` 을 먼저 고치고 여기를 맞춘다. 장 구성과 말은 `../스크립트-구조.md`.

## 바탕 생각
- 청중은 화면이 아니라 발표자를 본다. 한 장에 메시지 하나, 글자는 최소.
- 대회 키비주얼(검은 바탕 위 붉은빛·주황빛 매듭)과 같은 세계로 보이게 한다.
- 색은 아껴 쓴다. 한 장에서 색이 들어간 글자는 키커 하나, 강조는 한 군데.

## 캔버스
- 1920×1080 고정. 창 크기에 맞춰 통째로 줄이고 늘린다.
- 바깥 여백: 좌우 110px. 키커는 위에서 92px, 장 제목은 170px, 본문 덩어리는 300px 부근에서 시작, 아래 글줄은 바닥에서 104px.
- 왼쪽 정렬이 기본. 가운데 정렬은 닫기 장과 2장 결론 줄만.

## 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `--ink` | `#fff` | 본문 글자, 발표자 이름 |
| `--sub` | `#b9b2b0` | 보조 설명, 상자 아래 설명, 1장 아래 한 줄 |
| `--dim` | `#7d7573` | 상자 번호, 화살표, 빈 틀 안내 |
| `--kick` | `#ff4d6a` | 키커(「01 접근방식」 같은 장 꼬리표), 표지 대회명. 다른 곳에 쓰지 않는다 |
| `--accent` | `#ff6600` | 강조 한 군데: 「사람이 결정」 상자 테두리, 결론 화살표, 예측 꼬리표 테두리 |
| `--warm` | `#ff9a3d` | 주황 글자: 강조 상자 번호, 예측 꼬리표 글자 |
| `--line` | 흰색 16% | 상자·틀 테두리 |
| `--panel` | 흰색 4.5% | 상자·틀 바탕 |
| 바탕 | `#050203` | 배경 그림이 안 뜰 때 |

- 제목(HiKR)은 흰색에서 살구색(`#ffd9c2`)으로 내려가는 세로 그라데이션.
- 발표자 이름은 붉은색을 쓰지 않는다.
- 측정 숫자는 흰 꼬리표, 예측 숫자는 주황 꼬리표. 둘을 색으로도 가른다.

## 글자

| 역할 | 서체 | 크기 / 굵기 |
|---|---|---|
| 서비스 이름(표지) | HiKR ExtraBold | 180 |
| 서비스 이름(닫기) | HiKR | 150 |
| 1장 한 문장 | HiKR | 116, 줄 간격 1.1 |
| 큰 숫자 | HiKR | 128 (단위는 SUIT 44/700) |
| 장 제목 | SUIT | 60/800 (부록 56/800) |
| 결론 한 문장 | SUIT | 54/800 |
| 닫기 핵심 문장 | SUIT | 46/600 |
| 상자 제목 | SUIT | 40/800 |
| 표지 부제 | SUIT | 36/600 |
| 표지 대회명 줄 | SUIT | 38. 「대회명(붉은색 700) \| 이름(흰색 600)」 한 줄 |
| 아래 한 줄(1장) | SUIT | 34/500 |
| 키커 | SUIT | 30/700 |
| 설명·숫자 설명 | SUIT | 25~30/500~600 |
| 꼬리표·상자 번호 | SUIT | 22/700 |

- HiKR 은 「기억시킬 글자」에만: 서비스 이름, 1장 문장, 큰 숫자. 나머지는 전부 SUIT.
- 가장 작은 글자가 22px 이다. 그보다 작게 쓰지 않는다(뒷자리에서 안 읽힌다).
- 줄바꿈은 낱말 단위(`word-break:keep-all`). 제목 줄바꿈은 `<br>` 로 직접 정한다.
- 긴 줄표(엠대시)를 쓰지 않는다. 가운뎃점(·)이나 쉼표, 줄바꿈으로 가른다.
- 채울 자리는 `⟨ ⟩` 로 감싼다. 당일 이 괄호째 바꾼다.
- 글자가 자리를 넘으면 `index.html` 끝의 `fitAll` 이 그 글자만 2px 씩 줄인다(바닥 22px). 한 줄짜리(서비스 이름·장 제목·큰 숫자)는 폭, 나머지는 덩어리 높이가 기준이다. 새 부품을 더하면 `fitAll` 에 한 줄을 더한다.

## 배경
- 세 장: `assets/bg/cover-bg.jpg`(표지, 오른쪽에 매듭) · `closing-bg.jpg`(닫기, 아래쪽에 매듭) · `content-bg.jpg`(내용 장, 거의 검정에 오른쪽 아래 구석 빛줄기).
- 원본 1672×941 을 화면에 꽉 채워(`cover`) 쓴다. 다시 뽑을 땐 `assets/bg/프롬프트.md`.
- 글자는 그림의 어두운 쪽에 둔다. 표지는 왼쪽 1050px 안, 닫기는 위쪽.
- 내용 장에는 무늬 없는 판을 쓴다(점 무늬 판은 써 보고 물렸다).
- 경로는 전부 `deck/` 기준 상대 경로(`assets/…`)다. `../` 로 폴더 밖을 가리키지 않는다(폴더째 옮겨도 뜨게).

## 부품

| 부품 | 클래스 | 규칙 |
|---|---|---|
| 키커 | `.label` | 「번호 + 이름」. 왼쪽 위 고정. 붉은색 |
| 장 제목 | `.title` | 한 줄. 문장으로 쓴다(명사 나열 금지) |
| 큰 문장 | `.h` | HiKR. 두 줄까지 |
| 아래 한 줄 | `.note` | 왼쪽 아래. 보조색 |
| 흐름 상자 | `.flow` `.box` `.arrow` | 3~5개 한 줄. 상자마다 번호·제목(두 줄)·설명. 제목은 쓰는 사람의 동작 |
| 강조 상자 | `.box.human` | 한 장에 하나. 사람이 결정하는 자리 |
| 결론 줄 | `.concl` | 아래 화살표 + 한 문장. 가운데 |
| 캡처 틀 | `.cap` | 1010×568(16:9). 실제로 돈 화면만. `deck/assets/capture.png` |
| 큰 숫자 | `.num` | 이름 + 꼬리표 / 값 + 단위 / 근거 한 줄. 한 장에 둘까지 |
| 꼬리표 | `.tag` `.tag.pred` | 측정 / 예측 |
| 로고줄 | `.logos` | 표지에만. 높이 34px, SK hynix 만 56px, 간격 46px |
| 부록 본문 | `.apx .body` | 점선 틀. 굵은 글자만 흰색 |

- 모서리 둥글기 16~18px, 테두리 1px(강조만 2px). 그림자·그라데이션 상자는 쓰지 않는다.
- 쪽 번호는 넣지 않는다. 오른쪽 아래는 비워 둔다.
- 폰트 출처 표기는 넣지 않는다.

## 장을 더할 때
1. `bg-body` 배경에 키커 + 장 제목으로 시작한다.
2. 본문은 위 부품에서 고른다. 새 부품이 필요하면 색·둥글기·테두리를 이 표에 맞춘다.
3. 한 장에 강조색은 한 군데, HiKR 은 한 덩어리.
4. 넣은 뒤 1920×1080 으로 찍어 본다(글자 넘침, 배경 밝은 곳과 겹침).
5. 장은 `display` 가 아니라 `visibility` 로 가린다(전 장을 미리 그려 배경이 늦게 뜨지 않는다). 부록 첫 장의 `data-apx` 는 지우지 않는다(그 앞 장이 닫기로 잡힌다).

## 다른 발표로 옮겨 쓸 때
- 바꾸는 것: 배경 3장, 로고줄, 표지 대회명, `--kick`·`--accent`·`--warm` 세 색.
- 그대로 두는 것: 캔버스·여백·글자 크기 표·부품 규칙.
- HiKR 은 대회 포스터 제목과 맞춘 서체다. 다른 행사에서는 제목 서체를 그 행사에 맞게 바꾸고 본문 SUIT 는 둔다.
