# Overlay — 겹쳐서 맞춘다

> 브랜드 후보 1/3. 초안 2026-11-10, 문구 사용자 확정 전. 인용 번호(⑤-1 류)와 「전략 한 장」은 준비 때 쓴 문서의 것이다 — 그 문서는 이 킷에 없으니 찾지 않는다.

## 한 줄
**흩어진 데이터와 부서마다 다른 해석을, 한 화면 위에 겹쳐 맞춘다.**

## 단어의 뜻
- 일반: 위에 겹쳐 올리다, 덧씌운 층.
- 반도체 현장: 노광 공정의 **오버레이** — 새로 찍는 층의 패턴이 아래층 패턴 위에 얼마나 정확히 겹쳐 정렬됐는가(층간 정렬). 맞지 않으면 회로가 어긋난다. 팹 엔지니어에게 이 단어는 「정렬 정확도」로 먼저 읽힌다.
- 이름의 이중 읽기: 「층을 겹친다(데이터·관점)」 + 「어긋나지 않게 맞춘다(정의·해석)」.

## 브랜드 서사 연결점
| 연결 대상 | 이어지는 방식 |
|---|---|
| Over 시리즈 「Beyond default」 | 기본값 = 부서마다 따로 보는 숫자. 그 위에 한 층을 더 올려 같은 정의로 본다 |
| 현장 고통 ⑤-1 「동일한 데이터를 보더라도 부서마다 해석이 다를 수 있기 때문에 “어떻게 타 팀을 논리적으로 설득할 것인가”를 항상 고민한다」 | 해석이 어긋난 상태 = 오버레이 오차. 이 도구는 그 오차를 줄인다 — **비유가 문제 정의와 바로 붙는다** |
| 3대 미래 역량 ③ 사고적 다양성(②-3) | 여러 부서·여러 분야 관점을 한 장에 겹친다 |
| 전략 한 장 「거인의 어깨」 | 경영과학·원가회계 같은 다른 분야 기법을 반도체 데이터 위에 겹쳐 올린다 |
| 회사 원칙 ⑥-1 「AI가 원인과 대응 방안을 제시하고, 사람은 최종 판단」 | AI 의 제안은 사람이 보는 화면 위에 덧씌운 층 — 원본은 건드리지 않는다(원본 무접촉 원칙과도 맞음) |

## 피칭에서 쓰이는 자리
- 표지: `Overlay` + 부제 한 줄(⟨과제 공개 후: 무엇을 겹치는가⟩).
- 여는 15초 예: 「팹에서 오버레이는 층과 층이 어긋나지 않게 맞추는 일입니다. 저희는 부서와 부서 사이의 오버레이를 맞췄습니다.」
- 닫는 말 예: 「같은 숫자를, 같은 정의로, 한 화면에서.」

## 과제와의 궁합
- 잘 맞음: 여러 데이터 원천·여러 부서가 얽힌 과제(수율 원인 분석, 양산 계획, 품질 이상 대응, 리포트 자동화).
- 어색함: 단일 모델 성능 경쟁(리더보드형)이나 한 사람만 쓰는 도구. 이때는 「데이터 층을 겹쳐 원인을 찾는다」로 좁혀 말해야 한다.

## 주의
- UI 용어(오버레이 창)로도 흔해 일반인에겐 평범하게 들린다 — 반도체 뜻을 첫 문장에서 반드시 말한다.
- 노광 공정 설명을 길게 하면 배경 설명에 시간을 쓴다(H7 감점). 한 문장만.
- 공정 용어를 비유로 쓸 때 틀린 설명을 하면 현업 심사위원에게 바로 걸린다. 「층간 정렬」 이상으로 깊게 말하지 않는다.
