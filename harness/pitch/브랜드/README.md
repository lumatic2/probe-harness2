# 브랜드 이름 후보 — 본선 결과물·덱의 이름

> 2026-11-10 사용자와 논의해 3개로 좁혔다. 하나를 골라 덱 표지·서비스 이름으로 쓴다. 문구는 사용자 확정 전 초안.

## 출발점
- Over 시리즈 — 「Beyond default, in every direction.」 Over- 단어 하나를 도메인 하나에 붙이는 사용자 개인 브랜드 체계. 원래 쓰려던 **Overture**(음악 몫, 「서곡·먼저 내미는 제안」)는 서비스 이름으로 와닿지 않아 내려놓았다 — 피칭 여는 말의 비유로는 남겨 둘 수 있다.
- 시각은 하이닉스 디자인(`harness/guides/DESIGN.md`)과 대회 키비주얼(덱 배경 `../deck/assets/bg/`)을 따른다.

## 고르는 기준 (논의용)
1. 3분 안에 이름을 한 번 설명하면 끝까지 기억되는가.
2. 과제가 무엇이 나와도 붙는가 — 이름이 특정 해법을 미리 정해 버리면 당일 과제와 어긋날 수 있다.
3. 회사 언어(사람 최종 판단 · 같은 데이터 다른 해석 · 3대 미래 역량)와 몇 개가 바로 이어지는가.
4. 뜻이 갈려 오해될 위험.
