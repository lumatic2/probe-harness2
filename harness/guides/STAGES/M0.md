# M0 — 세팅 (오케)

## 핵심 4줄
- 목표: 과제 원문을 보존한 채 킷을 작업 공간에 깔고 첫 커밋을 남긴다
- 종료 조건: `scaffold` 커밋 · 세팅 보고 ①~④ 전달 · 스킬이 목록에 보인다
- 담당: 오케
- 증거: `scaffold` 커밋 · 세팅 보고 · `docs/세션.txt` 오케 줄

## 세팅 요청
1. 레포를 작업 공간 안 `probe-harness2/` 에 클론한다. 못 찾거나 clone 이 막히면 URL 을 지어내지 않고 사용자에게 알린다.
2. `bash probe-harness2/setup.sh` 를 **고치지 않고 그대로** 돌린다. setup.sh 는 작업 공간 밖에 아무것도 쓰지 않고, 지우는 것은 작업 공간 안의 클론 폴더뿐이다 — 「이 안에서만」 지침과 부딪히지 않으니 일부를 빼거나 복사본을 만들어 돌리지 않는다.
3. setup.sh 출력 맨 끝 「다음(에이전트)」 지시를 그대로 따른다 — 세팅 뒤 할 일의 정본은 그 출력 하나다. 세팅 보고에는 보고 ①~④ · 스킬 확인 줄 · **설명 탭 여는 문장** · `다음 입력(오케): 「과제 시작하자」` 가 다 들어간다.

다음 신호 「과제 시작하자」 → `M1-과제설정.md`.
