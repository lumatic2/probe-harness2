# DESIGN.md — 결정 화면 디자인 규약

> UI 코드를 쓰기 전에 읽는다. 산출물은 마케팅 페이지가 아니라 **실무자가 매일 여는 내부 운영 도구**다. 목표는 "예쁘다"가 아니라 **30초 안에 오늘 뭘 할지 보인다**.
> **화면 출발점**: 기본 = `bash harness/starter/shadcn/make.sh src/ui` 로 M2 「OK」 때 스캐폴드 서브에이전트가 세우는 shadcn 앱(폴더는 항상 `src/ui/`)(페이지 6개 + 도메인 설정으로 켜는 8개(일정 격자 `#/schedule` · 문서 검토 `#/review` · AI 기능 `#/assist` · CSV 가져오기 `#/import` · 기준값 `#/settings` · 데이터셋 `#/datasets` · 실행 `#/run` · 노드 그래프 `#/graph`) + 로그인·내 정보 · 위젯 19종(W17 = AI 대화창 · W18 = 녹음·전사 · W19 = 노드 그래프, React Flow) · SK 색 · 한국어, 약 1분). npm 이 막히면 화면 없이 API·CSV 출력으로 가고 `$decision` 한 줄. 출발점은 사용자만 바꾼다(AGENTS 원칙 8).
> **새 과제 데이터로 바꾸기**: 열·상태·지표·안내문은 `harness/starter/domains/<이름>/domain.json` 한 곳에서 정하고 화면 코드는 그대로 둔다 — 순서는 `harness/starter/DOMAIN.md`. 화면 커버리지·실전 결과 연결·로딩/오류 상태는 `harness/starter/shadcn/INTEGRATION.md`.
> 토큰 정본은 `harness/vendor/skhynix/design.css` 하나 — 앱 CSS 에 다시 정의하지 않는다(선택자 충돌). 토큰은 과제 도메인에 맞게 바꿔도 되지만 규칙(§원칙·§금지)은 유지한다.

**빠른 시작 — 앱용 파생 규칙**
1. 앱 주색 #ff6600(`--skh-accent`). 캠페인 #ff8e20은 기본 버튼에서 제외한다. 해커톤 사이트색은 쓰지 않는다.
2. 글꼴 = Pretendard 고정, 키트 동봉(`harness/vendor/fonts/PretendardVariable.woff2`, OFL-1.1). 대체: "Malgun Gothic","Apple SD Gothic Neo",system-ui,sans-serif.
3. shadcn은 생성기가 넣은 sk-theme.css와 원본 부품을 유지한다. 원본 컴포넌트 모양·상태 표현을 바꾸지 않는다 — 바꾸는 것은 색 토큰·데이터·라벨뿐(원본에 없는 장식 = slop). 기준 그림 `harness/guides/img/shadcn-recipe-sk.png`.
4. 색 쓰임: 주 버튼 = 검정 + 흰 글자. SK 주황은 데이터 강조(차트 강조 계열·긴급 배지·히트맵)에만 — 선택·포커스 표시는 원본 회색, 주황 선·테두리 금지. 긴급 배지 = 옅은 주황 바탕 + 진한 주황 글자. 주황 면 위 글자 금지(히트맵 최진 칸만 #c24e00 + 흰 글자). 라이트 모드만(다크 없음).
5. 표: 44px 행, 숫자 우측·단위 머리·미수집 —·표 안 가로 스크롤.
6. 개선은 중립색, 악화는 위험색; 방향과 개선/악화 글자를 함께 쓴다.
7. 공통 사이드바는 공식 동봉 로고 아래에 도메인 제목(`harness/vendor/skhynix/ASSETS.md`).
8. `harness/vendor/skhynix/design.css` 는 참고용 토큰표다 — shadcn 앱에 그 CSS·클래스를 섞지 않는다(테마는 `sk-theme.css` 하나).

## 원칙

1. **정보 위계가 디자인이다** — 요약 숫자(3~4개) → 오늘의 큐(행동 대상) → 상세·근거 순. 가장 중요한 것이 가장 크고 가장 위에.
2. **상위 N 시각 분리** — 목록이 있으면 "먼저 볼 것"이 테두리·배경으로 구분돼야 한다. 전부 같은 무게면 아무것도 안 중요한 것.
3. **색은 의미다** — 상태색은 의미에 고정하고 장식으로 쓰지 않는다. 색만으로 의미를 전달하지 않는다 — 반드시 텍스트 라벨 병기(색약·흑백 인쇄 대응).
4. **숫자는 정렬한다** — 금액·건수는 `font-variant-numeric: tabular-nums` + 우측 정렬. 천 단위 콤마.
5. **화면 실행 중 외부 자산 요청 0** — 번들에 포함된 shadcn·Radix·Lucide·Recharts·Sonner와 동봉 vendor(`harness/vendor/`)만. 외부 CDN·외부 웹폰트·아이콘폰트 금지(오프라인 샌드박스에서 죽는 지점은 외부 요청이다).

## 인터랙션·차트 규율

판단 기준 하나: **실무자의 클릭·판단을 줄이는가.** 보여주기 위한 움직임은 전부 감점 신호다.

**넣을 값어치 있는 것 (선택지)**
- **접힘 섹션** — 보조 정보(제외된 건·상세 로그)는 shadcn Collapsible.
- **정렬·필터 토글** — 큐가 20건 넘으면 유형별 필터가 클릭을 줄인다. 토글 상태는 URL이나 화면에 보이게.
- **행동 버튼 + 즉답 피드백** — "복사" 누르면 라벨이 "복사됨 ✓"으로 1~2초. shadcn은 동봉 Sonner. 성공 표시는 실제 처리 완료 뒤에만.
- **행 hover 하이라이트 · 행 클릭 상세** — 상세는 drawer/sheet로 맥락 유지, 짧은 입력은 dialog, 영향 있는 실행 확인은 alert-dialog. `harness/starter/shadcn/INTEGRATION.md`의 재사용 부품을 먼저 쓴다.
- **차트** — 아래 규율로, 필요할 때만. **숫자가 3~4개면 차트가 아니라 스탯 바가 이긴다.**

**차트 규율 (쓸 때)**
- 차트는 번들 Recharts. Chart.js 등 외부 요청 금지.
- 허용: 막대·선/면·100% 누적 막대·히트맵·진척 막대·퍼널·간트 간이판·노드 그래프(위젯 W1~W19). 금지: 3D·도넛·파이·그라데이션 채움·카운트업. 색은 토큰만 — 기본 회색, **강조는 딱 하나**(`--skh-data-accent`, 문제의 막대만 상태색). 히트맵은 sequential 단색 농도 + 칸 수치.
- W17 AI 대화창: 말풍선은 AI = `muted` 배경, 사용자 = 기본(검정) — 원본 톤 그대로, 장식·아바타·글자 효과 없음. 응답 옆에 「AI 응답」/「모의 응답」 배지를 항상 둔다. 질문 칩·입력칸에 설명 캡션·지시형 문구를 붙이지 않는다.
- 축·단위 라벨 필수, 숫자는 tabular-nums. 범례가 필요하면 차트가 너무 복잡한 것.

**모션 한도**: 상태 전환(hover·접힘)만 100~150ms ease-out. `prefers-reduced-motion` 존중. 그 외 움직임 0.

## 금지 (슬롭 신호 — 운영 도구에서 즉사)

- 그라데이션 · 장식 그림자 · 이모지 아이콘 남발 (신호를 흐린다)
- 마키·캐러셀·자동 슬라이드 (읽는 속도를 도구가 정하는 것)
- 3D·파티클·틸트·패럴랙스 (판단에 기여 0, 성능 비용만)
- 스크롤 트리거 리빌 · 숫자 카운트업 애니메이션 (두 번째 볼 때부터 대기 시간)
- hover 시 카드 떠오름(translateY+그림자 확대) — AI 상투형 대표
- 스켈레톤 쉬머 남발 (로컬 데이터엔 로딩이 없다)
- 다크모드 (범위 밖)

예외를 열면 `docs/DECISIONS.md`에 한 줄 — 이유 있는 추가는 감점이 아니라 의도 관리 가점.

## 도구 판정

| 도구 | 판정 | 이유 · 예외 조건 |
|---|---|---|
| **Tailwind + shadcn/ui** | **채택 — 화면 기본(npm 이 될 때)** | `bash harness/starter/shadcn/make.sh` 로만 세운다(Vite+React+Tailwind+shadcn+우리 overlay+SK 색). **10분 안에 안 되면 멈추고 사용자에게 알린다**(화면 없이 API·CSV 출력), `docs/DECISIONS.md` 에 선택 한 줄. 생성물을 통째로 제출물로 두지 않는다 — 문구·데이터·판정 로직은 우리 것(`src/`)으로 바꾼다 |
| **React/Vite** | 조건부 | 과제 스캐폴드가 React 로 오면 그 위에 얹는다. 우리가 새로 깔 때는 위 `make.sh` 로만 |
| **Chart.js / D3** | 기각 | 번들 Recharts·손 SVG로 충분. 예외 없음 |
| **three.js** | 기각 | 판단 화면에 3D가 기여하는 경우 없음. 예외: 과제가 진짜 공간 데이터이고 2D 평면도로 부족함을 실무자가 확인해줬을 때만 — DECISIONS에 기각한 2D 대안 명시 |
| **폰트/아이콘** | 동봉 채택 | Pretendard와 번들 Lucide. 아이콘 단독 버튼에는 접근 가능한 이름을 붙인다 |
| **getdesign.md** | 조건부 | 도메인에 더 맞는 디자인 언어가 필요할 때만 `npx getdesign@latest add <이름>`, 이유 한 줄을 `docs/DECISIONS.md`에 |

판단 원칙: 이미 검증한 shadcn 부품·데이터 연결을 먼저 쓴다. 추가 라이브러리는 기존 부품으로 못 하는 이유와 설치·검증 비용을 확인해 결정한다.

## 운용

- 첫 화면도 기본은 `make.sh` 생성 화면이며, 필요한 페이지·위젯만 남긴다(npm 이 막혀 설치가 실패하면 화면 없이 API·CSV 출력으로 간다 — 위 출발점 문단과 같다) — 디자인 고민 0분으로 "거칠지 않은 기본"을 확보하고, 폴리싱은 마지막(얇은 결과 먼저).
- 최종 전 사람 눈 확인 1회: "처음 30초에 오늘 뭘 할지 보이는가" — 안 보이면 스타일이 아니라 **정보 배치**를 다시 짠다.
