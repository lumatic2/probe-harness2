# 편성.md — 새 탭 안내 · 입력 요령 · 승계 문장 (에이전트가 사용자에게 안내할 때 읽는다)

> 사람이 치는 당일 순서는 킷 밖(준비 레포의 D-day 체크리스트)에 있다. 이 파일은 오케가 탭 안내·승계 안내를 할 때 가리키는 정본이다.

## 탭과 모델

모델·effort 는 사용자가 하면서 정한다 — 킷은 지정하지 않고, 오케는 안내에 `/model` 까지만 쓴다. 서브에이전트는 오케 세션 모델을 그대로 쓴다.

탭은 병목이 안 생기는 만큼 연다(기본: 오케 · 설명 · DM · 통합 · 검증 · 코어 · 화면 · 필요시 서비스). 통합은 서버를 살려 두고 화면 QA 재빌드에 바로 답하는 탭이라 오래 걸리는 일(E2E · 전량 실행 · Docker · 실행 재현)은 검증 탭이 맡는다 — 한 탭이 계속 일하느라 다른 탭이 기다리면 그 탭의 일을 갈라 새 탭을 연다. 오케에 실행 일이 몰리면 검증 워커에 넘긴다. 새 탭 안내 한 줄: `탭 이름 <이름> → codex → /permissions Full Access → /model → 붙이기: 「AGENTS.md와 .agents/skills/handoff/SKILL.md, docs/brief/<역할>.md 를 읽고 <역할> 워커로 시작해」`. 브리프는 파일이다 — 「준비됨」 queue 는 등록 확인이라 답하지 않는다. **설명 탭 안내 한 줄**(세팅 보고 때 — 빠졌으면 언제든 다시): `새 탭 → codex → /permissions Full Access → /model → 「harness/roles/설명.md 읽고 역할 파악해. 이 세션은 설명 세션으로 쓸 거야」 → 탭 이름 설명`.

## 입력 요령 (확인된 것)
- Codex 입력칸 줄바꿈은 **Ctrl+J**. Shift+Enter·역슬래시는 안 된다. 긴 여러 줄 지시는 파일에 쓰고 경로만 넘긴다(`docs/mail/` 또는 `메모.md` 밖의 임시 파일).
- 스킬 목록(`$`)이 안 보이면 `/quit` → `codex resume`. 그래도 없으면 `.agents/skills/<이름>/SKILL.md` 를 직접 읽는다. 전역 등록(`python3 harness/tools/install_skills.py --workspace .`)은 작업 공간 밖에 쓰므로 사용자가 시킬 때만.
- 플랫폼 Browser 는 **포트 칸 `3000` · 경로 칸 `/`**. 전체 URL 을 넣으면 깨진다.
- 터미널 스크롤이 멈추면 그 탭에서 `/quit` → `codex resume <UUID>`(화면에 뜨는 문장 그대로). **그 사이 들어온 queue 는 보존되어 재개 뒤 순서대로 처리된다**(Codex 0.163·0.166 확인). 바쁜 탭에 사용자가 직접 치면 쌓인 queue 보다 먼저 답한다.

## 승계 문장 (사용자가 「승계하자」를 치면 오케가 `$handoff` 뒤 이 문장을 출력하고, 사용자가 새 탭에 붙인다 — 상태줄 `context-used` 40% 근처면 준비, 50% 전에 단계 경계에서 · 새 탭 모델·effort 는 사용자 선택)

```
AGENTS.md 와 harness/roles/오케.md, .agents/skills/handoff/SKILL.md 「이어받기」, docs/HANDOFF.md 를 읽고 오케를 이어받아. 지금 상황 3줄 · 다음 할 일 1개 · 종료까지 남은 시간을 말하고, 「이어받기」의 새 오케 절차(편지함 → 세션.txt 오케 줄을 새 UUID 로 교체 → 살아 있는 탭에 「오케 바뀜」)를 한 뒤 기존 범위에서 계속해.
```

## 컨텍스트
compact 는 상태가 파일에 다 들어간 순간에만(권장: 「설계 OK」 뒤 브리프 발행 직후 = 승계, M5 끝 = compact). 상태줄의 컨텍스트 사용량을 사람이 본다.
