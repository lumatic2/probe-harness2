# LLM 응용 설계 — 학문 지도

> [기법 선반](../README.md) › **LLM 응용 설계** · 문서 3
> 한 줄: LLM 을 서비스의 부품으로 쓸 때 **무엇을 근거로 답하게 하고, 출력을 어떻게 타입으로 묶고, 맞았는지 어떻게 재고, 어떤 뼈대와 도구 경계로 짜는지**를 다룬다. 계산과 판정은 코드가, 질문 해석과 문장화는 LLM 이.

## 핵심 질문
**이 답은 어떤 기록을 근거로 하고, 숫자는 누가 계산했고, 틀렸을 때 어떻게 알아내며, AI 가 만질 수 있는 것은 어디까지인가?**

## 이럴 때 꺼낸다 / 옆 모듈로
- **꺼낸다**: 「조치 기록·SOP 검색」 「AI 가 판정·분류」 「근거를 보여 줘」 「정확도는?」 「환각」 · 어떤 과제든 LLM 을 앞단(질문 해석)이나 뒷단(설명)에 붙일 때의 공통 뼈대.
- **옆 모듈로**
  - 질문을 솔버 입력 변경(파라미터 diff)으로 바꾸고 전후 KPI 를 설명 → [최적화](../최적화/README.md) 질문을 파라미터로
  - 오분류 비용표로 확률 임계값·조치를 고르기, 가정이 틀리면 → [의사결정분석](../의사결정분석/README.md) 기대손실 결정표 · 민감도 분석
  - 일치율의 신뢰구간·필요 표본 수 → [확률과 시뮬레이션](../확률과-시뮬레이션/README.md) 몬테카를로
  - 알람 판정(통계)과 LLM 해석의 분업 → [품질과 신뢰성·통계](../품질과-신뢰성-통계/README.md) 관리도와 오경보 주기
- **옆 선반으로**: 어디까지 맡기나·권한·감사 로그는 접근법 선반의 [컴퓨터과학](../../approaches/컴퓨터과학/README.md)(자율성 설계 · 정보보안).

## 핵심 개념어
- **구조화 출력**: 스키마에 맞는 값만 내게 강제하는 기능. 스키마 일치는 값이 맞다는 보증이 아니다([출력을 타입으로 묶기](02-출력을-타입으로-묶기.md)).
- **Top-k 적중 · MRR**: 정답 근거가 상위 k 에 있는 비율 · 첫 정답 순위의 역수 평균(추론, [근거를 붙여 답하기](01-근거를-붙여-답하기.md)).
- **인용 정확도 · 근거 없는 답 비율 · 답 없음**: 인용한 id 중 정답 비율 · 근거 없이 답한 비율 · 근거가 없을 때 거절하는 행동(추론, 01).
- **숫자 경계**: 숫자는 코드가 계산한 값에서만 나오고 LLM 은 옮겨 적는다. 어긋나면 서버가 거른다(추론, 01·02).
- **가드레일 3층**: 입력(도구 밖 요청 거절) · 출력(스키마·범위) · 유출(원본 행 값 0건)([평가 세트와 가드레일](03-평가-세트와-가드레일.md)).
- **루브릭 판정 통과율**: LLM 판정 점수를 정확도로 부르지 않고 판정자를 밝힌다(03).

## 관점 쌍
- **LLM 칸 ↔ 계산 칸**: 화면에서 색으로 갈라 보인다. 숫자 칸은 서버가 계산 값과 대조한다([출력을 타입으로 묶기](02-출력을-타입으로-묶기.md)).
- **합성 점수 ↔ 현장 점수**: 합성은 방법이 맞는지 보는 시험지다. 「합성」 배지를 고정한다([평가 세트와 가드레일](03-평가-세트와-가드레일.md)).
- **최신 모델 ↔ 단순 기준선**: 최신 모델은 늘 단순 기준선과 나란히, 지면 진 대로(추론).
- **정답을 찾음 ↔ 답하지 않음**: 거절도 기대 판정이다. 답 가능·불가 질문을 둘 다 평가한다([근거를 붙여 답하기](01-근거를-붙여-답하기.md)).

## 이 분야 사람이 먼저 묻는 것 5
1. 이 답의 근거 기록은 무엇이고, 근거가 없으면 어떻게 하나?
2. 화면의 숫자는 LLM 이 만들었나, 코드가 계산했나?
3. 정확도는 어떻게, 질문 몇 개로 쟀나? 실패 사례는?
4. AI 에게 나간 데이터는 무엇이고, AI 가 만질 수 있는 도구는 어디까지인가?
5. 합성 데이터로 잰 숫자를 현장 숫자처럼 말하고 있지 않나?

## 흔한 함정
- 벤치마크 1위·합성 정확도를 우리 성과처럼 말한다.
- TimesFM 3.0 처럼 다운로드한 가중치가 비상업·비운영 라이선스인 모델을 「실무 적용 가능」으로 소개한다(TimesFM README 기준, 해당 행은 문서 없음).
- Decisions 의 확률을 보정된 확률·정확도로 부른다([출력을 타입으로 묶기](02-출력을-타입으로-묶기.md)).
- 임계값을 고른 평가 세트로 그대로 보고한다. 질문 수가 적으면 구간을 같이 적는다([근거를 붙여 답하기](01-근거를-붙여-답하기.md)).
- 오래된 글(Building effective agents 2024-12, LazyGraphRAG 2024-11)을 최신 지형처럼 인용한다.
