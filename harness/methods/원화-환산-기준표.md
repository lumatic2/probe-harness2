# 원화 환산 기준표 — 결과를 원 단위로 말할 때 쓰는 수치

> [기법 지도](README.md). 「시간 X% 절감」에서 멈추지 않고 원화로 말할 때 쓴다(킥의 대표 꼴 — `README.md` 6절). **하한(원가 — 돈이 실제로 나가는 값)과 상한(기회비용 — 생산능력이 꽉 찼을 때 못 판 값)을 같이** 적고, 확정치로 말하는 것은 하한뿐이다. 기준 시점을 붙인다(「2026년 2분기 공시 단가 기준」).
> 수치는 2026-11-09 에 공개 자료(금융감독원 DART 사업·반기보고서와 잠정 실적 · OpenDART 직원 현황 · KOSIS 사업체노동력조사 · 한국은행 ECOS 환율 · 기후에너지환경부·한전 전기요금 개편 보도자료 · K-water 공업용수 단가)에서 뽑았다. 표기: `계산` = 공개값끼리의 산술 · `추정` = 공개값에 가정을 얹은 값(등급 없음) · `가정` = 근거 없는 입력값(화면에서 바꿀 수 있게 설정값으로 둔다) · E1~E3 = 근거 등급(E1 공시·통계 원본).
> **이 수치는 회사 전체 평균에서 나온 어림이다. 과제가 준 데이터에 단가가 있으면 그것이 먼저다.** 추정·가정 값을 과제 결과에 쓸 때는 화면과 문서에 「추정」이라고 밝힌다.

## 2. 환산 예시 3개

공통: 2026 2Q 공시 단가 · 엔지니어 시간 11.6만원 · 웨이퍼당 스루풋 3,247만원(= 3,450만 × (1 − 0.063)).

### 예시 1 — 병목 장비(EUV급 노광기) 1시간 비계획 정지

| | 값 | 계산 |
|---|---|---|
| **하한(원가)** | **약 0.07억원(700만원)** | 감가 소진 685만원 + 대응 엔지니어 2명 × 2시간 × 11.6만원 = 46만원. 부품비는 `미확인` |
| **상한(기회비용)** | **8.9억~14.3억원** | O-3. 3Q26 처럼 매출이 32% 더 컸다면 11.7억~18.9억(추정, DRAM 비중 불변 가정) |
| 핵심 가정 | 이 장비가 진짜 병목이고, 잃은 산출을 뒤에서 만회하지 못한다 | 비병목이면 상한이 0 에 가까워진다 |
| 말하는 법 | 「보수적으로는 시간당 700만원의 원가지만, 이 장비가 병목이면 2분기 단가로 시간당 9억 원 이상의 매출 기회가 사라집니다」 | |

### 예시 2 — 엔지니어 1시간 (예: FDC 알람 수작업 분류 시간 절감)

| | 값 | 계산 |
|---|---|---|
| **하한(원가)** | **9.25만원**(임금만) ~ **11.6만원**(부담 포함) | L-5, L-6. 업종 기준이면 7.6만원 |
| **상한(기회비용)** | **약 104만원**(평균 부가가치 상한) | L-9 — 1시간이 회사에서 평균적으로 만드는 영업이익. 아낀 시간이 병목 장비 복구처럼 산출로 이어질 때만 이 쪽에 가깝다 |
| 연 환산 예 | 알람 하루 200건 × 15분 중 60% 절감 = 하루 30시간 → 연 10,950시간 × 11.6만 = **12.7억원(하한)** | 공시·보도 기반 추정 가정 승계, 단가만 11.6만으로 갱신 |
| 말하는 법 | 「줄어드는 현금이 아니라 엔지니어 약 5.5명의 1년치 시간이 돌아옵니다(10,950시간 ÷ 연 2,000시간 — 수치는 가정 칸)」 | 인원 환산은 추정 |

### 예시 3 — 로트 1개(25장) 재작업 (예: 노광 후 측정 이상으로 PR 벗기고 재노광)

| | 값 | 계산 |
|---|---|---|
| **하한(원가)** | **약 92만원 + 재료비(미확인)** | 재노광 장비 시간 25 ÷ 220wph = 0.114시간 × 685만원 = 78만원 + 엔지니어 1시간 11.6만원. 스트립·세정·재측정 장비 시간과 PR 재료비는 `미확인` |
| **상한(기회비용)** | **약 1.1억~1.7억원** | 병목 시간 0.114시간 × 8.9억~14.3억 = 1.0억~1.6억 + 재작업 후 수율 손실 1%p(가정) × 25장 × 3,450만 = 0.09억 |
| 비교 | 재작업 대신 **폐기**하면 1.45억(원가)~8.6억원(기회비용) | 예시 3 상한이 폐기 상한보다 훨씬 작다 → 「재작업이 되면 재작업이 이득」이 숫자로 보인다(추론) |
| 핵심 가정 | 25장/랏, 재노광이 병목 장비를 다시 쓴다, 재작업 수율 손실 1%p | 전부 슬라이더 칸 |


## 3. 쓰지 말아야 할 값

- 한전 사이버지점 산업용 요금표 — 2023 단가·옛 시간대가 걸려 있다.
- 「평균가동률 100%」를 장비 가동률로 읽기.
- L-9(104만원/시간)를 한계 효과로 쓰기.
- 이천시 가정용 상수도 890원을 팹 용수 단가로 쓰기 — 팹은 광역 공업용수.
- 3Q26 웨이퍼 단가를 공시값처럼 쓰기.
