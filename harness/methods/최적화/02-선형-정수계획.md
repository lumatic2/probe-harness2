# 선형·정수계획 (LP/MIP) + 쌍대가격
> 선형 목적·제약 아래 연속/정수 결정변수를 최적화하고, 제약이 "얼마의 값어치인지"를 쌍대가격(그림자 가격)으로 읽는다. 붙는 과제 유형: ② ⑥. 코드: `../code/lp_mip.py`

## 바로 쓰는 칸
- **쓸 점**: 병목 제약의 1시간·1단위 값어치를 쌍대가격으로 읽고 LP 총마진과 LOT 정수(MIP) 총마진의 차를 보인다.
- **필요한 컬럼**: `products`(product, margin, demand_max), `usage`(product, group, hours), `capacity`(group, hours). 제품별 장비군 사용 시간이 없으면 못 쓴다.
- **한 줄 실행**: `python code/lp_mip.py` (methods 폴더에서) — 합성 제품·장비군으로 LP 생산계획·제약별 쌍대가격·MIP 총마진을 출력. (highspy 필요) 내 데이터로 쓸 때 부를 함수: `build`, `solve`, `report`
- **출력**: 생산계획표, 제약표(rhs, slack, shadow_price, binding), LP 총마진 vs MIP 총마진, 쌍대가격 순위.
- **하지 말 것**: MIP 에서 `row_dual` 을 읽지 않는다 — 쌍대가격은 LP 완화에서만. 큰 용량 변화의 가치는 재풀이로 확인한다.
- **대신 쓸 수 있었던 것 / 안 쓴 이유**: 병목 분석 · 파레토 프런티어 — 제약과 목적이 선형으로 쓰이고 자원 1단위의 값(쌍대가격)까지 필요하면 이 기법을 고르고, 어느 장비군이 병목인지 가리는 데서 끝나면 계산이 가벼운 병목 분석으로 충분하며 목적이 둘이라 하나로 합칠 수 없으면 파레토 프런티어가 맞다.

## 이럴 때 꺼낸다
- 과제 문구 신호: "제품 믹스", "용량 배분", "한정된 장비 시간", "부하를 나눠라(냉동기·공조)", "어느 제약이 병목인가", "1시간 늘리면 얼마나?".
- 데이터 모양 신호: 제품×장비군 사용시간 표, 장비군별 가용시간, 제품별 이익·수요 상한, 설비별 효율 곡선(구간 선형화 가능).
- 꺼내지 말아야 할 때: 순서·겹침이 핵심이면(→ 제약 프로그래밍 일정). 목적이 비선형·확률적이면 먼저 선형화·시나리오화가 되는지 본다.

## 입력 → 출력
입력 (DataFrame)

| 표 | 컬럼 | 의미 | 단위 |
|---|---|---|---|
| `products` | `product` | 제품 이름 | 문자열 |
| | `margin` | 웨이퍼당 처리량 마진(매출-완전변동비) | 만원/장 |
| | `demand_max` | 주간 수요 상한 | 장/주 |
| `usage` | `product`, `group`, `hours` | 제품 1장이 장비군에서 쓰는 시간 | 시간/장 |
| `capacity` | `group`, `hours` | 장비군 주간 가용시간 | 시간/주 |

출력: 생산계획표(제품별 웨이퍼 수·마진), 제약표(`rhs, slack, shadow_price, binding`), LP 총마진 vs MIP(LOT 정수) 총마진. KPI = 총마진 · 병목 제약 목록 · 쌍대가격 순위.

## 핵심 개념
- 모형: `max c·x  s.t.  A x <= b,  x >= 0` (정수이면 `x ∈ Z`). 행 = 장비군 용량 + 제품 수요 상한.
- 쌍대가격 `y`: 우변 `b_i` 를 1 늘릴 때 최적 목적값이 늘어나는 양. 여유가 남은 제약은 0 (상보 슬랙). 강쌍대성: `b·y = c·x*`.
- 정수계획(MIP)은 쌍대가격이 정의되지 않는다 → LP 완화로 가격을 읽고, 정수해(예: 25장 LOT 단위)는 따로 구한다.

## 반도체 현장에서
- 제품 믹스·장비군 용량 배분, 냉동기·공조 부하 배분(⑥), 예비부품 배치. Intel 의 공급망 계획이 MIP 로 대규모 문제를 푼 사례다 (S1, 연 매출 +$1.9B 는 자기 신고).
- 포토 같은 병목 장비군의 쌍대가격이 크다는 것은 "그 1시간이 공장 1시간"이라는 TOC 논리와 같은 말이다 (처리량 회계).

## 솔버/코드가 하는 것 · AI 가 하는 것
- 결정론: `highspy` 로 LP/MIP 풀이, 쌍대가격 추출, `scipy.linprog` 와 같은 답인지 대조.
- AI: 현업 질문 → 파라미터 변경.
  - "포토 장비 1대(월 ○시간)가 들어오면?" → `capacity.loc[group=="PHOTO","hours"] += 값`.
  - "HBM 수요 상한이 500장으로 늘면?" → `products.demand_max` 수정 후 재실행.
  - 설명 문장 틀: "포토 1시간의 가치는 X만원입니다 — 포토가 병목이고 식각·CVD·CMP 는 여유가 있어 값이 0 입니다."

## 화면 한 장
- 제약별 쌍대가격 가로 막대(y = 제약, x = 만원/단위). 병목 행(binding)은 진하게, 여유 행은 회색 0. 오른쪽에 "용량 +10%" 슬라이더 → 총마진 변화 미리보기(쌍대가격 × 변화량은 현재 기저 안에서만 유효하다고 각주).

## 함정
- MIP 에서 `row_dual` 을 읽으면 의미 없는 값이 나온다. 쌍대가격은 LP 완화에서만 읽는다.
- 최대화 문제의 부호 규약이 라이브러리마다 다르다. 코드의 유한차분 assert 로 부호를 매번 확인한다.
- 퇴화(degenerate)면 쌍대가격이 여러 개 가능하다. 값이 이상하면 우변을 ±1 씩 흔들어 본다.
- 수요 상한을 변수 상한(bounds)에 넣으면 쌍대가격이 reduced cost 로 숨는다. 행으로 넣어야 가격이 보인다.

## 한 문장 설명 · 예상 질문
- 한 문장: "이 장비군 용량을 1시간 늘리면 처리량이 얼마 오르는지가 쌍대가격으로 나옵니다."
- Q. 쌍대가격은 얼마나 늘려도 유효한가? → 현재 기저(binding 집합)가 바뀌기 전까지다. 큰 변화는 재풀이한 값을 쓴다 — 코드는 유한차분으로 확인한다.
- Q. 정수 제약은 왜 LP 와 다른가? → 25장 LOT 단위로 반올림하면 총마진이 소폭 줄어든다(합성 예: 약 0.1%). 그 차이를 "정수 비용"으로 보여 준다.

## 부록 — 검증 기록과 근거

### 검증 (하드체크)
- 코드 끝 assert: ① `A x <= b`, `x >= 0` 1차 가능성(numpy 로 직접). ② 쌍대 가능성 `A^T y >= c` 와 강쌍대성 `b·y = 목적값`. ③ `scipy.linprog` 목적값·쌍대가격 일치(다른 솔버 경로). ④ 유한차분: 우변을 실제로 1 늘려 다시 풀면 목적값이 쌍대가격만큼 오른다. ⑤ MIP 해가 정수·가능하고 LP 상한 이하. ⑥ 여유가 있는 제약의 쌍대가격 = 0.
- 현장에서 추가할 경계값 테스트 2개: 용량을 0 으로 낮춘 장비군(제품이 그 군을 쓰면 생산 0 이 나오는지), 수요 상한을 매우 크게(용량만 병목 — 쌍대가격이 전부 용량 행에 몰리는지).

### 손익 환산
- 공식: 병목 1시간 가치 ≈ 쌍대가격. 처리량 회계로 병목 1장 추가 = 매출의 약 94% 가 이익으로 간다 (2026 상반기 완전변동비 대용치 6.3%, 추정). 용량 `+Δ시간` 의 연 가치 = 쌍대가격 × Δ × 52주.
- 예시(합성 가정, 추정): 포토 쌍대가격 5,778만원/시간 → 포토를 주 +10시간 늘리면 한 주 +5.8억원, 연 약 300억원. 합성 마진을 쓴 값이라 실제 절대값은 병목 1시간 8.9억~14.3억원(추정, EUV 220 wph 원문 미확인)처럼 "병목인가"에 크게 좌우된다. 장비 구매가 아니라 가동 개선의 가치로만 말한다.
