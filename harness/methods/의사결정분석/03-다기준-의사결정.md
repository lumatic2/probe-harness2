# 다기준 의사결정 (AHP 일관성 비율 + TOPSIS, MCDM)
> 여러 기준(위험·영향·비용·긴급도)에 AHP 로 가중치를 주고(일관성 비율로 검증), TOPSIS 로 이상적 해와의 거리로 대안 순위를 매긴 뒤 가중치 민감도를 본다. 붙는 과제 유형: ④ ①. 코드: `../code/mcdm_ahp_topsis.py`

## 바로 쓰는 칸
- **쓸 점**: 여러 기준의 가중치를 AHP 로 정하고(CR 검증) TOPSIS 로 대안 순위를 매긴 뒤 가중치 민감도를 본다.
- **필요한 컬럼**: 대안×기준 표 `M`, `benefit` dict, 쌍대비교 행렬 `A`. 현업의 쌍대비교 입력이 없으면 못 쓴다.
- **한 줄 실행**: `python code/mcdm_ahp_topsis.py` (methods 폴더에서) — 합성 알람으로 AHP 가중치·CR, TOPSIS 순위, 1위 바뀌는 가중치. 내 데이터로 쓸 때 부를 함수: `ahp`, `topsis`, `sweep_weight`, `mc_top1`
- **출력**: 가중치·λmax·CI·CR, 근접도 순위, 기준별 1위가 바뀌는 가중치, 가중치 흔들기 1위 비율.
- **하지 말 것**: 쌍대비교를 AI 가 임의로 채우지 않는다(현업이 정함). `benefit` 방향을 틀리면 거꾸로 나온다. CR 이 낮아도 가중치가 옳다는 보증은 아니다.
- **대신 쓸 수 있었던 것 / 안 쓴 이유**: [기대손실 결정표](01-기대손실-결정표.md), 단일 지표 정렬 — 기준 단위가 서로 달라 화폐로 바꿀 근거가 부족한데 현업이 쌍대비교 입력을 줄 수 있을 때 골랐고, 기준을 원화로 환산할 수 있으면 결정표가 더 설득력 있고 기준이 하나면 정렬로 충분하며 가중치를 정당화할 현업 입력이 없으면 임의 가중치로 보여 쓰지 않는다.

## 이럴 때 꺼낸다
- 과제 문구: "우선순위", "어떤 알람부터", "조치안 비교", "투자안 순위", "여러 기준을 종합", "가중치".
- 데이터 모양: 대안(알람·LOT·장비·조치안) 행 × 기준 열 숫자표 / 기준마다 클수록 좋은지 작을수록 좋은지가 정해져 있음.
- 꺼내지 말아야 할 때: 기준이 하나(단순 정렬)이거나, 기준을 화폐로 환산할 수 있어 기대손실로 비교 가능한 경우(→ 기대손실 결정표가 더 설득력 있다). 가중치를 정당화할 현업 입력이 전혀 없을 때(임의 가중치로 보임).

## 핵심 개념 (5줄 이내 + 수식 1~2개)
- AHP: 기준 쌍대비교 행렬 `A`(Saaty 1~9, `A[i][j]` = i 가 j 보다 몇 배 중요)의 주고유벡터가 가중치 `w`. 일관성 `CI=(λmax−n)/(n−1)`, `CR=CI/RI`, **CR ≤ 0.1 이면 수용**, 넘으면 입력을 다시 받는다.
- TOPSIS: 열별 벡터 정규화 `x/√Σx²` → 가중 → 이상해(좋은 쪽 최고)·반이상해와의 거리 `d⁺, d⁻` → 근접도 `C = d⁻/(d⁺+d⁻)` (1에 가까울수록 좋음).
- 기준 방향(benefit/cost)을 반드시 지정. 가중치 민감도: 한 기준 가중치를 0→1 로 움직여 1위가 바뀌는 지점을 찾고, Dirichlet 흔들기로 1위 유지 비율을 센다.

## 반도체 현장에서 (용도 2~3줄, 사례 수치는 출처와 함께)
- FDC/SPC 알람 우선순위 큐, 조치안·투자안 순위. 관리도와 오경보 주기 에서 알람이 많아지는 이유를 보인 뒤, 한정된 엔지니어가 어느 알람부터 볼지를 정하는 층이다.
- 사례 수치는 찾지 못했다(표준 기법). 아래 값은 합성 알람 6건의 코드 출력이다.

## 솔버/코드가 하는 것 · AI 가 하는 것
- 결정론: 고유값 분해, CR 판정, TOPSIS 계산, 가중치 스윕, 몬테카를로 흔들기.
- AI: 현업 말을 쌍대비교 값·기준 목록으로 옮긴다. 예 1) "비용이 훨씬 중요하다" → `A[조치비용][*]` 를 5~7 로 수정 후 CR 재확인. 예 2) "긴급도 기준을 빼 보면?" → 열 제거 + `A` 에서 해당 행·열 제거.
- 설명 틀: "가중치는 현업 쌍대비교(CR ○)에서 나왔고 1위는 ○입니다. 이 1위는 ○ 기준 가중치가 ○~○인 동안 유지되고, 가중치를 ±흔들었을 때 ○%에서 1위입니다. ○가 ○ 기준에서 가장 약해 2위입니다."
- 쌍대비교를 AI 가 임의로 채우지 않는다 — 현업이 정하게 두고 AI 는 입력 보조·설명만.

## 화면 한 장
- 좌: 가중치 슬라이더 4개(합 1 자동 정규화) + CR 배지(초록 ≤0.1/빨강). 우: 순위 표(근접도 막대, 순위 변동 화살표). 하단 "공정위험 가중치 vs 1위" 구간 띠(1위가 유지되는 구간 색칠).

## 함정
- TOPSIS 는 대안을 추가·삭제하면 순위가 뒤집힐 수 있다(순위 역전). 대안 집합을 바꾸면 다시 계산하고 안정성을 확인한다.
- 방향을 잘못 주면(비용을 benefit 으로) 결과가 거꾸로 나온다. `benefit` dict 를 화면에 표시한다.
- AHP 의 CR 이 낮아도 가중치가 옳다는 보증은 아니다 — 일관적일 뿐. 순위를 뒤집는 가중치 구간이 좁으면 "근소한 1위"라고 말한다.
- 상관이 큰 기준을 겹쳐 넣으면 사실상 가중치가 두 배가 된다. 기준 수는 3~6개.

## 한 문장 설명 · 예상 질문
- "가중치를 숨기지 않습니다 — 현업이 정한 가중치에서 이 순위가 나오고, 어디서 뒤집히는지도 보여 드립니다."
- Q. 가중치는 누가 정했나? A. 현업의 쌍대비교 입력이고 일관성 비율 0.1 이하만 받습니다. 합성 데모에서는 가정값(CR 0.022)입니다.
- Q. 왜 기대손실 결정표 기대손실이 아닌가? A. 기준이 서로 다른 단위이고 화폐로 환산할 근거가 부족할 때 쓰는 층입니다. 환산할 수 있는 알람은 기대손실 결정표 로 보강합니다(추론).
