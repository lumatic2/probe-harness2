# 의사결정분석·기대가치 (Decision Analysis, Expected Value, EVPI)
> 선택지×상태 확률×손실 표로 기대손실이 최소인 조치를 고르고, 판단이 뒤집히는 확률 경계와 정보의 가치(EVPI)를 계산한다. 붙는 과제 유형: ① ③. 코드: `../code/decision_analysis.py`

## 바로 쓰는 칸
- **쓸 점**: 조치×상태 손실표에서 기대손실이 최소인 조치와 판단이 뒤집히는 확률 경계, 정보의 가치(EVPI)를 계산한다.
- **필요한 컬럼**: 손실표(행=조치, 열=상태, 값=손실)와 상태별 확률 `probs`. 상태 확률과 조치별 손실이 없으면 못 쓴다.
- **한 줄 실행**: `python code/decision_analysis.py` (methods 폴더에서) — 합성 랏·장비 판정의 기대손실·경계 확률·EVPI. 내 데이터로 쓸 때 부를 함수: `expected_loss`, `evpi`, `breakpoints`, `lot_table`
- **출력**: 조치별 기대손실, 최선 조치, EVPI, 구간별 최선 조치 [(p시작, p끝, 조치)] 경계.
- **하지 말 것**: 클레임·정지 손실을 사실처럼 말하지 않는다(가정 표시+슬라이더). 경계는 상태 2개만, EVPI 는 상한일 뿐 재검의 가치가 아니다.
- **대신 쓸 수 있었던 것 / 안 쓴 이유**: [임계값을 비용으로 정하기](../판정-모델/04-임계값을-비용으로-정하기.md), [선형·정수계획](../최적화/02-선형-정수계획.md) — 조치 후보가 몇 개이고 상태 확률과 조치별 손실을 (가정이라도) 적을 수 있어 표 하나로 경계와 EVPI 까지 보이려고 골랐고, 분류 점수의 컷만 정하면 되면 임계값 문서가, 선택지가 수십 개이고 자원 제약이 얽히면 최적화가 맞다.

## 이럴 때 꺼낸다
- 과제 문구: "출하/재검/폐기", "조치 A/B/관찰", "지금 정지할까", "추가 검사를 할 가치가 있나", "오판 비용", "확률이 얼마를 넘으면".
- 데이터 모양: 조치 후보 목록 + 상태(정상/이상 등) 확률 추정치(모델 점수·과거 비율) + 조치별 비용 표(없으면 가정 입력).
- 꺼내지 말아야 할 때: 선택지가 수십 개 이상이고 자원 제약이 얽힌 문제(→ 제약 프로그래밍 일정·선형·정수계획 최적화). 상태 확률을 전혀 추정할 수 없고 비용도 모를 때(→ 경계만 보여 주는 용도로 한정).

- → 실행 결과는 부록

- 확률 `p` 는 분류 모델의 보정된 확률이거나 과거 비율이다. 보정이 안 된 점수는 경계 해석이 틀어진다.

## 핵심 개념 (5줄 이내 + 수식 1~2개)
- 손실표 `L(a,s)`(조치 a, 상태 s)와 확률 `P(s)`로 기대손실 `EL(a)=Σ_s P(s)·L(a,s)`. 최소 `EL` 조치를 고른다.
- 상태가 2개면 `EL(a)` 는 p(이상 확률)의 직선 — 최소 직선의 하부 포락선이 구간별 최선 조치이고, 꺾이는 점이 "판단이 바뀌는 확률 경계"다.
- `EVPI = min_a EL(a) − Σ_s P(s)·min_a L(a,s)` : 상태를 완벽히 알게 해 주는 정보에 쓸 수 있는 돈의 상한. 이보다 비싼 계측·검사는 하지 않는다.
- 손실은 "이상적 판정 대비 후회"로 적는다(예: 정상 랏 폐기 = 랏 가치, 불량 유출 = 클레임 손실).

## 반도체 현장에서 (용도 2~3줄, 사례 수치는 출처와 함께)
- 이상 랏 출하/재검/폐기, 장비 조치 A/B/관찰 유지의 근거 카드 옆에 "조치별 기대 손실"을 붙이는 용도. Q-Time 위반은 폐기 또는 비싼 재작업이라는 정성 서술만 공개돼 있고 건당 비용은 공개 근거가 없다(외부 출처 미확인) — 비용은 가정·슬라이더로 둔다.
- 사례 수치는 찾지 못했다(표준 기법). 아래 수치는 추정 단가에 가정 파라미터를 얹은 합성 출력이다.

## 솔버/코드가 하는 것 · AI 가 하는 것
- 결정론: 기대손실, 하부 포락선 경계(정확해), EVPI. 난수 없음.
- AI: 질문을 확률·비용 파라미터로 바꾼다. 예 1) "고객 클레임이 50억으로 올라가면?" → `lot_table(1.45, claim=50)`. 예 2) "재검 장비 민감도가 70% 뿐이면?" → `{sens: 0.7}`.
- 설명 틀: "불량 확률 ○%에서 기대손실이 가장 작은 조치는 ○(○억)입니다. 확률이 ○%를 넘으면 ○가 낫고, ○% 아래면 ○가 낫습니다. 현재 확률은 경계에서 ○%p 떨어져 있어 판단이 ○합니다. 정보의 가치 상한은 ○억이라 그보다 비싼 계측은 정당화되지 않습니다."

## 화면 한 장
- 조치별 기대손실 막대(최선 강조) + x=이상 확률, y=기대손실의 세 직선 차트에 현재 확률의 세로선과 경계 점. 확률·클레임·랏 가치 슬라이더, 우측에 "EVPI ○억" 배지.

## 함정
- 클레임·정지 손실은 가정이 지배한다. 값에 "가정" 표시를 붙이고 슬라이더로 연다(추정 단가를 사실처럼 말하지 않는다).
- 손실을 "후회" 기준으로 쓸지 절대 비용으로 쓸지 섞으면 EVPI 가 틀어진다. 한 표 안에서 통일.
- 코드의 경계 계산은 상태 2개만 지원한다. 상태가 3개 이상이면 기대손실·EVPI 는 되지만 경계는 슬라이더로 직접 훑는다.
- 재검은 그 자체가 불완전한 정보다(민감도·오폐기율). 완전정보 EVPI 는 상한일 뿐 재검의 실제 가치(표의 재검 행)와 다르다.

## 한 문장 설명 · 예상 질문
- "확률이 이 선을 넘으면 정지가 이깁니다 — 그 경계를 엔지니어가 직접 움직여 보실 수 있습니다."
- Q. 확률과 비용은 어디서 나오나? A. 확률은 모델 점수·이력 비율, 비용은 현업 입력 칸입니다. 값이 틀려도 경계 그림으로 어느 범위까지 같은 결론인지 보입니다.
- Q. AI 가 판단하는 건가? A. AI 는 근거 카드·확률 입력을 돕고 결정은 표 계산이 합니다. 사람이 최종 승인합니다.

## 부록 — 검증 기록과 근거

### 검증 (하드체크)
- 코드 끝 assert: ① p 를 10,001점 격자로 훑은 argmin 전환점 == 해석적 경계(2×10⁻⁴ 이내) — 세 표 모두 ② 손으로 푼 리터럴(원가 기준 출하→재검 0.01508, 재검→폐기 0.34863) ③ 출하↔폐기 직접 손익분기 `p=V/(V+claim)` 에서 두 기대손실 일치 ④ 상태를 200만 번 뽑아 만든 EVPI 몬테카를로가 공식과 일치(±0.02) ⑤ EVPI≥0, p=0 이면 0, 최선 기대손실 이하.
- 현장 추가 경계 테스트: (a) 모든 조치의 손실이 같은 표에서 EVPI=0 인지 (b) 확률을 정확히 경계값에 두었을 때 기대손실이 같은 두 조치를 결정론적으로 고르는지(동률 규칙을 화면에 명시).

### 합성 데이터 실행 결과
- 합성 결과(P(불량)=0.10, 클레임 20억 가정): 랏 가치 1.45억(원가 기준)에서 출하 0~0.0151 · 재검 0.0151~0.3486 · 폐기 0.3486~. 8.6억(기회비용 기준)이면 재검 구간이 0.0342~0.7837로 넓어진다. 장비(P=0.30): 관찰 0~0.0857 · B 부분점검 0.0857~0.5997 · A 즉시교체 0.5997~, 최선 B(기대 11.13억), EVPI 5.79억.

### 손익 환산
- 랏 손실 = 25장 × 웨이퍼당 손실: 원가 기준 약 1.45억/랏, 기회비용 기준 약 8.6억/랏(추정·완판 국면이면 후자). 장비 손실 = 정지 시간 × 병목 시간당 8.9억(추정). 서비스 NPV·회수기간은 [민감도와 가정 바꿔 보기](02-민감도와-가정-바꿔-보기.md)의 예.
- 예(합성·가정): 불량 확률 0.10에서 "무조건 출하"(기대 2.0억/랏) 대신 재검(0.465억)을 택하면 랏당 약 1.5억 절감(원가 기준). 국면 가정(원가↔기회비용)으로 경계가 0.35→0.78로 움직이므로 두 경우를 같이 띄운다(민감도 문서의 화법).
