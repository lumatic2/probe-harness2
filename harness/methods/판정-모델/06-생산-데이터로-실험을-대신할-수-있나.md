# 관측 데이터 대 계획 실험 (Observational Data vs Designed Experiment, 숨은 변수·VIF·검정력)
> 이미 쌓인 생산 로그로 「이 인자가 수율을 바꾼다」를 말해도 되는지 판정하고, 안 되면 확인 실험이 최소 몇 장인지 계산한다. 붙는 과제 유형: ③ (추론). 코드: `../code/observational_vs_experiment.py`
> 접근법 선반 짝: [인과추론과 실험](../../approaches/경제학/인과추론과-실험/README.md) · [계측·제어 관점](../../approaches/반도체-현장/품질-계측-후공정/02-계측-제어.md)

## 바로 쓰는 칸
- **쓸 점**: 쌓인 생산 로그로 「이 인자가 수율을 바꾼다」를 말해도 되는지 가리고, 안 되면 확인 실험이 최소 몇 장인지 계산한다.
- **필요한 컬럼**: 인자 열 `p`·반응 열 `y`·숨은 변수의 대리변수 `z`(챔버·PM 누적 등)와 잡으려는 차이 `delta`·잔차 `sigma` — 인자·반응 열이 없으면 못 쓴다.
- **한 줄 실행**: `python code/observational_vs_experiment.py` (methods 폴더에서) — 합성 400건 부호 반전·필요 장수. 내 데이터로 쓸 때 부를 함수: `ols`, `vif`, `n_needed`
- **출력**: 단순·다변수 기울기와 SE, VIF, 대리변수 층 안 기울기, 부호 뒤집힘 비율, 확인 실험 집단당 필요 장수.
- **하지 말 것**: 대리변수를 넣고 「통제했다」고 말하지 않는다 — 부트스트랩이 안정적인 것(뒤집힘 0)은 맞다는 뜻이 아니다.
- **대신 쓸 수 있었던 것 / 안 쓴 이유**: 계획 실험(요인 실험) · 관측 데이터 단순 회귀 — 이미 쌓인 로그로 인과 문장을 써도 되는지 가리고 확인 실험 장수를 셀 때 이 기법이고, 인자를 의도적으로 바꾼 데이터가 있으면 계획 실험 분석으로 바로 가며, 단순 회귀만 내밀면 숨은 변수로 부호가 뒤집힐 수 있어 쓰지 않는다.

## 이럴 때 꺼낸다
- 과제 문구: "MES/FDC 데이터로 수율 저하의 원인 인자를 찾아라", "이미 데이터가 많은데 실험이 필요한가", "파워를 올리면 수율이 오르나", "챔버별 차이가 진짜인가".
- 데이터 모양: 생산 이력 테이블(인자 컬럼 · 반응 · 챔버·시간·로트 같은 층 컬럼). 인자가 레시피로 관리돼 범위가 좁고, 챔버·PM 주기가 인자와 같이 움직이는 모양.
- 꺼내지 말아야 할 때: 인자를 이미 의도적으로 바꾼 실험 데이터가 있을 때.

## 입력 → 출력
| 입력 | 의미 | 단위 |
|---|---|---|
| `p`, `y` | 인자(예: 파워)와 반응(예: 수율) 열 | 변수 단위 |
| `z` 등 대리변수 | 숨은 변수의 흔적(PM 누적 횟수 등) | 변수 단위 |
| `delta`, `sigma` | 확인 실험에서 잡으려는 최소 차이, 잔차 표준편차(가정 또는 과거 값) | 반응 단위 |
- 출력: 단순·다변수 회귀 기울기와 SE(`ols`), VIF(`vif`), 대리변수 분위 층 안 기울기(`stratified_slope`), 부트스트랩 부호 뒤집힘 비율(`bootstrap_sign`), 확인 실험 필요 장수(`n_needed`)와 집단당 n장일 때 최소 검출 차이(`min_detectable`).
- → 실행 결과는 부록
- 확인 실험 비용(가정 σ≈1.56 = 숨은 변수 몫이 잡음으로 들어간 값): 수율 차 0.5 를 80% 검정력으로 잡으려면 집단당 155장. 집단당 8장이면 최소 검출 차이 2.35.
- 실행: `python code/observational_vs_experiment.py` (numpy·scipy, 수 초 — 200만 행 확인 포함). 현장에서 바꿔 끼우는 곳: `ols`·`vif`·`bootstrap_sign` 에 실제 열, `n_needed(delta, sigma)` 에 현업이 정한 값. 생성기(`gen_observational`·`gen_randomized`)의 계수는 시연용이라 실제 데이터에는 쓰지 않는다.

## 핵심 개념 (5줄 이내 + 수식 1~2개)
- 실험은 인자를 의도적으로 바꾼다("we deliberately change one or more process variables", NIST 5.1.1). 관측 데이터의 회귀는 계획 실험에서 성립하는 최소제곱 전제를 무비판적으로 가져다 쓴다는 것이 Box(1966)의 지적이다(초록 기준).
- 숨은 변수 h 가 인자 p 와 반응 y 를 함께 움직이면 y~p 단순 회귀 기울기는 `β − γ·cov(p,h)/var(p)` 로 치우친다(`y = β·p − γ·h + 잡음` 일 때, 교과 일반 — 이 코드는 식과 대표본으로 직접 확인).
- 분산팽창계수 `VIF_j = 1/(1 − R_j²)` (R_j² = 인자 j 를 나머지에 회귀한 결정계수). 두 변수가 같이 움직일수록 큰 값.
- 공정 잡음이 크면 계획된 스플릿 로트도 결론을 못 낸다(Bohn 1995, 초록: "In some cases, experiments are little better than coin flipping").

## 반도체 현장에서 (용도 2~3줄, 사례 수치는 원천과 함께)
- 생산 데이터는 레시피가 좁은 운전 범위에 묶여 있고(관리되니까), 챔버·PM 주기·로트 투입 순서 같은 숨은 변수가 인자와 같이 움직인다(추론). NIST 퍼니스 사례처럼 런 간·존 간 변동이 유의한 공정에서는 그 층을 먼저 떼어 낸다(NIST 3.5.1, E3).
- Bohn(IEEE TSM 1995, E2)은 5개 팹의 프로브 수율 데이터로 부트스트랩해, 잡음이 큰 팹에서는 스플릿 로트가 이론상 학습의 10%~100% 이상을 잃는다고 보였다. 그 수치는 그 팹들의 값이며 하이닉스에 옮기지 않는다.
- 이 문서의 합성 시나리오(「챔버 노후도」 숨은 변수, 엔지니어가 노후 챔버에 파워를 올림)는 가정이다. 실제 팹이 그렇게 운영된다는 근거가 아니다.

## 솔버/코드가 하는 것 · AI 가 하는 것
- 결정론: 최소제곱·SE, VIF, 층 안 비교, 부트스트랩(seed 고정), 비중심 t 분포로 검정력·필요 장수·최소 검출 차이.
- AI: 질문을 파라미터로 바꾼다. 예 1) "파워 효과를 0.2 까지 잡으려면 몇 장?" → `n_needed(0.2, sigma)`. 예 2) "챔버별로 나눠 보면?" → 층 컬럼을 대리변수로 `stratified_slope`. 숨은 변수 후보(PM·소모품·투입 웨이퍼 로트)를 현장 언어로 나열하고, 「인과라고 말하면 안 되는 문장」을 걸러 보고서 문장을 고친다.
- 설명 틀: "이 로그로 말할 수 있는 것은 ○와 ○가 같이 움직인다는 것까지입니다. 인자 범위 폭은 ○, 파워와 PM 의 VIF 는 ○이라 둘의 몫을 가르기 어렵습니다. 인과 효과를 말하려면 무작위 배정 실험이 필요하고, 효과 ○를 잡으려면 집단당 ○장입니다."

## 화면 한 장
- 좌 「관측 데이터가 말하는 효과」 막대(−0.40), 우 「무작위 실험이었다면」 막대(+0.55), 가운데 숨은 변수 경로 그림(노후도 → 파워, 노후도 → 수율), 아래 「이 결론을 믿으려면 확인 실험 집단당 n장」.

## 함정
- 합성 결과는 방법 시연이다. 계수·부호 반전은 가정으로 만든 것이고 효과 근거가 아니다.
- 대리변수를 넣어도 숨은 변수를 다 잡지 못한다(+0.123 대 참 +0.5). 「통제했다」는 말을 쓰지 않는다.
- 부트스트랩이 안정적이라는 것은 맞다는 뜻이 아니다(관측 뒤집힘 0.000인데 부호가 틀렸다).
- 필요 장수는 σ 에 민감하다. σ 를 낮게 잡으면 장수가 과소하다 — 숨은 변수 몫이 σ 에 들어간 값으로 계산한다.
- 로트 내 잡음이 크면 계획된 스플릿 로트도 약하다(Bohn 1995). 이 코드는 그 부트스트랩을 축소 재현한 것이 아니라 부호 뒤집힘 비율만 계산한다.

## 한 문장 설명 · 예상 질문
- "데이터가 많다고 답이 나오지 않습니다. 이 화면은 어디까지가 상관이고 어디서부터 실험이 필요한지 선을 긋고, 그 실험 비용까지 계산합니다."
- Q. 그럼 생산 데이터는 쓸모없나? A. 아닙니다. 가설을 좁히고 층 변동을 먼저 떼는 데 씁니다. 인과 문장만 실험으로 닫습니다.
- Q. 이 합성 부호 반전이 실제 팹에도 있나? A. 모릅니다. 방법을 보여 주는 가정 시나리오이고, 현장 데이터로 같은 점검(VIF·층 안 비교)을 돌려 보여 드립니다.

## 부록 — 검증 기록과 근거

### 검증 (하드체크)
- 코드 끝 assert:
  - ① 이론 기울기(모집단 공분산 식)와 200만 행 OLS 가 단순 회귀·두 변수 회귀 모두 0.01 이내 일치
  - ② 손계산 리터럴 −0.46
  - ③ 관측 표본 기울기가 음수이고 95% 구간 전체가 0 아래 / 실험 기울기는 참값 3SE 이내
  - ④ 300회 반복: 관측은 매번 음수로 이론 −0.46 쪽, 실험은 참 +0.5 쪽
  - ⑤ 대리변수 보정은 참값에 더 가깝지만 완전 복원은 아님, 숨은 변수를 알면 참값 복원
  - ⑥ VIF 를 다른 방법(상관행렬 역행렬 대각)과 대조, 2변수 `1/(1−r²)`
  - ⑦ 필요 장수·최소 검출 차이의 비중심 t 정확식을 6000회 t 검정 시뮬레이션과 대조(검정력 0.8±0.03), 차이 0 이면 검정력=유의수준
  - ⑧ 부트스트랩 뒤집힘이 관측은 거의 0, 소표본 실험은 더 큼
  - ⑨ 층 안 비교가 단순 회귀보다 참값에 가까움.
- 현장 추가 경계 테스트: (a) 층 컬럼(챔버)이 인자와 거의 완전 공선(VIF 매우 큼)일 때 코드가 「분리 불가」로 멈추는지 (b) 표본 중 한 층에 인자 수준이 하나뿐일 때 `stratified_slope` 가 0 나누기를 내지 않는지.

### 합성 데이터 실행 결과
- 합성 실행(n=400, 참 효과 +0.5): 관측 회귀 기울기 −0.398(95% 구간 −0.53~−0.27, 부호가 반대), 무작위 실험 +0.552(구간 +0.39~+0.71). 이론 기울기 `0.5 − 1.2·0.8/(0.64+0.36) = −0.46`. 대리변수를 같이 넣으면 +0.123(부분 보정), 대리변수 분위 층 안 비교는 −0.065, 숨은 변수를 직접 알면 +0.643(현실에선 모름). VIF(파워, PM) 1.87.
- 부트스트랩 부호 뒤집힘: 관측(n=400) 0.000 — 안정적으로 틀린다. 무작위 실험이라도 n=16 이면 0.281. 안정성은 타당성이 아니다.

### 손익 환산
- 장수로만 환산한다: 확인 실험 필요 장수 = 2 × 집단당 장수 (위 가정에서 310장). 장당 실험 비용·로트당 웨이퍼 수(25장)는 **근거 없음** — 현업 입력 칸(가정). Lam Research 가상 게임에서 레시피 1개 실험은 1,000달러 이상으로 가정됐으나(Nature 2023) 그 논문의 추정이다.
- 이 장수는 「실험을 안 하고 잘못된 방향으로 파워를 올리는 손실」과 비교하는 문장의 한쪽 변이다. 반대편 손실 금액은 이 문서에 근거 수치가 없다.
