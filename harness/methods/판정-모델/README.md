## 핵심 개념어
- **t₀ · W · H**: 판정 시점 · 관측 창 · 예측 구간([사건 이력에서 라벨 만들기](01-사건-이력에서-라벨-만들기.md)).
- **검열 · 진행 중**: 데이터 끝 가까운 표본은 라벨 미확정, 이미 정지 중인 표본은 예측 대상이 아니다. 둘 다 뺀다(01).
- **전처리 누수**: 분할 전에 `fit` 한 것이 시험 정보를 가져온다. 파이프라인으로 막는다([누수 없이 나누기](02-누수-없이-나누기.md)).
- **순열 잡음대**: 라벨을 섞은 점수의 범위. 실제 점수가 그 밖이어야 신호(02).
- **PR-AUC 기준선**: 0.5 가 아니라 양성 비율([불균형일 때 맞았는지 재기](03-불균형일-때-맞았는지-재기.md)).
- **정밀도@k · 재현율@k**: 하루 k 건을 보면 몇 건이 진짜 / 그날 사건 중 몇 %를 잡았나(03).
- **Brier**: 확률의 평균제곱오차. 상수 예측과 나란히 읽는다(03).
- **p\***: 보정된 확률일 때 `c_FP/(c_FP+c_FN)`. 이 이상이면 경보([임계값을 비용으로 정하기](04-임계값을-비용으로-정하기.md)).
- **이상 ≠ 불량**: 평소와 다름과 불량은 다른 질문(05).

## 관점 쌍
- **높은 점수 ↔ 내일도 나올 점수**: 무작위 분할 점수보다 배포 상황대로 나눈 점수를 보고한다(02).
- **순위 ↔ 확률**: ROC-AUC·PR-AUC 는 순위만 본다. 확률을 숫자로 말하려면 Brier·보정을 따로 본다(03).
- **확률 문제 ↔ 결정 문제**: 모델은 확률을 배우고, 경보 기준은 현장의 손실 비율이 정한다(04).
- **모델 ↔ 아무것도 안 하기**: 전부 통과·전부 경보를 못 이기면 모델을 내지 않는다(04).
- **연관 ↔ 원인**: 특징 중요도·SHAP 은 모델이 기댄 연관이다. 원인은 실험으로(02).
- **이상 ↔ 불량**: 라벨이 쌓이면 비지도에서 지도 판정으로 옮겨 간다(05 → 01~04).

## 이 분야 사람이 먼저 묻는 것 5
1. 이 라벨은 언제 아는 정보로 만들었고, 특징 중에 그 뒤에 아는 컬럼은 없나?
2. 배포 때 처음 보는 것이 시점인가 장비인가? 분할은 거기에 맞나?
3. 양성 비율 기준선과 무작위 라벨 점수는 얼마이고, 이 점수는 그 밖인가?
4. 하루 몇 건을 볼 수 있고, 그중 몇 건이 진짜인가? 오경보·놓침 비용 비는 어디서 왔나?
5. 「전부 통과」보다 나은가? 합성 데이터 점수를 현장 점수처럼 말하고 있지 않나?

## 흔한 함정
- 특징 선택·스케일·오버샘플링을 분할 전에 한다([누수 없이 나누기](02-누수-없이-나누기.md)).
- 정확도·ROC-AUC 만 보고한다. 균형 가중으로 학습한 확률을 그대로 위험 확률로 보인다([불균형일 때 맞았는지 재기](03-불균형일-때-맞았는지-재기.md)).
- 임계값을 0.5 로 두거나 시험셋으로 고른다. p* 공식을 보정 안 된 확률에 적용한다([임계값을 비용으로 정하기](04-임계값을-비용으로-정하기.md)).
- 중요도 상위를 근본 원인으로 말한다(02).
- 이상 점수를 불량 확률처럼 말한다(05).
- SECOM 직접 시험 수치를 일반 결론으로 말한다 — 한 데이터·한 분할점·튜닝 없음이다.
