# 생산과 재고·운영 — 학문 지도

> [기법 선반](../README.md) › **생산과 재고·운영** · 문서 2
> 한 줄: 공장의 **흐름과 자원**을 다룬다. 어디가 병목인가(TOC), 얼마를 쌓아 둘까(재고)를 본다.

## 핵심 질문
**처리량을 정하는 곳은 어디이고, 거기를 지키려면 무엇을 얼마나 쌓아야 하나?**

## 이럴 때 꺼낸다 / 옆 모듈로
- **꺼낸다**: 「병목」 「어떤 장비군을 늘려야」 「제품 믹스」 · 「예비부품 결품」 「발주 시점·수량」.
- **옆 모듈로**
  - 병목 1시간의 값(쌍대가격) 계산 → [최적화](../최적화/README.md) 선형·정수계획
  - 가동률과 대기, 목표 WIP → [확률과 시뮬레이션](../확률과-시뮬레이션/README.md) 대기행렬과 운영 곡선
  - 순서·겹침이 핵심인 일정 → [최적화](../최적화/README.md) 제약 프로그래밍 일정
  - 결품 비용의 원화 기준, 처리량회계의 회계 쪽 → 접근법 선반의 회계학 › 원가관리회계

## 핵심 개념어
- **병목**: 가동률이 가장 높아 처리량을 정하는 장비군. 믹스에 따라 이동한다([병목 분석](01-병목-분석.md)).
- **처리량회계**: 원가 배분이 아니라 병목 1시간당 공헌이익으로 판단한다.
- **EOQ**: 주문비와 보관비의 합을 최소로 하는 주문량.
- **안전재고 / 서비스수준**: 수요·리드타임 변동을 막는 완충과, 결품을 얼마나 막을지의 목표. 주기 서비스수준(α)과 충족률은 다르다([재고 정책](02-재고-정책.md)).

## 관점 쌍
- **국소 효율 ↔ 시스템 처리량**: 비병목을 빨리 돌려도 처리량은 안 는다. 「이 장비군 1시간이 공장 전체의 1시간」이다.
- **재고비용 ↔ 결품 위험**: 서비스수준을 올릴수록 재고가 느는 곡선이다([재고 정책](02-재고-정책.md)).

## 이 분야 사람이 먼저 묻는 것 5
1. 병목은 어느 장비군이고, 믹스를 바꿔도 같은 곳인가?
2. 결품·정지 비용은 그 장비가 병목일 때만 큰 것 아닌가?
3. 수요 이력이 충분한가? 희소 부품이면 정규 근사가 맞는가?
4. 제약(용량·램프·최소 가동) 위반이 0건인가? 복구가 불가능한 상태는?
5. 예측이 틀리면 결정이 바뀌는가?

## 흔한 함정
- 「모든 장비 1시간 = ○억」을 쓴다. 병목 여부를 먼저 본다([병목 분석](01-병목-분석.md)·[재고 정책](02-재고-정책.md)).
- 한 번 찾은 병목을 고정한다. 믹스가 바뀌면 다시 푼다([병목 분석](01-병목-분석.md)).
- 그림자 가격을 큰 증설에 그대로 쓴다. 현재 기저에서만 유효한 한계값이다([병목 분석](01-병목-분석.md)).
- 리드타임이 변동하는데 상수로 가정한다([재고 정책](02-재고-정책.md)).
