# 재고: EOQ·안전재고·(s,S) (Inventory Control)
> 주문비용과 보관비용의 균형점(EOQ)에 수요·리드타임 변동을 막는 완충(안전재고)을 얹어, 서비스수준을 올릴 때 재고비용이 얼마나 느는지 곡선으로 보인다. 붙는 과제 유형: ① (예비부품) ⑥ (화학물질·소모품). 코드: `../code/inventory_eoq.py`

## 바로 쓰는 칸
- **쓸 점**: EOQ 에 안전재고를 얹어 서비스수준을 올릴 때 재고비용이 얼마나 느는지 곡선으로 보인다.
- **필요한 컬럼**: `parts`(part, annual_demand, order_cost, unit_cost, hold_rate, lead_time_days, daily_std). 연 수요·리드타임·수요 변동이 없으면 못 쓴다.
- **한 줄 실행**: `python code/inventory_eoq.py` (methods 폴더에서) — 합성 부품의 EOQ·서비스수준별 안전재고·비용과 (s,S) 시뮬레이션 충족률을 출력. 내 데이터로 쓸 때 부를 함수: `eoq`, `curve`, `simulate_sS`
- **출력**: 부품별 EOQ, 서비스수준별 안전재고·재주문점 s·상한 S·연 재고비용·충족률 표, 99%→99.9% 증분 비용.
- **하지 말 것**: 결품 비용에 「모든 장비 1시간=○억」을 쓰지 않는다(병목 장비 부품일 때만). 주기 서비스수준(α)과 충족률을 섞지 않는다.
- **대신 쓸 수 있었던 것 / 안 쓴 이유**: 몬테카를로 · 병목 분석 — 수요 이력이 충분한 반복 발주 부품의 발주점·수량이면 이 기법을 고르고, 연 수요가 몇 건뿐인 희소 부품은 정규 근사가 깨지므로 포아송 직접 계산이나 몬테카를로로 결품 확률을 재며, 재고가 아니라 장비 가동이 병목인 문제면 병목 분석을 쓴다.

## 이럴 때 꺼낸다
- 과제 문구: "예비부품 재고", "결품", "발주 시점·수량", "부품 재고를 줄이면서 장비 정지는 막아라", "재고비용 vs 서비스수준".
- 데이터 모양: 부품별 월/일 출고(사용) 이력 + 리드타임 + 단가 / 발주 이력(발주일·입고일) 컬럼.
- 꺼내지 말아야 할 때: 수요가 거의 없는 희소 부품(연 수요 몇 건 — 정규 근사가 깨지므로 포아송 직접 계산이나 단순 "1~2개 상시 보유" 규칙), 재고가 아니라 장비 가동이 병목인 문제(→ 병목 분석). 이 기법과 직접 닿는 과제 유형은 많지 않다.

## 핵심 개념 (5줄 이내 + 수식 1~2개)
- EOQ: 발주 고정비 K 와 연 보관비 h(=단가×보관비율)의 합이 최소인 1회 주문량 `Q* = √(2DK/h)`. Q 가 20% 틀려도 비용은 1.7% 만 늘어난다(평평한 바닥).
- 안전재고: 리드타임 L 동안 수요 변동 σ_L=σ_d√L 을 z 배만큼 덮는다 `SS = z·σ_d·√L`, z=Φ⁻¹(서비스수준 α).
- 충족률(fill rate)은 주기 서비스수준과 다르다: `fill = 1 − σ_L·G(z)/Q`, G(z)=φ(z)−z(1−Φ(z)) (정규 손실함수).
- (s,S) 정책: 재고위치가 s=μ_L+SS 이하면 S=s+Q 까지 발주. 수요가 일정 이상 크고 일 단위 점검이면 이 근사로 충분하다.

## 반도체 현장에서 (용도 2~3줄, 사례 수치는 출처와 함께)
- 챔버 소모 부품·예비부품·화학물질의 발주점·발주량. SK하이닉스는 부품 재고 약 30% 절감을 기대 목표로 언급했다(K1, 번역 기사 E3). 이 기법의 공개 효과 수치는 없다.
- 병목 장비의 부품 결품은 곧 처리량 손실이다. 비병목이면 결품 비용은 수리 지연 정도로 작다 → 부품별로 서비스수준을 다르게 잡는 근거.

## 솔버/코드가 하는 것 · AI 가 하는 것
- 결정론: EOQ·z·SS·충족률 해석식, 일 단위 (s,S) 시뮬레이션(20만 일)으로 충족률 재계산.
- AI: 질문 → 파라미터. 예 1) "리드타임이 2주에서 4주로 늘면?" → `{lead_time_days: {PART-1: 28}}`. 예 2) "결품을 0.1% 이하로 하려면?" → `{alpha: 0.999}`.
- 설명 틀: "PART-○ 는 ○개씩 발주하고 재고가 ○개 이하로 내려가면 재주문합니다. 서비스수준을 ○%에서 ○%로 올리면 안전재고 ○개(연 ○원)가 더 필요합니다."

## 화면 한 장
- 선 차트: x=서비스수준(90~99.9%, 로그 스케일 권장), y=연 재고비용(원). 현재 서비스수준 점 + 슬라이더. 보조 축에 안전재고 개수와 "결품 횟수/년" 막대.

## 함정
- 주기 서비스수준(α)과 충족률은 다르다. "결품률 1%" 가 어느 쪽인지 정의부터 맞춘다. 코드는 두 값을 모두 낸다.
- 리드타임이 변동하면 σ_L²=L·σ_d²+μ_d²·σ_LT² 로 키워야 한다(코드는 리드타임 상수 가정).
- 일 단위 점검의 발주 초과분(overshoot) 때문에 실제 서비스수준이 해석식보다 약간 낮다 — 시뮬레이션이 이를 잡는다.
- 부품 하나의 결품 비용을 "모든 장비 1시간=○억" 으로 쓰면 틀리다. 병목 여부 먼저.

## 한 문장 설명 · 예상 질문
- "결품률 1%를 0.1%로 줄이는 데 필요한 재고가 이만큼이고, 그 값은 이 부품이 병목 장비에 붙어 있을 때만 정당화됩니다."
- Q. 수요가 정규분포인가? → A. 정규 근사다. 합성 시뮬레이션도 정규에서 뽑아 해석식과 0.01 이내임만 확인했고 비정규는 못 잡는다. 현장에서는 `simulate_sS` 의 수요 배열 `d` 를 실제 출고 이력 재표본으로 바꿔 다시 잰다.
- Q. 보관비율 20% 는 근거가 있나? → A. 가정이다(화면 슬라이더). 자본비용 8%(가정) + 보관·진부화를 얹은 값이고 현업 값으로 교체하는 칸.

## 부록 — 검증 기록과 근거

### 검증 (하드체크)
- 코드 끝 assert 가 독립 재검사: ① EOQ 를 격자 5,001점 전수 탐색한 최소점과 비교(상대차 <1%) ② Q 를 20% 틀렸을 때 비용비가 ½(1.2+1/1.2) 와 일치 ③ 안전재고·비용이 서비스수준에 단조 증가, `Φ(SS/σ_L)=α` 왕복 ④ 일 단위 (s,S) 시뮬레이션 충족률이 해석 충족률과 0.01 이내.
- 현장 추가 경계 테스트: (a) `daily_std=0` 이면 SS=0, s=μ_L 인지 (b) 리드타임 0 일 때 SS=0 이고 EOQ 만 남는지.

### 합성 데이터 실행 결과
- 합성 실행(PART-1): Q*=26.2개. 서비스수준 99%→99.9% 에 안전재고 +4.4개, 연 +1.8백만원.

### 손익 환산
- 공식: 재고 증가분의 일회성 현금 = ΔSS×단가, 연 효과 = ΔSS×단가×(보관비율+자본비용). 결품 회피 가치 = 회피 횟수 × 장비 정지 손실(병목일 때만).
- 예시(추정): 99%→99.9% 로 결품 회피 ≈ 35회 발주/년 × 0.9%p ≈ 0.32회/년. 병목 장비 4시간 정지 = 8.9억×4=35.6억원(추정 하한, L 가정) → 연 약 11.2억원 대 비용 1.8백만원. 비병목이면 사실상 0 — 병목 여부가 부호를 정한다.
