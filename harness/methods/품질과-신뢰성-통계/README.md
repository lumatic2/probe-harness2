## 핵심 개념어
- **관리한계 ≠ 규격한계**: 관리한계는 공정이 자기 흔들림을 넘었는지, 규격한계는 고객이 받아들이는 범위다([관리도와 오경보 주기](01-관리도와-오경보-주기.md)·[공정능력](03-공정능력.md)).
- **ARL**: 평균 런 길이. 관리 상태에서 오경보가 몇 점마다 나는가.
- **Cp / Cpk**: 규격 폭 대비 산포 / 치우침까지 반영한 값. 안정(관리 상태)과 능력(규격 만족)은 따로 판정한다.
- **Weibull 형상 β**: β ≤ 1 이면 초기 불량형이라 PM 이 이득이 없다([신뢰성과 보전 주기](02-신뢰성과-보전-주기.md)).
- **중도절단**: PM 이나 관측 종료로 고장 전에 끊긴 행. 지우거나 0 으로 두면 안 된다.
- **수축(shrinkage)**: 표본이 적은 군의 비율을 전체 평균 쪽으로 당기는 일([계측 샘플 배분](04-계측-샘플-배분.md)).

## 관점 쌍
- **안정 ↔ 능력**: 안정한 공정이 규격을 못 맞출 수 있고, 규격을 맞춰도 불안정할 수 있다([공정능력](03-공정능력.md)).
- **감도 ↔ 알람 피로**: NIST 에 따르면 3σ 단독 ARL 은 371, WECO 를 더하면 약 91.75 다. 규칙을 켤수록 잡는 것도 오경보도 는다(S17, E2).
- **활용 ↔ 탐색**: 불량이 높아 보이는 곳을 재는 것(활용)과 데이터가 적은 곳을 재는 것(탐색)([계측 샘플 배분](04-계측-샘플-배분.md)).
- **연령 기반 ↔ 상태 기반 보전**: 신뢰성과 보전 주기 은 앞의 것이다.

## 이 분야 사람이 먼저 묻는 것 5
1. 기준선(정상 구간)은 사람이 확인한 정상인가?
2. 데이터가 독립·정규에 가까운가? 자기상관은?
3. 관리한계와 규격한계를 섞지 않았나?
4. 고장·불량 이력이 몇 건인가? 중도절단은 어떻게 처리했나?
5. 오경보와 미검출 중 어느 쪽이 더 비싼가?

## 흔한 함정
- ARL 371/92 는 독립·정규·σ 참값일 때의 수치다. σ 를 짧은 기준선에서 추정하거나 자기상관이 있으면 오경보가 더 잦다([관리도와 오경보 주기](01-관리도와-오경보-주기.md)).
- 불안정한 공정의 Cpk 를 믿는다. 판정문에 「능력지수 신뢰 불가」를 먼저 쓴다([공정능력](03-공정능력.md)).
- PM 최적 주기를 한 점으로 말한다. 최적 근처는 평평하니 구간으로 말한다([신뢰성과 보전 주기](02-신뢰성과-보전-주기.md)).
- 고장 5건 미만으로 Weibull 을 적합한다([신뢰성과 보전 주기](02-신뢰성과-보전-주기.md)).
- Eva 의 「1.85배」를 우리 합성 결과와 직접 비교한다. 실제 국경 데이터·IPW 반사실 추정이고 우리는 합성이다([계측 샘플 배분](04-계측-샘플-배분.md)).
