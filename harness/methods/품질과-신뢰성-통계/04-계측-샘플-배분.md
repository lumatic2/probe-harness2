# 밴딧 + 경험적 베이즈 계측 샘플 배분 (Bandit Sampling with Empirical Bayes)
> 한정된 계측·검사 슬롯을 "추정 불량률(활용) + 불확실성(탐색)" 순으로 군(장비·챔버·LOT 군)에 나눠 주고, 표본이 적은 군의 비율은 전체 평균 쪽으로 수축한다. 붙는 과제 유형: ③ ④ (보조 ①). 코드: `../code/bandit_sampling.py`

## 바로 쓰는 칸
- **쓸 점**: 한정된 계측 슬롯을 추정 불량률과 불확실성 순으로 군에 나누고, 표본 적은 군의 비율은 전체 평균 쪽으로 수축한다.
- **필요한 컬럼**: `arms`(arm, cap, n_measured, n_defect)와 라운드 슬롯 `budget`. 군별 누적 계측·검출 수가 없으면 못 쓴다.
- **한 줄 실행**: `python code/bandit_sampling.py` (methods 폴더에서) — 합성 12개 군에서 Thompson/UCB/무작위 배분 비교. 내 데이터로 쓸 때 부를 함수: `allocate`, `fit_prior_mle`, `compare`
- **출력**: 군별 슬롯 배분 정수 벡터, 군별 사후 평균·구간, 정책 비교표(무작위 대비 기대 검출 배율).
- **하지 말 것**: 합성 배율을 효과 근거로 쓰거나 Eva 의 1.85배와 직접 비교하지 않는다. 슬롯이 군 수×상한 이상이면 이득 0 이라 전수 계측.
- **대신 쓸 수 있었던 것 / 안 쓴 이유**: 무작위·균등 샘플링, [관리도와 오경보 주기](01-관리도와-오경보-주기.md) — 계측 결과가 라운드마다 들어와 갱신되고 슬롯이 군 수 × 상한보다 적을 때만 배분 이득이 있어 이 기법을 골랐고, 전수가 가능하거나 결과가 늦게 와 라운드 구조가 안 만들어지면 무작위·전수로 충분하며 「이상인가」를 판정하는 문제면 관리도가 맞다.

## 이럴 때 꺼낸다
- 과제 문구: "계측 능력이 모자라다", "전수 검사는 불가", "어느 LOT·챔버를 먼저 잴까", "알람이 너무 많아 다 못 본다", "샘플링 계획".
- 데이터 모양: 군(장비/챔버/LOT 군) 별 누적 계측 수·검출 수 + 군별 라운드당 받을 수 있는 최대 슬롯. 결과가 **라운드마다 들어와 갱신**되는 구조.
- 꺼내지 말아야 할 때: 슬롯이 군 수 × 상한 이상이라 전수 가능할 때(배분 이득이 정확히 0 — 아래 하드체크), "이상인가"를 판정하는 문제(→ 관리도와 오경보 주기 SPC), 결과가 나오기까지 지연이 길어 라운드 구조가 안 만들어질 때.

|---|---|---|
| `arms`(군당 1행) | `arm` | 장비/챔버/LOT 군 id |

## 핵심 개념 (5줄 이내 + 수식 1~2개)
- 군 k 의 불량률 `p_k ~ Beta(a,b)`(사전), 관측 `x_k ~ Binomial(n_k, p_k)` ⇒ 사후 `Beta(a+x_k, b+n_k−x_k)`. 소표본 군은 `(a+x)/(a+b+n)` 로 평균 쪽으로 수축.
- 경험적 베이즈: 사전 `(a,b)` 를 군 전체 관측에서 추정 — 모멘트법(빠름)을 라운드마다, 베타-이항 우도 최대화(MLE)를 보고용으로.
- 배분: 슬롯마다 사후에서 `θ_k` 를 뽑아 최대인 군에 준다(Thompson), 또는 사후 상위 분위수가 최대인 군에 준다(Bayes-UCB). 군별 상한(`cap`) 안에서, 첫 라운드는 무작위.
- 보상은 슬롯당 기대 검출 수 `Σ n_k·p_k`.

## 반도체 현장에서 (용도 2~3줄, 사례 수치는 출처와 함께)
- 계측 능력이 모자란 팹에서 어느 LOT·웨이퍼·챔버를 잴지 정하는 근거. 신호가 적은 챔버의 불량률은 경험적 베이즈로 수축(적용은 추론).
- 그리스 국경 검사 시스템 Eva: 제약 있는 배치형 밴딧 + 경험적 베이즈 유병률 + Gittins 지수로 무작위 검사 대비 무증상 감염자 1.85배(성수기 2~4배), 역학 지표 기반 정책 대비 1.25~1.45배(R8, Nature 599:108–113, 피어리뷰).
  - 반사실 성능은 역확률 가중(IPW) 추정이고, 같은 논문 조건문은 "Eva's targeting is most effective when tests are scarce". 비수기에는 무작위가 Eva 의 54.1% → 73.4% 까지 따라온다.

## 함정
- Eva 의 "희소할수록 효과"는 이 합성에서 그대로 재현되지 않았다. 슬롯이 너무 적으면(6) 학습할 데이터가 없어 이득이 작고(Thompson 1.12배), 중간에서 크고, 전수에서 0 이다 — "학습 가능한 희소 구간"이라고 말한다.
- 사전 분포 추정은 편향된(이미 불량 쪽으로 몰린) 표본으로 하면 틀린다. 보고용 MLE 는 균등에 가까운 표본으로 구하고, 극단적 분포에서 MLE 가 무한 집중(Beta 파라미터 폭주)으로 가는 걸 경계로 막았다.
- 수치 "1.85배"를 우리 결과와 직접 비교하지 않는다 — Eva 는 실제 국경 데이터·IPW 반사실 추정이고 우리는 합성이다.
- 계측 결과가 늦게 오면(지연 피드백) 같은 라운드 내 갱신을 가정하는 이 코드는 낙관적이다.

## 한 문장 설명 · 예상 질문
- "모든 곳을 잴 수 없을 때, 의심스러운 곳과 모르는 곳에 슬롯을 더 주고, 데이터가 적은 곳의 숫자는 함부로 믿지 않습니다."
- Q. 전수가 아니면 놓치지 않나? → A. 놓친다. 그래서 무작위 대비 기대 검출 배율을 같이 보이고, 슬롯이 군 수 × 상한 이상이면 이득이 0 이라 전수 계측을 권한다(하드체크 ③).
- Q. 왜 Thompson 도 UCB 도 같이 두나? → A. 합성에서는 UCB 가 더 컸지만 시드·군 구성에 달렸다. 둘 다 같은 사후를 쓰고 점수만 다르니 현업 데이터에서 시뮬레이션으로 고른다(Eva 는 해석 가능성 때문에 Gittins 지수를 택했다, R8).

## 부록 — 검증 기록과 근거

### 검증 (하드체크)
- 코드 끝 assert 가 독립 재검사: ① 라운드 로그를 다시 합쳐 슬롯 합 = 예산, 군별 `cap` 준수, 검출 ≤ 슬롯, 누적 n·x 가 로그 합과 일치 ② 슬롯이 모자란 구간(6·12·24)에서 Thompson·UCB 모두 무작위 대비 z>3 (100회 평균의 표준오차 기준) ③ 전수 계측(예산 = 군 수 × cap = 96)이면 정책 간 기대 검출이 **정확히 같다**(이득 0) ④ 경험적 베이즈 수축의 MSE 가 원 비율보다 작다 ⑤ MLE 사전 평균이 실제의 0.3~3배.
- 현장 추가 경계 테스트: (a) 모든 군의 참불량률이 같은 데이터 → 배분 이득이 1.0 근처인지(위반 시 우연한 군 차이에 과적합) (b) 한 군의 `cap=0` → 그 군에 슬롯이 0 인지.

### 합성 데이터 실행 결과
- 합성 실행(12개 군, 참불량률 평균 약 2.9%, 군 상한 8, 30라운드 × 100회, 기대 검출 수): 슬롯/라운드 6·12·24·48·96 에서 Thompson/무작위 = 1.12·1.20·1.38·1.38·**1.00**배, UCB/무작위 = 1.67·1.73·1.64·1.44·**1.00**배. 소표본 군 추정 오차(MSE)는 원 비율 0.00517 → 경험적 베이즈 0.00224. MLE 사전 Beta(0.78, 28.93)(평균 0.026 vs 실제 0.029).

### 손익 환산
- 공식: 연 효과 = Δ검출 건수 × (건당 조기 검출로 회피한 손실). 손실 = Q-Time·스크랩 추정(1랏 25장 가정): 원가 기준 약 1.45억원 ~ 기회비용 기준 약 8.6억원/랏(추정, 위반 1건당 공개 원화값 없음).
- 예시(합성·추정): 슬롯 12/라운드 30라운드에서 무작위 10.5건 대비 UCB 18.1건 → +7.6건. **"검출 1건 = 불량 1랏 확산 방지"를 가정**하면 7.6 × 1.45억 ≈ 11억원(원가 기준 하한). 가정이 크므로 슬라이더로 둔다.
