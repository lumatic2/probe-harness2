# 공정능력 Cp·Cpk (Process Capability)
> 규격 폭 대비 공정 산포(Cp)와 치우침까지 반영한 Cpk 를 구하고, "관리 상태(안정)"와 "규격 만족(능력)"을 따로 판정한다. 붙는 과제 유형: ③ ④. 코드: `../code/process_capability.py`

## 바로 쓰는 칸
- **쓸 점**: 공정이 안정한지(관리 상태)와 규격을 만족하는지(Cp·Cpk)를 따로 판정해 센터링·산포 조치를 가른다.
- **필요한 컬럼**: `group`, `time`, `value`와 규격 `specs`={group:(LSL, USL)}. 규격한계가 없으면 못 쓴다.
- **한 줄 실행**: `python code/process_capability.py` (methods 폴더에서) — 합성 챔버 3개의 안정성·Cp·Cpk·예측 ppm·판정 문장을 출력. 내 데이터로 쓸 때 부를 함수: `evaluate`, `capability`
- **출력**: 묶음별 stable·Cp·Cpk·Pp·Ppk, 예측 ppm, 안정/능력 4칸 판정 문장, Cpk 신뢰구간.
- **하지 말 것**: 불안정한 공정의 Cpk 를 믿지 않는다 — 「능력지수 신뢰 불가」를 먼저 쓴다. 관리한계를 규격한계로 오해하지 않는다.
- **대신 쓸 수 있었던 것 / 안 쓴 이유**: 규격 밖 비율·백분위 직접 집계, [기대손실 결정표](../의사결정분석/01-기대손실-결정표.md) — 규격 수치가 있고 분포가 정규에 가까울 때 안정과 능력을 따로 판정해 센터링·산포 조치를 가를 수 있어 골랐고, 합/불만 있거나 분포가 이봉·꼬리면 비율·백분위가, 출하 조치의 비용까지 따지는 질문이면 결정표가 맞다.

## 이럴 때 꺼낸다
- 과제 문구: "출하해도 되는가", "규격 만족", "공정 개선 우선순위", "장비·챔버 간 품질 차이", "안정적인가".
- 데이터 모양: 측정값 + 규격(LSL/USL) 또는 규격표 / 장비·챔버·레시피별 묶음 컬럼 / 시간순 측정.
- 꺼내지 말아야 할 때: 불량 여부가 합/불 이진값뿐(규격 수치 없음)이거나, 분포가 심하게 비정규(이봉·꼬리)일 때(→ 비율·백분위로, 아래 함정). 알람 임계 설계가 질문이면 관리도와 오경보 주기.

## 입력 → 출력
| 컬럼 | 의미 | 단위 |
|---|---|---|
| `group` | 장비·챔버·레시피 등 묶음 | 문자열 |
| `time` | 측정 순서/시각 | 정수·시각 |
| `value` | 측정값 | 변수 단위 |
| `specs` (인자) | `{group: (LSL, USL)}` | 변수 단위 |
- 출력: 묶음별 `stable`(+근거 σ비·3σ밖·최대연속), Cp·Cpk·Pp·Ppk, 예측 ppm, 4칸 판정 문장. 함수 `capability()` 는 Cpk 신뢰구간(Bissell 근사)도 돌려준다.
- → 실행 결과는 부록
- 실행: `python code/process_capability.py` (numpy·scipy·pandas). 현장에서 바꿔 끼우는 곳: `evaluate(df, specs)` 의 DataFrame·규격표, 상수 `TARGET`.
- 규격이 레시피마다 다르면 `specs` 키를 `group` 값과 같게 만든다. 측정 단위가 섞이면 먼저 단위를 통일한다.

## 핵심 개념 (5줄 이내 + 수식 1~2개)
- `Cp = (USL−LSL)/(6σ_군내)` 는 산포만, `Cpk = min(USL−μ, μ−LSL)/(3σ_군내)` 는 치우침 포함. 항등식 `Cpk = Cp·(1−k)`, `k = |μ−중심|/반폭`.
- `Pp·Ppk` 는 같은 식에 전체 표준편차를 쓴다. 군내 σ 는 이동범위 `MR̄/1.128`. `Ppk ≪ Cpk` 이면 시간에 따른 이동·드리프트가 있다는 뜻.
- 능력은 "안정한 공정"에서만 의미가 있다. 순서: ① 관리 상태 판정 → ② 그다음 Cpk. 기준값은 현업이 정한다(코드 기본 1.33).
- 정규 가정 규격 밖 비율 = `P(X>USL)+P(X<LSL)` — Cpk 1.33(중심)이면 약 66 ppm.

## 반도체 현장에서 (용도 2~3줄, 사례 수치는 출처와 함께)
- 출하 판정 근거와 개선 우선순위: Cpk 가 낮은 장비·챔버부터. "산포가 문제인가 치우침이 문제인가"는 Cp 와 Cpk 의 차이로 갈라 센터링(조정)과 산포 축소(설비 개선)를 구분한다.
- NIST 핸드북은 관리한계 ≠ 규격한계를 구분한다(S17). 이 구분이 판정표의 두 축이 된다. 사례 수치는 찾지 못했다(합성 데이터 출력만 표시).

## 솔버/코드가 하는 것 · AI 가 하는 것
- 결정론: 안정성 3조건(σ비>1.2, 중심선 한쪽 연속 ≥12, 3σ 밖 ≥3점) 판정, 지수 계산, ppm 변환, 판정 문장 선택.
- AI: 질문을 규격·기준값·필터로 바꾼다. 예 1) "규격이 ±5 로 좁아지면 B 챔버는?" → `specs={"B": (95, 105)}`. 예 2) "기준을 1.67 로 올리면 어느 챔버가 탈락?" → `TARGET=1.67`.
- 설명 틀: "챔버 ○는 안정(σ비 ○)하지만 평균이 중심에서 ○ 치우쳐 Cpk ○ < 기준 ○입니다. 산포(Cp ○)는 충분하므로 평균 조정으로 Cpk 가 ○까지 오를 수 있습니다."

## 화면 한 장
- 히스토그램 위에 LSL·USL(빨강 실선)과 관리한계(회색 점선)를 다르게 그리고, 우측에 2×2 판정 카드(안정/불안정 × 능력 충분/부족) + Cpk 값과 신뢰구간 막대. 묶음별 Cpk 막대를 정렬해 개선 우선순위로.

## 함정
- 불안정한 공정의 Cpk 는 숫자가 나와도 미래를 보장하지 않는다. 판정문에 "능력지수 신뢰 불가"를 먼저 쓴다.
- 안정성 판정은 느슨한 임계로 둔다. WECO 규칙을 그대로 쓰면 250점 정상 데이터도 자주 불안정으로 나온다(관리도와 오경보 주기: 오경보 약 92점마다 1번). 합성 seed 를 바꿔 보면 3σ 밖 1~2점은 정상 공정에서도 흔하다.
- 군내 σ(MR)는 짧은 기간 산포라 장기 산포를 과소 추정한다 — Ppk 를 함께 본다.
- 규격이 한쪽뿐(상한만)이면 Cp 가 정의되지 않는다. Cpu 만 쓴다.

## 한 문장 설명 · 예상 질문
- "관리 상태(안정)와 규격 만족(능력)은 다른 질문입니다 — 둘을 나눠 판정합니다."
- Q. 정규분포가 아니면? A. 정규 가정 ppm 과 실제 규격 밖 비율을 같이 표시해 차이가 크면 경고합니다(검증 ②의 방식, 현장 데이터로 재측정).
- Q. 1.33 은 어디서 나왔나? A. 업계에서 흔히 쓰는 기준이며 코드 상수 `TARGET` 이라 현업 기준으로 바꿔 끼웁니다(추론, 외부 인용 없음).

## 부록 — 검증 기록과 근거

### 검증 (하드체크)
- 코드 끝 assert: ① Cpk→ppm 교과서 값(Cp=1 중심 2699.8ppm, Cpk=1.33 중심 약 66ppm, 한쪽 1349.9ppm) ② 같은 모수에서 400만 건을 뽑아 실제 규격 밖 비율을 세어 공식 ppm 과 비교(15% 이내) ③ 항등식 `Cpk = Cp(1−k)` ④ A/B/C 가 각각 "출하 OK / Cp 충분·Cpk 부족 / 규격 안이지만 불안정"으로 갈림 ⑤ A 의 참 Cpk 2.0 이 신뢰구간 안.
- 현장 추가 경계 테스트: (a) 평균이 정확히 규격 중심이면 Cp == Cpk (b) 평균이 USL 위로 나가면 Cpk < 0, ppm > 50 만.

### 합성 데이터 실행 결과
- 합성 실행 결과(규격 94~106): A(중심·좁음) Cp 2.06·Cpk 2.04 안정 → 출하 OK. B(평균 +2.5) Cp 2.26·Cpk 1.30 안정 → 센터링 조정. C(규격 안 드리프트) Cp 2.00·Pp 1.40 σ비 1.43 → 불안정, 규격은 만족하나 능력지수 신뢰 불가.

### 손익 환산
- 연 손실 = 예측 ppm × 10⁻⁶ × 연 처리 웨이퍼 수 × 웨이퍼당 손실. 웨이퍼당 손실 = 원가 기준 약 580만원 ~ 기회비용 기준 약 3,230만원(추정 — 완판 국면이면 기회비용, 바탕은 아래 근거).
- 예(전부 가정): B 챔버 48 ppm, 연 12만 장 → 5.8장 × 580만원 ≈ 0.33억원 ~ 5.8장 × 3,230만원 ≈ 1.9억원/년. Cpk 를 1.30→1.67로 올리면 ppm 이 약 0.5 로 줄어 대부분 회피(추정, 코드 `ppm_from_cpk(1.67,1.67)` 로 재계산).
