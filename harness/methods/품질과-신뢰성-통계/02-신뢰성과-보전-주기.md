# 신뢰성·보전 정책 (Reliability & Maintenance Policy)
> 고장 시간을 Weibull 로 적합하고, 예방보전(PM) 주기별 시간당 기대비용 U자 곡선에서 최적 주기를 찾는다. 붙는 과제 유형: ① (장비 이상·보전 조치). 코드: `../code/reliability_maintenance.py`

## 바로 쓰는 칸
- **쓸 점**: 고장 이력으로 Weibull 을 적합하고 PM 주기별 시간당 기대비용 U자 곡선에서 최적 PM 주기를 찾는다.
- **필요한 컬럼**: `hours`, `failed`(1=고장, 0=중도절단)와 비용 `cp`·`cf`. 고장이 5건 미만이면 못 쓴다.
- **한 줄 실행**: `python code/reliability_maintenance.py` (methods 폴더에서) — 합성 고장 80개로 Weibull β·η 와 PM 주기별 비용. 내 데이터로 쓸 때 부를 함수: `fit_weibull`, `optimal_age`, `cost_rate`
- **출력**: β·η·MTBF(+β 95% 구간), PM 주기-시간당 비용 U자 곡선, 최적 T*, 「고장나면 수리」 대비 절감.
- **하지 말 것**: 중도절단 행을 지우거나 고장 시각 0 으로 두지 않는다(`failed` 필수). T* 를 한 점이 아니라 평평한 구간으로 말한다.
- **대신 쓸 수 있었던 것 / 안 쓴 이유**: 상태 기반 보전(센서 열화 신호로 시점 결정), 고장나면 수리(사후보전) — 고장·PM 이력이 5건 이상 있고 운전시간만 알 때 연령 기반 비용 곡선으로 PM 주기를 구간으로 말할 수 있어 골랐고, 고장 이력이 적거나 센서 상태로 판단하는 문제면 상태 기반이, 고장률이 감소형(β≤1)이면 PM 이 이득이 없어 사후보전이 맞다.

## 이럴 때 꺼낸다
- 과제 문구: "PM 주기", "언제 정지·교체할까", "고장 이력으로 수명 예측", "예방보전 vs 사후보전", "다음 PM 까지 버틸까".
- 데이터 모양: 부품·장비별 고장까지 운전시간 + 고장 여부(PM·관측 종료로 끊긴 행 포함) / 고장·PM 이력 로그(날짜·장비·부품).
- 꺼내지 말아야 할 때: 고장 이력이 거의 없거나(고장 5건 미만) 시간이 아니라 센서 상태로 판단하는 문제(→ 상태기반 보전, 이 기법은 연령 기반). 고장률이 감소형(β≤1, 초기 불량형)이면 PM 이 이득이 없다 — 코드가 `None` 으로 알려 준다.

## 입력 → 출력
| 컬럼 | 의미 | 단위 |
|---|---|---|
| `hours` | 고장까지, 또는 PM·관측 종료로 끊긴 운전시간 | h |
| `failed` | 1=고장, 0=중도절단 | 0/1 |
| `cp`, `cf` (인자) | 계획 PM 1회 손실 / 돌발 고장 1회 손실 | 억원 등 같은 단위 |
- 출력: β·η·MTBF(+β 부트스트랩 95% 구간), PM 주기-시간당 비용 표(U자), 최적 T*, "고장나면 수리" 대비 연 절감.
- → 실행 결과는 부록
- 실행: `python code/reliability_maintenance.py` (numpy·scipy·pandas). 현장에서 바꿔 끼우는 곳: `fit_weibull(df)` 에 실제 이력 DataFrame, `optimal_age(beta, eta, cp, cf)` 에 비용.
- 컬럼 변환 팁: 장비별 고장·PM 로그는 (마지막 PM 이후 가동시간, 고장이면 1·PM 이면 0) 쌍으로 만든다.

## 핵심 개념 (5줄 이내 + 수식 1~2개)
- 수명 T ~ Weibull(β 형상, η 척도): β>1 이면 마모형(쓸수록 고장률↑), β=1 지수(무기억), β<1 초기 불량형.
- 연령교체: 가동 T 시간에 PM, 그 전에 고장 나면 돌발 수리. PM 을 당기면 계획 정지 비용이 잦아지고, 미루면 돌발 고장 비용이 는다 → 합이 U자.
- 시간당 기대비용 `C(T) = [cp·R(T) + cf·(1−R(T))] / ∫₀ᵀ R(t)dt`, `R(t)=exp(−(t/η)^β)`. 최적 T* 는 `h(T)·∫₀ᵀR − F(T) = cp/(cf−cp)` 를 만족.
- 고장이 없어 끊긴 행(중도절단)을 버리면 수명이 짧게 추정된다 — 코드는 우측 중도절단 MLE 로 처리.

## 반도체 현장에서 (용도 2~3줄, 사례 수치는 출처와 함께)
- 챔버 부품·펌프·RF 부품 같은 소모성 부품의 PM 주기 결정, "지금 정지할까 다음 PM 까지 버틸까"의 근거. 병목 장비면 정지 1시간이 곧 처리량 손실이라 cp·cf 가 커진다(추정).
- 공개 사례 수치는 이 기법에 직접 대응하는 것이 없다. 표준 연령교체 모형이고 최적 주기 예제 원문은 접근 실패했다 — 아래 수치는 모두 합성 데이터의 코드 출력이다.

## 솔버/코드가 하는 것 · AI 가 하는 것
- 결정론: Weibull MLE(`scipy.optimize.brentq`), 닫힌 형태 가동시간 적분(`scipy.special.gammainc`), `minimize_scalar` 로 T* 탐색.
- AI: 질문을 `cp`·`cf`·데이터 필터로 바꾼다. 예 1) "PM 이 4시간 걸리면?" → `{cp: 35.6}` (시간당 8.9억 × 4h, 추정). 예 2) "예비 부품이 없어 고장 복구가 하루 더 걸리면?" → `{cf: 74.2 + 24*8.9}`.
- 설명 틀: "고장 이력 N건에서 β=○로 마모형이라 PM 이 이득입니다. ○h 마다 PM 하면 시간당 기대비용이 ○억으로, 고장나면 수리(○억)보다 ○% 낮습니다. 단, ○~○h 구간에서는 차이가 ○% 이내라 일정 맞추기가 유연합니다."

## 화면 한 장
- 선 차트: x=PM 주기(h), y=시간당 기대비용. 최적점 표시 + "고장나면 수리" 수평 점선 + 최적 ±10% 음영 구간(평평한 구간 = 일정 조정 여유). 우측에 `cp`·`cf` 슬라이더.

## 함정
- 중도절단 행을 지우거나 고장 시각 0 으로 두면 β·η 가 크게 틀어진다. `failed` 컬럼을 반드시 만든다.
- 비용률 곡선은 최적 근처가 평평하다(합성: 0.75~1.5×T* 에서 +9% 이내) — "정확히 534h" 가 아니라 구간으로 말한다.
- 고장 간 의존·부품 교체 후 성능 변화(불완전 수리)는 이 모형 밖. 고장이 5건 미만이면 적합하지 않는다.
- `cf`·`cp` 는 가정이 지배한다. 값의 출처(병목 여부)를 화면에 같이 적는다.

## 한 문장 설명 · 예상 질문
- "PM 을 당기면 계획 정지 비용, 미루면 돌발 고장 비용 — 둘의 합이 최소인 주기입니다."
- Q. 고장 데이터가 적은데 믿을 수 있나? A. β 부트스트랩 구간(합성에서 1.86~2.95)을 같이 보이고, 구간 안에서 T* 가 얼마나 움직이는지 슬라이더로 보여 줍니다.
- Q. 왜 센서 기반 예지보전이 아닌가? A. 연령 기반은 센서가 없는 부품에도 되는 기준선이고, 센서 신호가 있으면 이 비용 모형이 "정지 임계값"의 비용 근거로 이어집니다(추론).

## 부록 — 검증 기록과 근거

### 검증 (하드체크)
- 코드 끝 assert 가 독립 재검사: ① 중도절단 없는 사본을 `scipy.stats.weibull_min.fit` 과 비교(상대차 <0.1%) + 진짜 모수 회수 ② 가동시간 적분을 `scipy.integrate.quad` 로 재계산 ③ T* 에서 1계 조건 `h·∫R − F = cp/(cf−cp)` 성립 ④ 100만 건 몬테카를로 갱신 시뮬레이션이 해석 비용률(2% 이내)과 일치, T*의 0.5배·2배가 5% 이상 더 나쁨(U자) ⑤ β≤1 이면 `None`, T→∞ 극한이 사후보전 비용률.
- 현장 추가 경계 테스트: (a) 고장 행만 있는 데이터와 절반이 중도절단인 데이터의 β 비교 (b) `cf` 를 `cp` 의 1.0배·1.1배로 놓아 T* 가 `None`→매우 큰 값으로 이어지는지.

### 합성 데이터 실행 결과
- 합성 실행 결과: 80개(고장 65·중도절단 15) → β=2.29 [1.86, 2.95], η=972h, MTBF=861h. T*=534h에서 0.0615억/h, 사후보전은 0.0862억/h.

### 손익 환산
- 연 절감 = (사후보전 비용률 − 최적 비용률) × 연 가동시간(8,760h). `cp`·`cf` = 정지 시간 × 병목 장비 시간당 손실 8.9억~14.3억(아래 근거의 매출·사양에서 계산, 추정) + 수리비. 비병목 장비는 버퍼가 있어 손실이 0 에 가깝다(처리량 회계 논리, 추론) — "모든 장비 1시간 = ○억"으로 말하지 않는다.
- 예(합성·추정): cp=17.8억(2h), cf=74.2억(8h+수리 3억) → 장비 1대 연 약 217억 절감. 병목 가정의 상한값이며 화면에는 가정 표시를 붙인다.
