# 과제설정.md — 이번 과제에서만 달라지는 값 (정본 한 곳)

> 이 파일은 **허브**다 — 원문 내용을 옮기지 않고, 어디에 무엇이 있고 우리가 어떻게 다룰지(위치 · 취급 · 뽑아낸 값 · 근거)만 적는다. 「과제 시작하자」 턴에 오케가 원문 파일을 전부 읽고 **값만 뽑아** 채운다. 다른 문서·역할·스킬은 이 값을 복사하지 않고 「과제설정 n절」로 가리킨다. 통제 메시지(연장·중단·AI 금지 시작)가 오면 **4절을 먼저 고치고** 그 사실을 모든 탭에 queue 한다.
> 출처 태그: `[README:줄]` `[<파일>:줄]` `[공지 HH:MM]` `[사용자]`. 비어 있으면 「미확인」이라고 쓴다 — 기본값을 지어내지 않는다.

## 2. 제출물 배치
채우는 지침: 과제가 지정한 파일명·양식 위치를 그대로. **루트 README 취급** 기본은 보존 — 과제가 교체·작성을 요구할 때만 교체한다(이때 원문은 `docs/task/README.md` 로 옮기고 이동 사실을 README 첫 줄에 적는다). 문장이 애매하면 사용자에게 묻는다.

- 루트 README 취급: 보존 / 교체 — 근거 `[README:줄]`
- 실행 안내 파일: (과제가 지정한 이름 · 양식 위치 `[README:줄]`. 지정이 없으면 새 `HOW_TO_RUN.md`)
- 공식 답변 파일: (예 `AI_COLLABORATION.md` Q1~Q3 · 양식 위치) 또는 「없음」
- 출력 계약 파일: (예 `EXPORT_SCHEMA.md`) 또는 「없음」 — 있으면 구현·검산·HOW_TO_RUN 이 같은 버전을 가리킨다
- 그 외 필수 산출물: 원문 위치 포인터 `[README:줄]` + 필수 산출물 **이름만** 나열(본문은 옮기지 않는다):
