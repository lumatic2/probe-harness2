# 문제 유형 카드 (OR/운영 최적화)

- 용도: 오케가 조사 질문을 세울 때와 브리핑 때 참고한다(M1 유형 후보 · M2 조사 갈래와 풀이 조건표). 사용자에게 카드를 설명하지 않는다.
- 유형이 겹치면 핵심 결정 변수로 가른다(무엇을 정하나: 누구에게=배정, 어떤 묶음=군집, 어떤 순서=경로/일정, 어디에=입지, 얼마나=재고/용량/배분).
- 표기: [S#]=맨 끝 출처. 출처 없는 문장은 (권고)=작성자 추정이다.
- 칸: ①신호 ②정식화(변수·목표·제약 — SOLUTION 0절 풀이 조건표의 재료) ③해법(검산 가능?) ④3시간 휴리스틱 ⑤엣지 ⑥물을 것 ⑦검산.
- 정확해법/솔버는 "수치 재현 가능"하면 쓰고, 설치·검산이 막히면 휴리스틱+하한 비교로 간다.

## 산업공학식 접근 순서
1. 정식화(변수·목표·제약): 말로 된 요구를 식으로 못 쓰면 풀 수 없다. **목표는 가중치가 아니라 순서로 세운다** — ① 필수 규칙 위반 0 ② 개인별 절대 상한(실무자 체감치를 설정 기본값으로, 넘는 건은 숨기지 않고 공개) ③ 자원(편수·인원) 최소 ④ 동률이면 평균. 가중치 합산은 논쟁이 끝나지 않고, 상한 없는 총점 최적화는 현장이 거부한다. 정답은 없다 — 기준을 세우고 지킨 것을 보여 주는 것이 채점 대상이다.
2. 기준안: 지금 방식 그대로 계산한 숫자. 개선은 이 숫자와의 차이로만 말한다.
3. 제약 표(하드/소프트/가정): 어긴 해는 무효인지, 벌점인지, 내 가정인지 구분해 합의한다.
4. 가장 단순한 휴리스틱: 먼저 돌아가는 해를 확보하고 정교화는 그 뒤.
5. 최악 사례·개인별 악화: 평균이 좋아도 한 건이 크게 나빠지면 현장은 거부한다.
6. 민감도: 상한·가중치를 흔들어 결론이 뒤집히는 지점을 찾는다 [S19].
7. 실무자 수용: 수치가 아니라 규칙·예외 처리를 설명한다.

## 1. 배정(assignment)
①건과 자원의 비용표, "하나당 하나" 문장. ②변수 x[건,자원]∈{0,1} · 총비용 최소 · 건마다 1개, 자원 정원 ≤ 상한. ③헝가리안/SciPy linear_sum_assignment: 1:1 최적, 다항시간, 정원>1이면 자원을 복제 [S2][S3] / 탐욕(비용 순): 차선, 암산 검산 쉬움. ④기준안 배정 → 두 건씩 맞바꿔 총비용이 줄면 채택 → 정원 초과 건만 예외 처리(권고). ⑤정원 0인 자원, 비용 동률, 특정 시기 몰림, 계획과 다르게 움직이는 건. ⑥1:1이 맞나, 선호·우선순위가 있나, 재배정 허용 범위. ⑦건수 합=전체, 자원별 정원 위반 0, 최악 건의 비용 상위 5개 직접 열람.

## 2. 용량 제약 묶음/군집화(빈 패킹 포함)
①"N개를 정원 K의 묶음으로", 위치·크기가 있는 건. ②변수 건→묶음 · 목표 묶음 수 또는 내부 거리 최소 · 묶음 크기 ≤ K. ③빈 패킹 FFD(크기 내림차순 First Fit): 근사 보장 11/9·OPT+6/9, 빈 패킹은 NP-hard [S5] / k-means: 크기 제약 없고 국소 최적, 초기값 민감 [S9] / 정수계획(솔버): 소규모만. ④k-means 후 정원 초과 묶음에서 경계 건을 이웃 묶음으로 이동(권고). ⑤정원 초과 묶음, 외딴 건(아웃라이어는 단독/별도 처리), 빈 묶음. ⑥정원은 하드인가, 묶음 수 상한, 외딴 건 처리 방침. ⑦묶음 수·크기 분포를 생성기와 별개로 집계, 최대 묶음 크기 ≤ K, 건 누락·중복 0.

## 3. 경로(VRP/TSP)
①건이 여러 지점에 흩어져 있고 방문 순서·묶음을 정함. ②변수 이동 단위별 방문 순서 · 총 이동거리(또는 최장 경로) 최소 · 단위당 적재 상한 [S1]. ③OR-Tools 라우팅: 거리 행렬+용량 제약 지원, 코드 예제 Apache 2.0 [S1], 설치·시간제한 필요 / 절약 알고리즘(Clarke-Wright): 두 지점 합칠 때 절약량 d0i+d0j−dij 큰 순으로 병합, 적재 상한 확인 [S15] / 최근접 이웃: 단순, 끝에서 나빠짐(권고). ④기준안 경로 → 2-opt식 교환(구간 뒤집기)으로 거리 감소분만 채택(권고). ⑤시간창·복수 출발지는 기본형이 못 다룸 [S15], 적재 상한 초과, 한 지점에 건 몰림. ⑥경로 길이·소요 상한, 기존 순서 유지 여부, 거리 정의. ⑦경로별 거리 합을 별도 코드로 재계산, 모든 지점 정확히 1회 방문, 최장 경로 열람.

## 4. 일정·스케줄링(shift/job)
①"언제 누가/무엇을", 근무·작업 시간 제약. ②변수 x[건,시기,자원] · 목표 완료시간·지연·불균형 최소 · 시기당 1건, 자원별 총량 상·하한 [S10]. ③CP-SAT: 교대표 문제 예제 있음 [S10], 제약 늘면 느림 / 최단작업 우선(SJN): 평균 대기 최소, 긴 건이 굶음 [S11] / 규칙 기반 배치: 암산 가능. ④기준안 표 → 과부하 시기에서 여유 시기로 한 건 이동(권고). ⑤특정 시기 몰림, 자원 결원, 연속 근무 한도, 작업 선후 관계. ⑥하드 제약 목록, 공정성 기준, 긴급 건 선점 허용. ⑦시기별 부하 히스토그램, 상·하한 위반 수를 스크립트로 재계산.

## 5. 재고·보충
①수요 기록+주문 비용+보관 비용. ②변수 주문량·시점 · 총비용(주문+보관+품절) 최소 · 용량·리드타임. ③EOQ Q*=√(2DK/h): 수요 일정, 일괄 입고, 한 품목 가정 [S7] / 재주문점+안전재고: 리드타임 수요+여유분(권고, 출처 미확보). ④기준안 주기 → 수요 분산이 큰 품목만 안전재고 가산(권고). ⑤수요 급증 시기, 품절, 용량 초과, 빈 재고. ⑥품절 허용 여부, 리드타임 변동, 발주 최소 단위. ⑦일별 재고를 시뮬레이션해 음수 일수·평균 재고를 별도 계산.

## 6. 우선순위·분류(triage, 규칙 기반)
①"급한 순", 등급 부여, 한정 자원 배분 [S17]. ②변수 건→등급 · 목표 오분류 비용 최소 · 등급별 처리 한도. ③점수표+임계값: 설명 쉬움, 임계값이 임의적 / 결정트리형 규칙: 검산 쉬움 / 가중 SJF: 비용 대비 소요로 정렬 [S11]. ④기준안 규칙 → 오분류 많은 구간에 규칙 1개 추가(권고). ⑤경계값 동률, 한도 초과 등급, 규칙 충돌, 누락 값. ⑥등급 정의, 오분류 중 더 나쁜 방향, 예외 승격 규칙. ⑦등급별 건수 합=전체, 경계값 표본 20건 수동 대조.

## 7. 이상 탐지(통계적 관리도)
①"평소와 다른 것", 시계열·측정값. ②변수 건→정상/이상 · 목표 놓침·오경보 균형 · 기준선과 한계. ③관리도: 중심선±3σ 한계, 정규 가정 [S8] / 이동평균 이탈: 단순 [S13] / 백분위(p95) 컷: 분포 가정 불필요(권고). ④기준 기간 평균·σ 계산 → 한계 밖 건만 표시, 시기별 기준선 분리(권고). ⑤비대칭 분포, 계절 패턴이 이상으로 잡힘 [S12], 기준 기간 오염. ⑥이상의 정의, 오경보 허용도, 기준 기간. ⑦한계값을 손계산, 표시된 건수를 별도 집계, 표본 확인.

## 8. 수요 예측(이동평균·계절성)
①과거 수량으로 다음 기간 수량. ②변수 예측값 · 오차(MAE 등) 최소 · 기간 단위. ③단순 이동평균: 최근 k개 평균, 최신보다 약 k/2 뒤처짐 [S13] / 계절 지수: 고정 주기 반복 반영 [S12] / 직전 값 그대로(naive): 비교 기준선. ④naive와 이동평균 오차 비교 → 요일·시기별 비율 곱하기(권고). ⑤데이터 짧음, 급변 시기, 결측, 이상치. ⑥예측 기간, 과대/과소 중 더 나쁜 쪽, 알려진 행사. ⑦마지막 구간을 빼놓고 예측해 실제와 오차 계산(홀드아웃).

## 9. 대기열·용량 계획(큐잉)
①도착과 처리가 있고 "기다림"이 문제. ②변수 처리 자원 수 · 목표 대기시간·가동률 균형 · 처리율. ③Little 법칙 L=λW: 분포 무관, 정상상태 평균 [S6] / 시뮬레이션: 분포 가정 자유, 코드 필요 / 가동률 여유(권고). ④시기별 도착률 표 → 몰리는 시기에 자원 추가 배치(권고). ⑤특정 시기 몰림은 평균 가정을 깬다 [S6], 자원 0, 대기 무한 증가. ⑥허용 대기시간, 처리 시간 변동, 우선 처리 건. ⑦L, λ, W 세 값이 Little 식을 만족하는지 별도 집계로 점검.

## 10. 매칭(안정·이분)
①양쪽이 선호 순위를 가진 짝짓기. ②변수 짝 · 안정성(깨는 쌍 없음) 또는 총 점수 · 1:1 또는 정원. ③Gale-Shapley: 항상 안정 매칭, 제안 측에 최적, O(n²) [S4] / 헝가리안: 점수합 최대 [S2] / 탐욕: 단순. ④선호표 → 제안 측 선택을 바꿔 비교(권고). ⑤미배정, 동점 선호, 정원>1, 선호 미제출. ⑥안정 vs 총점 중 무엇이 우선인가. ⑦모든 쌍에 대해 서로 더 선호하는 이탈 쌍이 없는지 이중 루프로 검사.

## 11. 입지·커버링
(권고 — 이 카드는 출처 미확보) ①후보 지점 중 일부를 골라 수요를 덮거나 가깝게("어디에 둘까"). ②변수 지점 선택 y[후보]∈{0,1} · 목표 지점 수 최소(커버링) 또는 총 거리 최소(p-median) · 모든 수요가 거리 한도 안, 지점 수 상한. ③덮는 수요가 많은 순 탐욕: 구현·검산 쉬움, 최적 보장 없음 / 정수계획: 소규모만 / 군집 중심을 실제 후보 지점으로 옮기기: 빠름, 거리 한도 재확인 필요. ④기존 지점 유지 → 못 덮인 수요만 지점 추가 → 빼도 되는 지점 제거. ⑤외딴 수요, 후보 부족, 한 지점에 몰림, 직선거리와 실제 이동의 차이. ⑥「덮였다」의 거리 기준, 기존 지점 유지 의무, 지점 수 상한. ⑦수요별 최근접 지점 거리를 별도 코드로 재계산, 못 덮인 수 0, 최장 거리 건 열람.

## 12. 자원 배분(선형계획)
(권고 — 이 카드는 출처 미확보) ①한정된 예산·인력을 활동별로 "얼마나" 나누고, 양이 비례 관계. ②변수 x[활동]≥0 · 목표 효과 합 최대 또는 비용 최소 · 자원별 사용량 ≤ 보유량, 활동별 하한·상한. ③선형계획(SciPy linprog 등): 선형이면 최적, 어느 자원이 병목인지 보임 / 효율(효과÷자원) 순 탐욕: 단순, 제약이 많으면 차선 / 정수 단위면 정수계획. ④기준안 배분 → 효율 낮은 곳에서 높은 곳으로 조금씩 이동. ⑤효과 체감(비선형), 정수 단위, 최소 보장, 해가 없는 조건. ⑥효과를 어떻게 재나, 하한 의무, 보유량이 사실인가 체감인가. ⑦자원별 사용 합 ≤ 보유량 재계산, 기준안 대비 효과, 보유량을 흔들어 결론 확인.

## 라이브러리 (3시간 안 설치·검산 부담만)
- OR-Tools: 코드 예제 Apache 2.0, 문서 CC BY 4.0 [S1]. 설치·API 학습이 부담이면 휴리스틱 먼저.
- PuLP: 모델링 도구, CBC 솔버는 별도 설치 필요 [S16]. 오프라인이면 불가.
- SciPy linear_sum_assignment: 배정 전용, 라이선스 별도 확인 필요 [S3].
- 어느 것이든 해를 별도 코드로 재계산해 제약 위반 0을 확인한다(권고).
